# aiadcast Studio — 원본 보존 편집 검증판

기존 앱·서버 소스코드 없이 새로 만드는 aiadcast의 첫 기능 검증판입니다. 15개 화면 자료와 사용자가 제시한 6가지 문제를 기준으로, 상품 사진·문구·배경·규격을 분리했습니다.

## 독립 관리와 별도 출시

외주 MVP와 분리한 **guyhan76 소유의 비공개 `aiadcast-next` 저장소**를 기준으로 개발합니다. 현재 폴더는 독립 Git 저장소이며 새 Google Play 앱으로 출시할 계획입니다. 원격 저장소 생성/접근과 신규 Play 앱 등록은 아직 완료하지 않았습니다.

- [독립 소유·계정·출시·백업 계획](docs/independent-app.md)
- [새 모델 평가와 교체 기준](docs/model-evaluation.md)
- `npm run check:isolation`: 앱 식별자·환경·기존 MVP 연결 금지 설정 검사.
- `npm run release:status -- internal`: 내부 테스트 업로드 전 남은 작업 확인.
- `npm run release:status -- production --strict`: 공개 출시 증거가 빠져 있으면 종료 코드 1. 현 단계는 미출시 상태가 정상입니다.
- `npm run release:package`: 검토 후 커밋한 소스, Git 이력, 최신 검증판을 ZIP으로 묶습니다. Python 3와 Git이 필요합니다.

현재의 웹 편집 기능 검사는 상용 Android 앱의 완성 또는 Play 승인과 다릅니다. 실제 AI·계정·결제·Android·운영 검증을 완료한 뒤 별도로 등록합니다.

## 바로 확인하기

`release/aiadcast-studio.html`을 PC에 내려받아 Chrome 또는 Edge에서 여세요. 글꼴과 프로그램을 포함한 단일 파일이며 별도 설치가 필요 없습니다. 휴대폰 화면에 맞게 구성했지만, 모바일의 로컬 HTML 실행·다운로드 지원은 앱/브라우저마다 다릅니다. Android 설치 파일과 공개 체험 URL은 아직 제공하지 않습니다.

1. 광고 정보에서 ‘사진과 문구로 직접 만들기’(기본) 또는 ‘새로운 광고 이미지 만들기’를 선택합니다. 광고 업종과 사진을 입력합니다. 교육·보험·서비스 광고는 사진이 선택 사항입니다. 배경이 있는 사진은 배경도 그대로 표시됩니다. 상품만 사용하려면 투명 PNG를 넣으세요.
2. ‘문구·언어’에서 한국어와 영어 문구를 각각 입력합니다. 초기 문구는 예시이며 자동 번역되지 않습니다.
3. ‘배경’에서 색상이나 배경 사진을 교체합니다.
4. ‘규격’에서 직육면체·평면·지름/높이·표시 없음 중 선택하고 치수를 입력합니다. ‘표시 안 함 / 규격 요약만 / 요약과 치수선’ 중 하나를 선택합니다. 숨겨도 치수 입력값은 보존됩니다. 선의 두 점은 직접 맞춥니다.
5. 미리보기 위의 ‘출력 비율’ 또는 ‘광고 용도별 비율 고르기’에서 용도와 비율을 선택합니다. 사진을 자르거나 늘이지 않고 문구와 사진을 재배치합니다.
6. ‘이 기기에 저장’한 뒤 ‘저장한 작업’에서 다시 열 수 있습니다.
7. ‘PNG 내보내기’로 이미지를, ‘프로젝트 백업’으로 원본과 편집 정보를 함께 저장합니다.

사진과 편집 내용은 외부 서버로 전송하지 않습니다. 기기 저장은 해당 브라우저에 한정되므로 중요한 작업은 JSON 프로젝트 파일로 백업하세요. PNG 파일만으로는 분리된 문구와 배경을 다시 편집할 수 없습니다.

## 이미지 제작 방식

- 사진과 문구로 직접 만들기: 현재 동작하는 직접 편집입니다. 사진·문구·배경·선택한 규격 표시를 편집하고 PNG로 내보냅니다. 교육·보험·서비스 광고는 사진 없이 문구와 배경으로 구성할 수 있습니다.
- 새로운 광고 이미지 만들기: 사진과 광고 내용을 참고 자료로 두고 새로운 광고의 제작 방향을 저장합니다. 규격을 사용하는 프로젝트만 치수를 함께 참고합니다. 새 상품이나 장면은 원본과 다르게 표현될 수 있으며 실물 형상·설계도 재현을 보장하지 않습니다. 현재 AI 연결 전이므로 생성 결과 대신 참고 사진을 표시하고 생성/PNG 출력을 막습니다.

제작 방식과 규격의 사용/표시 여부는 각각 선택합니다. 규격을 사용하는 프로젝트는 표시를 숨겨도 치수를 참고값으로 포함합니다. 규격 사용을 끈 프로젝트는 생성 요청에 치수를 넣지 않습니다. 선택과 요청 문구는 저장·복원되며, 원본 방식으로 돌아오면 같은 첨부 파일과 편집 정보를 다시 사용합니다. 예전 프로젝트는 원본 보존 방식으로 열립니다.

## 규격 없는 업종 광고

‘광고 업종·상품 분류’에 자동차·모빌리티, 교육·강의, 보험, 서비스 업종을 추가했습니다. 이 네 분류를 선택하면 ‘규격 정보 사용’이 기본적으로 꺼집니다. 다른 실물 상품도 같은 선택을 끄거나 ‘규격 형식 → 규격 정보 없음’을 선택할 수 있습니다.

- **규격 사용 안 함:** 치수 입력을 요구하지 않고 생성 요청의 specifications는 빈 배열입니다. 치수선과 규격 표를 만들지 않으며 사진이 있으면 그 공간을 사진 영역으로 활용합니다. 이전에 입력한 수치는 기기/백업 데이터에만 남겨 복구할 수 있게 합니다.
- **규격 사용 + 표시 안 함:** 치수를 생성 참고값으로 사용하면서 완성 이미지에서는 숨깁니다. ‘규격 없음’과 다른 설정입니다.
- **교육·보험·서비스:** 상품·서비스명, 서비스 내용, 광고 문구를 저장할 수 있습니다. 사진 없이 문구·배경만으로 PNG를 만들거나 교실·상담·매장 사진 및 로고를 사용할 수 있습니다. 사진 없는 창작 요청에는 원하는 광고 내용을 입력해야 하며 실제 AI 연결 전까지 생성은 대기 상태입니다.
- **자동차:** 치수 없이 실제 차량 사진을 사용하는 광고를 만들 수 있습니다. ‘사진과 문구로 직접 만들기’에서 차량을 다른 차로 다시 그리지 않습니다. 실제 차량 보존 모드에서는 원본 사진이 필요합니다.

기존에 입력한 문구·사진·치수 값은 업종을 바꿔도 지워지지 않습니다. 필요하면 ‘규격 정보 사용’을 켜고 규격 형식을 선택한 뒤, 표시 여부를 직접 정하세요. 보험의 보장 내용·가격·조건 등을 자동으로 만들어 넣는 기능은 없으며 광고 문구에 직접 입력합니다.

## 구현과 한계

| 실제 구현 | 후속 작업 |
|---|---|
| 원본 사진 바이트·비율 보존, 균등 확대/축소 | 자동 배경 제거·마스크 보정, 상품 이동·회전 |
| 한/영 문구 별도 저장·폰트 출력 | 자동 번역·문안 검토, 추가 언어 |
| 배경색·사진 교체, 문구·규격 개별 수정 | AI 배경 생성·영역 수정 |
| 치수 입력·수동 치수선·일관된 요약 표시 | 실물 형상 재현·특허 명세서 대조 |
| 기기 저장·백업·복원·7가지 비율 PNG 출력 | 서버 계정·생성 작업·이용권·결제·Android 패키징 |

원본 사진 내부의 글자는 사진의 일부여서 홍보 문구 언어를 바꿔도 변경되지 않습니다. 폰트 출력은 입력한 문구를 보존하며 원문의 맞춤법을 자동으로 고쳐주지는 않습니다. 선택한 비율의 템플릿에서 문구가 넘치면 내보내기를 막고 수정을 안내합니다.

## 광고 이미지 비율

| 비율 | PNG 크기 | 활용 예시 |
|---|---|---|
| 1:1 | 1080 × 1080 | SNS 피드, 정사각형 상품 소개 |
| 4:5 | 1080 × 1350 | 인스타그램·페이스북 세로 피드 |
| 3:4 | 1080 × 1440 | 세로 상품 소개, 카탈로그 |
| 9:16 | 1080 × 1920 | 스토리, 릴스·쇼츠용 이미지 소재 |
| 2:3 | 1080 × 1620 | 세로 포스터, 핀터레스트 |
| 16:9 | 1920 × 1080 | 웹 가로 홍보 이미지, 영상 썸네일 |
| 1.91:1 | 1200 × 628 | 링크 광고, 가로 배너 |

1.91:1은 광고에서 쓰이는 근사 표기이며 실제 픽셀 비율은 1200/628입니다. 용도는 활용 예시이며 매체별 광고 게재 규격을 실시간 검증하는 기능은 아닙니다. 릴스·쇼츠용 PNG 선택이 영상 생성을 의미하지는 않습니다.

세로형과 정사각형은 상하 배치, 가로형은 문구와 상품을 좌우로 배치합니다. 원본 사진은 전체를 비율 유지하여 맞추고 원본의 인쇄 내용은 바꾸지 않습니다. 문구가 해당 공간에 넘치면 내보내기를 막고 수정을 안내합니다. 규격 표시 여부와 제작 방식은 바뀌지 않습니다.

기존 프로젝트는 9:16·2:3 그대로 열립니다. 새 비율도 기기 저장·JSON 백업·불러오기와 향후 생성 요청에 보존됩니다. 창작 모드의 선택 비율은 저장되지만 실제 AI 생성은 아직 연결 전입니다. 생성 요청의 출력 픽셀은 최종 합성 규격이며 특정 AI 공급사가 그 해상도를 직접 지원한다는 뜻은 아닙니다.

## 추가된 서버 기반

`server/`에는 고객 이용권의 예약·확정·복원과 공급사 API 비용을 분리한 SQLite 참조 구현, 모델 버전 선택 구조가 있습니다. `npm run test:domain`으로 검증합니다. 실제 결제사·OpenAI·Google Play에는 연결되지 않았고 브라우저 화면에서 이용권을 차감하지 않습니다. 인증·영수증 검증·품질 판정·작업 큐 등은 운영 연결 전에 추가해야 합니다.

## 개발 및 검증

Node.js 24, npm 11에서 확인했습니다.

```bash
cd /workspace/aiadcast-next
npm ci --cache /workspace/.npm-cache --no-audit --no-fund
npm run build
npm test
npm run test:domain
```

`npm run dev`는 개발 서버를, `npm run preview`는 빌드 검증 서버를 실행합니다. 개발 서버 5180 / 미리보기 4180 포트를 사용합니다. 내부 테스트용 주소를 외부 사용자가 접속할 수 있는 주소로 안내하지 마세요.

브라우저 테스트는 기본 `/usr/bin/chromium`을 사용합니다. 다른 실행 환경에서는 설치된 Chromium 경로를 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`로 지정하거나 playwright.config.ts의 실행 경로 정책을 확인하세요. Android/iOS 실제 기기 검증과 Play 배포 검증은 별도입니다.

빌드 결과는 `dist/`, 다운로드 검증판은 `release/aiadcast-studio.html`입니다. 공개 호스팅은 Web Crypto 기능을 위해 HTTPS를 사용해야 합니다. API 키나 유료 서비스가 필요 없는 로컬 검증판이며 회사 홈페이지 저장소를 변경하거나 배포하지 않습니다.
