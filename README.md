# aiadcast Studio — 독립 모바일 광고 제작 개발판

**제품 목표: 마케팅 전담 직원·프롬프트 작성 능력·AI 전문 지식·여러 AI 구독 없이, 누구나 언제 어디서든 필요한 광고를 만들 수 있게 합니다.** [핵심 제품 원칙과 판단 기준](docs/product-vision.md)을 신규 기능과 화면 설계에 적용합니다. 자유로운 대화는 선택 사항이며, 추천을 고르는 것만으로도 광고를 완성하는 경험이 목표입니다.

기존 앱·서버 소스코드 없이 새로 만드는 aiadcast의 개발판입니다. 15개 화면 자료, 사용자가 제시한 6가지 문제와 특허 출원서 24쪽을 기준으로 상품 사진·문구·배경·규격을 분리했습니다. 홈·3단계 제작·프로젝트·사용 안내·편집 화면을 모바일/PC에 맞춰 구성했습니다.

**2026-10-10 구현 상태:** 한국어·영어 UI, 원본 사진 편집, Sunburst 개발 API 어댑터, 문구 제안·번역 어댑터, 생성 결과 검토·사용 확정·테스트 이용권 복원, SQLite 원장, Android debug APK 제작 기반을 연결했습니다. 승인된 $1 시험에서 사진 없는 카페 이미지 1장을 실제 생성했고, 사용량 기준 API 비용은 $0.04749였습니다. 문구는 Responses의 인증 오류 후 Chat Completions로 연결을 수정해 성공했고, 사용량 기준 $0.000496를 추가 기록했습니다. 평균 원가·참조 사진 품질 검증은 남아 있습니다. [실제 시험 기록](docs/live-test-2026-10-10.md)을 참고하세요. 실제 회원·결제·공개 API·Play 출시는 완료하지 않았습니다. [로컬 API 실행과 경계](docs/backend-local-api.md), [Android 빌드와 실기기 검증](docs/android-development.md), [최신 검증 기록](docs/validation.md)을 함께 확인하세요.

앱 언어는 브라우저 설정을 기본값으로 한국어 또는 영어로 시작하고 사용자가 바꾼 선택을 보관합니다. **앱 화면 언어·광고 문구 언어·결제 국가/통화는 별도 설정**입니다. 화면 언어 변경으로 기존 광고 문구를 번역하거나 판매 통화를 바꾸지 않습니다. 아래 기존 미리보기 파일은 이전 개발 단계의 기록이며 최신 구현 상태는 검증 문서를 기준으로 합니다.

## 비공개 서버 연결 준비

초대 로그인, 계정별 생성 DB·테스트 이용권·월 예산, 서버 프로젝트 저장·복원과 충돌 검사를 구현했습니다. 기기 저장도 계정별로 분리합니다. 일반 회원가입·실결제·공개 서비스가 아닌 비공개 시험용이며, **외부 HTTPS 서버는 아직 개설하지 않았습니다.** [베타 서버 실행·배포·제한](docs/beta-server.md)을 확인하세요.

`Dockerfile.beta`와 선택적 `render.yaml`로 영구 디스크가 있는 서버에 배포할 수 있도록 준비했습니다. 예산0·생성/문구 비활성이 기본이며, 컨테이너 시작이 유료 API 실행이나 서버 개설 승인을 뜻하지 않습니다. 새 설치 파일은 `release/android/aiadcast-next-beta-dev.apk`입니다. 실제 공개 주소를 아직 포함하지 않아 휴대폰에서 서버 생성은 연결 전입니다.

## 새 제작 흐름

홈에는 **상품 광고**와 **서비스 광고** 두 가지 선택을 표시합니다. **나의 광고 만들기**로 시작해도 먼저 상품 또는 서비스를 고른 뒤 해당 분야의 카테고리와 세부 업종을 선택합니다. 업종과 브랜드 → 사진·정보 → 광고 방향을 거쳐 편집기로 이동합니다. 새 제작의 규격은 선택 사항이며 서비스 광고는 사진 없이도 시작할 수 있습니다. 필요한 규격을 넣고 표시만 숨기는 선택도 가능합니다.

‘내 프로젝트’에서 기기 저장본을 검색·다시 열고, 미리보기의 **게시글과 활용 방법 보기**로 이동합니다. 업종·목적별 추천 매체 2개, 매체별 게시글 초안·검색어·해시태그, 이미지 저장, 게시 요령과 반응 확인 방법을 제공합니다. 직접 수정한 글은 매체·광고 언어별로 프로젝트에 저장하며 가격·연락처 변경 시 재확인을 안내합니다. 매체용 이미지 저장은 편집 중인 비율을 바꾸지 않습니다. 입력 정보를 조합하는 규칙 기반 제안이며 추가 AI 호출·자동 게시·검색 순위 예측은 하지 않습니다. ‘광고 기획 저장’은 생성 요청과 게시 초안을 JSON으로 보관합니다. ## 업종별 광고 방향과 프리미엄 스타일

**상품 / 서비스 → 카테고리 → 세부 업종 → 광고 방향** 순서로 고릅니다. 상품을 고르면 전자기기·가전, 패션·스타일, 포장재 등 상품 카테고리 9개만, 서비스를 고르면 음식·매장, 숙박·여행, 금융·보험 등 서비스 카테고리 10개만 보입니다. 세부 분류는 실물 상품 19종과 서비스 29종으로 총 48개이며 검색도 선택한 상품 또는 서비스 범위에서 이루어집니다. 편집기에서는 업종 선택을 접어두고 필요할 때 변경할 수 있습니다.

**상품 → 포장재**에서 포장재 분야를 따로 선택합니다. **박스·쇼핑백·라벨·용기·비닐·파우치·기타** 중 고르고 브랜드·제품 소개나 규격·소재 안내 방향을 선택합니다. 기존 포장재 프로젝트는 포장재 그룹의 기타로 열리며 사진·문구·규격 설정을 유지합니다.

**상품 → 패션·스타일**에서 패션 분야를 따로 선택합니다. 의류·패션, 가방, 신발, 주얼리, 패션잡화 중 고르고 컬렉션·제품 소개나 소재·디테일에 맞는 광고 방향을 선택합니다. 기존 패션 프로젝트의 사진·문구·규격 등 저장 정보는 유지합니다.

**서비스 → 사주·운세**를 열면 **타로·별자리·명리학·신점** 네 가지로 구분해 선택할 수 있습니다. 각 분야의 소개, 상담·예약, 이용 정보에 맞춰 광고를 준비합니다.

각 업종에 맞는 목적 3가지와 에디토리얼·시그니처·내추럴·모던 테크 4가지 스타일을 선택합니다. 추가 요청은 선택 사항이며, 선택만으로 기본 문구·배경색·장식을 적용한 편집 초안을 시작할 수 있습니다. 서비스는 사진·규격 없이 시작하고, 실물 규격이 필요하면 업종과 관계없이 직접 켤 수 있습니다. 목적·스타일·추가 입력은 저장·백업·생성 요청에 함께 포함됩니다.

새 배경·창작 시안을 요청하는 개발용 AI API를 연결했습니다. 테스트 서버와 공급사 비용 한도가 활성화된 경우에만 호출하며 결과를 확인·사용 확정한 후 편집과 PNG 내보내기로 이어집니다. 기본 설정에서는 유료 호출이 꺼져 있고 원본 사진·문구 직접 편집을 사용할 수 있습니다. [전체 업종·사용 흐름·구현 범위](docs/industry-advertising.md)를 참고하세요.

## 대화로 광고 요청·수정

편집기의 **대화로 요청·수정하기**에서 배경·조명·구도·인쇄·상품 색상·문구 등을 문장으로 남기고 후속 요청을 이어갈 수 있습니다. ‘배경을 검정색으로 바꿔줘’, ‘제목을 "브랜드의 가치를 담다"로 바꿔줘’, ‘비율을 4:5로 바꿔줘’, ‘규격은 숨겨줘’는 변경안을 확인한 뒤 바로 편집합니다. 상품 인쇄·색상 변경은 별도 시안 허용을 확인하고 요청으로 보관합니다.

대화는 기기 저장·프로젝트 JSON 백업에 포함됩니다. 단순 요청은 빠른 편집으로 적용하고, 자유로운 연출 요청은 별도 AI 생성 요청에 포함합니다. 메모를 남기는 것만으로 이미지 생성이나 테스트 이용권 차감은 실행하지 않습니다. 문구·언어 탭의 CopyAssistant는 한국어·영어 제안과 번역을 검토한 뒤 선택적으로 적용하도록 연결했습니다. 일반적인 AI 채팅 전체와 선택 영역의 상품 인쇄·색상 수정은 아직 구현되지 않았습니다. [동작·원본 보호·연결 설계](docs/conversational-direction.md)를 참고하세요.

## 독립 관리와 별도 출시

외주 MVP와 분리한 **guyhan76 소유의 비공개 `aiadcast-next` 저장소**를 기준으로 개발합니다. 현재 폴더는 독립 Git 저장소이며 새 Google Play 앱으로 출시할 계획입니다. 개발용 Android 식별자는 `com.selluplabs.aiadcast.next.dev`이며 기존 외주 앱을 덮어쓰지 않습니다. 신규 Play 앱 등록·상용 서명·심사 제출은 아직 완료하지 않았습니다.

- [독립 소유·계정·출시·백업 계획](docs/independent-app.md)
- [새 모델 평가와 교체 기준](docs/model-evaluation.md)
- `npm run check:isolation`: 앱 식별자·환경·기존 MVP 연결 금지 설정 검사.
- `npm run release:status -- internal`: 내부 테스트 업로드 전 남은 작업 확인.
- `npm run release:status -- production --strict`: 공개 출시 증거가 빠져 있으면 종료 코드 1. 현 단계는 미출시 상태가 정상입니다.
- `npm run release:package`: 검토 후 커밋한 소스, Git 이력, 최신 검증판을 ZIP으로 묶습니다. Python 3와 Git이 필요합니다.

웹·서버 검사와 debug APK 빌드는 상용 Android 앱의 완성 또는 Play 승인과 다릅니다. 유료 AI 실측, 계정·실결제, Android 실기기·운영 검증을 완료한 뒤 별도로 등록합니다.

## 바로 확인하기

`release/aiadcast-studio.html`을 PC에 내려받아 Chrome 또는 Edge에서 여세요. 글꼴과 프로그램을 포함한 단일 파일이며 별도 설치가 필요 없습니다. 휴대폰 화면에 맞게 구성했지만, 모바일의 로컬 HTML 실행·다운로드 지원은 앱/브라우저마다 다릅니다. 별도 Android 개발 APK는 `android/app/build/outputs/apk/debug/app-debug.apk`로 빌드합니다. 공개 체험 URL과 Play 출시 파일은 아직 제공하지 않습니다. 단일 HTML만 열면 로컬 AI 서버가 자동 연결되는 것은 아닙니다.

1. 광고 정보에서 ‘사진과 문구로 직접 만들기’(기본) 또는 ‘새로운 광고 이미지 만들기’를 선택합니다. 광고 업종과 사진을 입력합니다. 서비스 29종은 사진이 선택 사항입니다. 배경이 있는 사진은 배경도 그대로 표시됩니다. 상품만 사용하려면 투명 PNG를 넣으세요.
2. ‘문구·언어’에서 한국어와 영어 문구를 각각 입력합니다. 초기 문구는 예시입니다. 테스트 서버·문구 호출이 활성화되면 CopyAssistant의 제안·번역 결과를 원문과 비교하고 승인하여 적용할 수 있습니다. 앱 언어를 바꾸는 것만으로 광고를 번역하지 않습니다.
3. ‘배경’에서 색상이나 배경 사진을 교체합니다.
4. ‘규격’에서 직육면체·평면·지름/높이·표시 없음 중 선택하고 치수를 입력합니다. ‘표시 안 함 / 규격 요약만 / 요약과 치수선’ 중 하나를 선택합니다. 숨겨도 치수 입력값은 보존됩니다. 선의 두 점은 직접 맞춥니다.
5. 미리보기 위의 ‘출력 비율’ 또는 ‘광고 용도별 비율 고르기’에서 용도와 비율을 선택합니다. 사진을 자르거나 늘이지 않고 문구와 사진을 재배치합니다.
6. ‘이 기기에 저장’한 뒤 ‘저장한 작업’에서 다시 열 수 있습니다.
7. ‘PNG 내보내기’로 이미지를, ‘프로젝트 백업’으로 원본과 편집 정보를 함께 저장합니다.

수동 편집과 기기 저장만 사용하는 동안에는 공급사 호출이 없습니다. AI 기능을 요청하면 필요한 입력이 개발 API로 전송됩니다. 원본 활용 모드의 사진은 개발 서버에서 검증·보관하지만 OpenAI에는 보내지 않고 배경만 생성합니다. 창작 모드의 참조 사진과 문구 제안·번역 입력은 해당 공급사 요청에 사용됩니다. 기기 저장은 해당 브라우저에 한정되므로 중요한 작업은 JSON 프로젝트 파일로 백업하세요. PNG 파일만으로는 분리된 문구와 배경을 다시 편집할 수 없습니다.

## 이미지 제작 방식

- 사진과 문구로 직접 만들기: 사진·문구·배경·선택한 규격 표시를 편집하고 PNG로 내보냅니다. AI 배경 요청은 원본 사진을 다시 그리지 않고 별도 배경을 생성해 합성합니다. 자동 배경 제거는 없으므로 불투명한 원본 사진의 배경은 남습니다. 서비스 29종은 사진 없이 문구와 배경으로 구성할 수 있습니다.
- 새로운 광고 이미지 만들기: 사진과 광고 내용을 참고 자료로 두고 새로운 광고의 제작 방향을 저장합니다. 규격을 사용하는 프로젝트만 치수를 함께 참고합니다. 새 상품이나 장면은 원본과 다르게 표현될 수 있으며 실물 형상·설계도 재현을 보장하지 않습니다. 현재 설정과 호환되는 생성 결과를 검토·사용 확정하기 전에는 참고 사진을 표시하며 PNG 출력을 막습니다. 사용 확정 후에는 해당 시안에 별도 문구를 합성해 저장할 수 있습니다. 사진 없는 카페 창작 1건은 실호출로 확인했으며 참조 사진 품질은 별도 검증이 필요합니다.

제작 방식과 규격의 사용/표시 여부는 각각 선택합니다. 규격을 사용하는 프로젝트는 표시를 숨겨도 치수를 참고값으로 포함합니다. 규격 사용을 끈 프로젝트는 생성 요청에 치수를 넣지 않습니다. 선택과 요청 문구는 저장·복원되며, 원본 방식으로 돌아오면 같은 첨부 파일과 편집 정보를 다시 사용합니다. 예전 프로젝트는 원본 보존 방식으로 열립니다.

## 규격 없는 업종 광고

서비스 29종과 자동차·모빌리티로 업종을 바꾸면 ‘규격 정보 사용’이 기본적으로 꺼집니다. 새 광고는 모든 업종에서 규격이 선택 사항입니다. 필요한 경우 직접 규격 사용을 켤 수 있으며, 같은 업종을 다시 선택해도 사용자가 켠 규격 설정을 유지합니다.

- **규격 사용 안 함:** 치수 입력을 요구하지 않고 생성 요청의 specifications는 빈 배열입니다. 치수선과 규격 표를 만들지 않으며 사진이 있으면 그 공간을 사진 영역으로 활용합니다. 이전에 입력한 수치는 기기/백업 데이터에만 남겨 복구할 수 있게 합니다.
- **규격 사용 + 표시 안 함:** 치수를 생성 참고값으로 사용하면서 완성 이미지에서는 숨깁니다. ‘규격 없음’과 다른 설정입니다.
- **서비스 29종:** 상품·서비스명, 서비스 내용, 광고 문구를 저장할 수 있습니다. 사진 없이 문구·배경만으로 PNG를 만들거나 교실·상담·매장 사진 및 로고를 사용할 수 있습니다. 사진 없는 창작 요청도 업종별 추천 방향만으로 준비할 수 있습니다. 생성 실행에는 연결된 개발 서버와 활성화된 비용 한도가 필요합니다.
- **자동차:** 치수 없이 실제 차량 사진을 사용하는 광고를 만들 수 있습니다. ‘사진과 문구로 직접 만들기’에서 차량을 다른 차로 다시 그리지 않습니다. 실제 차량 보존 모드에서는 원본 사진이 필요합니다.

기존에 입력한 문구·사진·치수 값은 업종을 바꿔도 지워지지 않습니다. 필요하면 ‘규격 정보 사용’을 켜고 규격 형식을 선택한 뒤, 표시 여부를 직접 정하세요. 보험의 보장 내용·가격·조건 등을 자동으로 만들어 넣는 기능은 없으며 광고 문구에 직접 입력합니다.

원본 사진 내부의 글자는 사진의 일부여서 홍보 문구 언어를 바꿔도 변경되지 않습니다. 폰트 출력은 입력한 문구를 보존하며 원문의 맞춤법을 자동으로 고쳐주지는 않습니다. 선택한 비율의 템플릿에서 문구가 넘치면 내보내기를 막고 수정을 안내합니다.

## 광고 이미지 비율

편집기의 **인스타그램에 맞춰 저장하세요**에서 피드 이미지(4:5, 1080×1350), 스토리 이미지(9:16, 1080×1920), 릴스용 정지 이미지(9:16, 1080×1920)를 각각 PNG로 저장할 수 있습니다. 선택한 크기로 사진과 문구를 재배치하되 현재 프로젝트의 비율·원본·편집 이력은 바꾸지 않습니다. 각 출력에서 문구 넘침과 필수 정보를 검사하며, 현재 작업에 맞는 생성 결과를 아직 사용 확정하지 않은 창작 모드에서는 저장을 비활성화합니다.

릴스용 PNG는 영상 제작에 사용할 정지 소재이며 동영상 생성·인스타그램 자동 게시 기능이 아닙니다. 실제 게시 전 플랫폼 미리보기에서 잘림과 글자 위치를 확인해야 합니다.

홈의 **이전 광고 수정하기**에서 기기에 저장한 프로젝트를 다시 열 수 있습니다. 프로젝트 JSON 백업도 원본과 편집 데이터를 복원합니다. 합쳐진 PNG/JPG만 다시 올려서 문구·상품·배경이 자동으로 분리되는 기능은 아직 없습니다.

| 비율 | PNG 크기 | 활용 예시 |
|---|---|---|
| 1:1 | 1080 × 1080 | SNS 피드, 정사각형 상품 소개 |
| 4:5 | 1080 × 1350 | 인스타그램·페이스북 세로 피드 |
| 3:4 | 1080 × 1440 | 세로 상품 소개, 카탈로그 |
| 9:16 | 1080 × 1920 | 스토리, 릴스·쇼츠용 이미지 소재 |
| 2:3 | 1080 × 1620 | 세로 포스터, 핀터레스트 |
| 16:9 | 1920 × 1080 | 웹 가로 홍보 이미지, 영상 썸네일 |
| 1.91:1 | 1200 × 628 | 링크 광고, 가로 배너 |

1.91:1은 광고에서 쓰이는 근사 표기이며 실제 픽셀 비율은 1200/628입니다. 용도는 활용 예시이며 매체별 광고 게재 규격을 실시간 검증하는 기능은 아닙니다. 릴스·쇼츠용 PNG 선택이 영상 생성을 의미하지는 않습니다.

세로형과 정사각형은 상하 배치, 가로형은 문구와 상품을 좌우로 배치합니다. 원본 사진은 전체를 비율 유지하여 맞추고 원본의 인쇄 내용은 바꾸지 않습니다. 문구가 해당 공간에 넘치면 내보내기를 막고 수정을 안내합니다. 규격 표시 여부와 제작 방식은 바뀌지 않습니다.

기존 프로젝트는 9:16·2:3 그대로 열립니다. 새 비율도 기기 저장·JSON 백업·불러오기와 향후 생성 요청에 보존됩니다. 창작 모드의 선택 비율도 생성 요청과 프로젝트에 보관됩니다. 공급사의 네이티브 출력 비율과 최종 광고 비율은 합성 단계에서 구분합니다. 생성 요청의 출력 픽셀은 최종 합성 규격이며 특정 AI 공급사가 그 해상도를 직접 지원한다는 뜻은 아닙니다.

## 추가된 서버 기반

`server/`에는 Sunburst HTTP 어댑터, 문구 제안·번역 어댑터, 생성 작업 및 공급사 사용량과 개발용 이용권을 분리하는 SQLite 원장이 있습니다. 이미지를 요청할 때 테스트 이용권을 예약하고, 사람이 결과를 사용할 때 확정하며, 실패·반려 시 복원합니다. 불확실한 공급사 응답은 자동 재호출하지 않습니다. 문구·이미지는 같은 테스트 예산을 사용하며 세부 예산 예약액은 공급사 과금의 절대 상한 보장이 아닙니다. 실제 결제사·Google Play Billing·운영 사용자 인증은 연결하지 않았습니다.

`npm run api:dev`는 `127.0.0.1:8787`에서만 실행됩니다. 기본 예산은 0달러이고 이미지·문구 호출 스위치는 모두 비활성입니다. 공급사 키가 저장되어 있어도 이 기본값으로는 유료 호출하지 않습니다. 공개 터널이나 모바일 운영 서버로 사용하지 않으며 [로컬 API 문서](docs/backend-local-api.md)에 실행 설정·전송 범위·원장·테스트 한계를 기록했습니다. 새 모델은 서버 평가·승인을 거쳐 교체하는 방향이며 공급사 신모델로 자동 전환하는 기능은 아직 없습니다.

## 개발 및 검증

Node.js 24, npm 11에서 확인했습니다.

```bash
cd /workspace/aiadcast-next
npm ci --cache /workspace/.npm-cache --no-audit --no-fund
npm run build
npm test
npm run test:domain
```

`npm run dev`는 `127.0.0.1:5180` 개발 서버를, `npm run preview`는 `127.0.0.1:4180` 빌드 검증 서버를 실행합니다. API를 검증하려면 별도 터미널에서 `npm run api:dev`를 실행합니다. Vite의 `/api`가 루프백 API 8787로 연결됩니다. 기본 상태 확인과 직접 편집에는 유료 호출이 필요 없습니다. 내부 주소를 외부 사용자가 접속할 수 있는 주소로 안내하거나 인증 없는 개발 API를 외부 공개하지 마세요.

Android용 JDK 17 이상과 SDK API 36/build-tools 36.0.0을 준비한 뒤 `bash native/android-build.sh`로 웹 번들·네이티브 검증·debug APK를 빌드합니다. 전체 환경 준비·출력 경로·기기 검증 범위는 [Android 개발 안내](docs/android-development.md)를 따릅니다. 기본 APK에는 공개 API origin이나 공급사 키가 없으며 오프라인 편집이 가능합니다. 로컬 API 구현만으로 휴대폰에서 실제 생성·결제가 연결되는 것은 아닙니다.

브라우저 테스트는 기본 `/usr/bin/chromium`을 사용합니다. 다른 실행 환경에서는 설치된 Chromium 경로를 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`로 지정하거나 playwright.config.ts의 실행 경로 정책을 확인하세요. Android/iOS 실제 기기 검증과 Play 배포 검증은 별도입니다.

빌드 결과는 `dist/`, 다운로드 검증판은 `release/aiadcast-studio.html`입니다. 공개 호스팅은 Web Crypto 기능을 위해 HTTPS를 사용해야 합니다. 직접 편집은 API 키나 유료 서비스 없이 사용할 수 있습니다. AI 기능은 서버 비밀값과 테스트 비용 한도를 별도로 설정해야 하며 승인된 실제 호출 결과와 비용은 [시험 기록](docs/live-test-2026-10-10.md)에 남겼습니다. 회사 홈페이지 저장소를 변경하거나 배포하지 않습니다.

## 가격 검토

상단 **이용 요금**에서 사용자 확정 출시 가격을 확인할 수 있습니다. 원화는 체험 3개 6,900원·기본 10개 19,900원·묶음 30개 49,900원이며 달러는 각각 $4.99·$14.99·$39.99입니다. 새로운 AI 시안을 기준으로 하며 동일 광고의 수동 문구·비율 수정과 재다운로드를 새 생성으로 세지 않습니다. 현재 화면의 국가/통화 선택은 가격 안내이며 실제 결제는 연결 전입니다. 상용 결제의 통화·세금은 판매 국가와 스토어 상품 설정에 따르며 앱 언어 또는 광고 문구 언어로 자동 변경하지 않습니다. [경쟁 가격 참고·원가 가정·출시 제안](docs/pricing-strategy.md), [팩별 계산 결과](docs/pricing-calculation.md)를 참고하세요. `npm run pricing:report`로 계산을 다시 실행할 수 있습니다.

### 2026-10-10 광고 제작 화면 재설계

사진 최대10장, 상품 상세설명, 선택적 회사명·전화·이메일·홈페이지 하단 표시와 3단계 제작 흐름을 추가했습니다. 실제 참조 생성 1회에서 조명·구성은 확인했으나 상품 동일성은 미합격입니다. [변경 내용·시험 범위](docs/premium-redesign-20261010.md).
