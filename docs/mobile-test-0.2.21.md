# aiadcast Preview 0.2.21 시험 안내

2026-10-11 · `com.selluplabs.aiadcast.next.preview` · versionCode 23.

## 이번 업데이트

- 홈과 편집기 푸터를 같은 로고로 통합했다. 주황색 ai·삼각형, 검정색 adcast, 로고 28px, 회사 표기 14px를 적용했다.
- 회원가입과 로그인 화면 사이의 이동 링크를 추가했다. 이메일 인증은 인증 요청 기기에서 확인한 뒤 로그인하는 기존 보호 흐름을 유지한다.
- 서버 관리자 역할과 관리자 페이지를 연결했다. 회원, 생성 이력, 비용, 테스트 결제 기록, 작업 기록을 확인하고 테스트 이용권·예산을 배정한다.
- 서버 연결 화면에서 로그인 후 이미지 생성 가능 여부와 필요한 키·예산·이용권 설정을 확인한다.
- 영어 편집 화면의 320px 휴대폰 폭에서 상단 메뉴가 가로로 넘치지 않도록 줄바꿈을 적용했다.

기존 Preview 위에 APK를 설치해 업데이트한다. 기존 앱을 삭제하지 않는다. ZIP에는 APK와 이 안내를 담은 TEST-GUIDE.md가 들어 있다. 이전 Preview와 같은 개발 서명으로 빌드했으며 이번 업데이트의 휴대폰 설치 성공은 아직 확인하지 않았다.

## 지금 기기에서 가능한 시험

공개 서버가 없어도 **테스트 계정 · 서버 연결 → 서버 없는 체험 시작**으로 체험 가입·모의 결제·기기 합성·PNG 저장을 확인할 수 있다. 실제 OpenAI 호출, 이메일 수신, 결제사 승인이 아니다. 사진 여러 장 추가, 규격 입력, 원본 보존, 비례 검사와 홈 광고사례 10개는 유지한다.

## 실제 서버 연결 후 시험 순서

1. 운영자가 비공개 테스트 서버를 HTTPS로 배포하고 OpenAI·인증 메일 설정을 서버 비밀값으로 연결한다. API 키는 채팅·앱·Git에 넣지 않는다. OpenAI Developers 설치만으로 APK에 서버 주소와 API 키가 자동 연결되지는 않는다.
2. 운영자는 서버 CLI로 관리자 초대를 발급한다. 초대 로그인 후 **관리자** 화면을 연다. 일반 가입으로 관리자 역할을 선택할 수 없다.
3. 앱의 체험 모드를 종료한다. **테스트 계정 · 서버 연결 → 테스트 서버 주소**에 배포된 HTTPS 주소를 저장한다. 임의의 홈페이지나 가짜 주소를 입력하지 않는다.
4. **회원가입 → 인증메일 받기 → 메일에서 이메일 인증하기 → 원래 앱에서 인증 상태 확인** 순서로 로그인한다. 앱에서 API 키를 입력할 필요가 없다.
5. 관리자가 회원에게 테스트 이용권 1개와 승인된 범위의 API 예산을 배정한다. 이 단계는 실제 결제나 매출이 아니다.
6. 광고 만들기에서 상품 사진·정보 또는 서비스 정보를 입력하고 9:16을 선택한다. 실제 생성은 공급사 호출이 필요하므로 실행 전 준비 상태를 확인한다.
7. 시안을 확대 검수하고 사용 확정 후 PNG로 저장한다. 관리자는 생성 이력·사용량 기준 비용·회원 이용권을 확인한다. 오류·반려·같은 요청 재시도에 대한 기존 중복 차감 보호를 유지한다.

실제 시험 결제를 확인하려면 서버에 결제사 시험 키도 연결해야 한다. 실결제는 지원하지 않는다. 설정됨 표시는 자격증명 존재 여부이며 실제 생성·메일 수신 성공 증거가 아니다.

## 검증과 남은 연결

서버 로직 검사 207개를 통과했다. 가입·결제·관리자·오프라인 합성·촬영면 비교·모바일 배치 관련 브라우저 검사 16개와 Android 저장 브리지 검사 4개를 통과했다. 로컬 실제 HTTP와 SQLite를 사용해 회원가입·인증·로그인 → 관리자 지급·배정 → 이미지 응답 검토·확정 → 1080×1920 PNG 저장을 모바일과 데스크톱에서 확인했다. 인증 메일은 시험 수신함으로 캡처하고 이미지 공급사는 시험용 응답으로 대체했다. 실제 OpenAI·메일 발송 성공으로 계산하지 않는다.

OpenAI Developers 설치는 확인했지만 현재 대화에서 API 키 연결 기능을 사용할 수 없었다. 공개 HTTPS 서버·메일 공급사·결제사 시험 키도 아직 연결하지 않았다. 이번 요청의 실제 OpenAI 생성 및 휴대폰에서의 온라인 전체 흐름 검증은 남아 있다.

규격 표시·사진 두 축 비례 검사는 실제 3D 형상·절대 크기·상품 동일성 인증과 별도다. 특허는 출원 상태이며 명세서·청구항 전체 반영 완료를 주장하지 않는다.
