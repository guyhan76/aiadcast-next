# 본체 가로·높이만 제공된 제품

곡면 모니터처럼 본체 가로·높이만 확인된 제품은 `frontal` 규격 형식을 사용한다. 전자제품도 기존 직육면체/평면/원통 선택을 강요하지 않고 두 축만 입력·저장·전달한다. 남아 있는 이전 깊이 입력은 요청에 포함하지 않는다.

- 형상은 `unresolved`, 결과 검증은 false로 유지한다. 깊이·곡률·받침대 크기를 추정하거나 가짜 박스/평면 구조 가이드를 보내지 않는다.
- 원본은 외관뿐 아니라 확인된 곡면·받침대 구조의 참고 자료다. 본체 너비·높이의 치수선은 해당 본체 경계에 맞추며 받침대 포함 전체 높이로 바꾸지 않는다.
- 표시 없음/본제품/동일 제품 작은 사진 선택과 사람의 결과 검수는 유지한다. 정면 평면 자동 보정과 전체 외곽 자동 비례 검사는 적용하지 않는다.
- API의 치수 계약·결과 해시·새로고침 복구를 로컬 대체 provider로 검증한다. 이 테스트는 실제 AI 품질 검증이 아니다.

실제 상품 생성은 원본 파일의 직접 검토와 승인된 총비용 상한 확인 후에만 실행한다. 가격표의 예상 비용이나 앱 예산 예약을 provider의 요청별 비용 상한으로 설명하지 않는다. 이번 준비 단계에서 유료 생성·운영 배포는 실행하지 않았다.
