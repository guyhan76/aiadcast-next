# 자동차 광고 품질 기준

사용자가 제시한 자동차 광고 이미지를 육안으로 분석해 정한 제작·검토 기준이다. 참조 이미지의 광고주, 차종, 월 납입액, 할인, 출고·인증 주장은 다른 고객 광고의 사실 정보로 복사하지 않는다. 첨부 원본을 저장소에 복제하지 않았다.

## 기준 이미지에서 가져올 완성도

| 요소 | 제작 기준 | 사람이 확인할 항목 |
| --- | --- | --- |
| 차량 | 차량 전체가 크게 보이는 자신 있는 구도와 실사에 가까운 재질 | 원본과 모델·연식·트림·그릴·램프·휠·색상 일치, 차체·타이어·접지·원근 왜곡 여부 |
| 시선 순서 | 차종·핵심 문구, 주요 조건, 차량이 즉시 구분되는 크기와 대비 | 휴대폰에서 확대 없이 차종·핵심 제안이 읽히는가 |
| 가격 | 입력된 가격이 있을 때 강하게 강조하고 조건을 인접 표시 | 금액·통화·월/연 단위·보증금·계약 기간·주행거리 등이 원문과 같은가 |
| 혜택 | 입력된 장점을 짧은 문구와 그림으로 묶고 차량보다 작게 배치 | 없는 혜택·인증·실매물·출고 약속을 만들지 않았는가 |
| 장면 | 차체 반사광·배경·바닥·그림자가 하나의 환경을 이루는 조명 | 서로 다른 사진을 붙인 느낌, 검게 뭉개진 차체, 부자연스러운 반사 여부 |
| 비율·문구 | 정사각형과 세로형에서 각각 읽기 좋게 재배치 | 오탈자·잘림·과도한 작은 글자·매체 UI 가림 여부 |

금색 숫자, 파란 제목, 고급 건물, 하단 다섯 칸은 선택 가능한 표현이다. 모든 자동차에 같은 색·차종·다섯 칸을 강제하지 않는다. 세로형에서 다섯 칸이 작아지면 재배치하고, 사실 정보가 적으면 칸 수를 줄인다. 가격이 없으면 가격 영역을 만들지 않는다. 정해진 글자 수를 넘었다고 계약 조건이나 직접 입력 문구를 생략하지 않는다.

## 구현 범위

- 생성 서버의 완성형 광고 경로에 자동차용 구도·정보 순서·차량 일관성·혜택 묶음·비율별 배치 지침을 추가했다.
- 자동차·모빌리티 분류와 차량 대상임이 명시된 리스·렌탈 요청에 적용한다. 리스·렌탈 판별은 입력 단어에 따른 제한적인 규칙이며 모든 차량명·언어를 인식하는 의미 분석기가 아니다.
- 기존 상품 사실, 직접 문구, 연락처 표시와 CTA 선택을 유지한다. 사진 전용 구버전 요청과 원본 보존용 배경 생성에는 완성형 자동차 광고 지침을 넣지 않는다.
- 모델, 고품질 설정, 1회 생성 수량, 공급사 예산 및 무료 서버 설정은 변경하지 않았다.
- 서버 코드 변경이다. 기존 APK 설치만으로 적용되지 않으며 해당 서버 버전 배포가 필요하다.

## 실제 비교 전까지의 한계

이 변경은 제작 지침을 강화한 것이며, 기준 이미지 이상의 결과를 이미 생성했다는 뜻이 아니다. 자동 한글 검수, 차량 동일성 검출, 레이어 편집 또는 자동 재생성 기능을 새로 구현한 것이 아니다. 출원 내용 전체의 구현·권리범위 충족이나 기보 심사 통과를 증명하지 않는다.

검증 시 같은 차량 원본, 확정 문구·조건, 비율을 외주 앱과 신규 앱에 각각 입력한다. 최초 결과부터 보관하고 재생성 횟수·총 비용·소요 시간도 기록한다. 좋은 결과만 골라 안정적인 품질로 설명하지 않는다. 차량 또는 가격·조건 오류는 외관이 좋아도 사용 확정하지 않는다. 가격 없는 자동차 광고, 차량 리스 광고, 1:1·9:16 결과를 각각 검토한다.

현재 상태: 관련 도메인 검사 37건 통과. 자동차와 차량 리스·렌탈의 정사각형·세로형 요청, 확정 문구 보존, 다른 업종과 사진 전용·원본 배경 경로의 분리를 확인했다. 이 검사는 요청과 코드 동작의 확인이며 이미지 품질 검사가 아니다. 실제 생성 비교·서버 배포·신규 APK 제작은 이번 변경에 포함되지 않는다.
