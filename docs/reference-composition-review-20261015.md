## 보완한 코드

`server/openai-image-adapter.mjs`의 완성형 광고 경로를 보완했다.

- 고정 사진 중심 구성 대신 사진 또는 타이포그래피 중 하나의 중심을 허용한다.
- 브랜드 여백형, 제공 혜택 강조형, 서비스 상징형, 실제 사용·화면 설명형, 과정·기능 그룹형을 내부 구성 대안으로 제시한다. 사용자에게 추가 프리셋 선택을 요구하지 않는다.
- 문구가 짧으면 여백을 유지하고, 길면 장식과 패널 수를 줄인다. 확정 문구나 조건을 누락하지 않는다.
- 자동차는 제공된 측면 또는 사선 구도를 존중한다. 어두운 배경·금속 글자·네온을 모든 광고의 기본값으로 강제하지 않는다.
- 외부 브라우저·플랫폼 UI는 제외하고 실제 광고 대상인 앱·단말기·교육 자료는 실제 자료로 지정된 경우에 활용한다. 디자인 참고 화면에서 남의 데이터나 기능을 가져오지 않는다.
- 교육·소프트웨어 광고에서 근거 없는 대시보드·실적·수강생 작품·자동화 기능을 만들지 않도록 한다.

기존 사실 정보, 사진 용도, 직접 입력 문구, 연락처 표시, 선택적 CTA, 규격·비율 규칙을 유지한다. 모델·요청 수·품질 설정·예산은 변경하지 않았다. 생성 지침 revision만 `v14-composition`으로 변경했다. 이 변경은 서버 코드이며 0.2.23 APK 자체를 다시 빌드한 것이 아니다.

## 검증 결과와 남은 확인

기존 도메인 검사 24건 통과: 업종별 요청, 자동차 조건, 완성형 광고, 사진 용도·전달, 이미지 연출 지침. 모의 이미지 공급사 검사를 포함하며 유료 이미지 호출은 하지 않았다. PostgreSQL 파생 코드 일치 검사도 통과했다. 검사 통과는 생성된 이미지의 시각 품질 판정이 아니다.

실제 비교에서는 같은 사진·문구·조건·비율을 기존 앱과 업데이트 앱에 넣고, 생성 횟수를 함께 기록한다. 다음 항목을 각각 확인한다.

1. 실제 상품·공간·화면의 동일성.
2. 한글, 숫자, 조건, 연락처의 정확성과 누락 여부.
3. 휴대폰 크기에서 제목·주요 조건의 가독성.
4. 조명·재질·구도·여백과 정보의 위계.
5. 서로 다른 업종과 목적에서 구성의 적합성.
6. 재생성 횟수·소요 시간·실제 공급사 비용.

원본 합성은 생성형 사진 재현과 별도 비교한다. 서버 배포, 실제 이미지 비교, Android 실기기 사용, 기존 Play 앱의 패키지·서명 확인과 등록은 아직 이 기록의 완료 범위에 포함되지 않는다. 특허 전체 구현·기존 앱 대비 우월성·기보 승인 여부를 이 변경만으로 주장하지 않는다.
