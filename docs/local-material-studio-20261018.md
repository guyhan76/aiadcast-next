# 규격 제품 재질 렌더 · 로컬 광고 합성

PR #20 최종 `bb3fdb967071bc9443f2d29610770b8e64d8dfd4` 위의 `feat/local-material-ad-studio-20261018` 후속 작업이다. PR #18 홈페이지 작업과 독립이며 운영 배포하지 않았다.

## 실제 연결한 경로

- `node server/material-render-server.mjs`와 `npm run dev`를 실행하고 `http://127.0.0.1:5180/?materialStudio=1`을 연다. Blender 4.3.2 로컬 설치가 필요하다. API는 127.0.0.1:8792만 듣고 운영 모드에서 실행을 거부한다. 운영 beta 서버는 이 모듈을 가져오지 않는다.
- 치수 → 비동기 단일 Blender 작업 → 고정 본체·카메라의 투명 PNG와 투영 축 manifest → 상품이 없는 절차적 스튜디오 배경·사용자 문구·축별 치수선 → 검토 후 동일 canvas PNG 저장으로 연결했다.
- 진행률은 Blender 샘플 진행을 반영하며 작업 취소, 실행 파일 없음/실패, 서버 재시작 후 복구 불가를 표시한다. 실패 시 자동 재실행하지 않는다. 탭 내 새로고침은 작업 ID와 문구·치수를 복원한다. 서버 메모리 작업은 최대 5건/1시간이며 서버 재시작 후 사라진다. 파일은 작업 완료·취소 시 정리한다.
- 치수가 바뀌면 이전 결과를 숨기고 새 렌더가 필요하다. 문구/표시를 바꾸면 같은 렌더를 다시 합성하고 검토 확인을 해제한다. 미리보기 픽셀을 그대로 내보낸다.
- 박스 500×350×200 mm를 첫 사례로 하고 직선 원통은 지름·높이를 사용한다. 10~2000 mm, 최대 축 비율 10까지의 로컬 프로토타입 범위다. 가방·의류를 직육면체로 대체하지 않는다.

## 품질과 참조사진의 한계

입력 치수가 참조 형상보다 우선한다. 현재는 절차적 크라프트/원통 재질이고 원본 사진의 인쇄, 로고, 표면 질감, 고유 부품을 복원하지 않는다. 박스 두께·덮개 각도·길이는 명시적 예시다. UI와 PNG 모두 절차적 재질 시안이라고 표시한다. 첫 합성은 상품이 전혀 없는 코드 생성 배경을 사용한다. 기존 광고에 들어 있던 다른 상품 위에 덮어 씌우지 않는다.

이 경로는 실제 Blender 결과를 앱에서 합성·저장하는 로컬 시안이다. 프리미엄 실사 광고 품질 승인, 실제 참조 제품 동일성 검증 또는 운영 제공 완료가 아니다. 기존 사진 생성/원본 합성 경로는 유지한다. 치수 없는 상품에 임의의 규격을 만들지 않는다.
