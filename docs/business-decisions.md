2026-10-10 사용자가 가격을 우선 확정하고 모바일 앱 개발을 진행하도록 지시했다. 실제 스토어 상품 등록·결제 활성화 완료를 의미하지 않는다. 앱 언어·광고 문구 언어·결제 국가와 통화를 구분한다.

새 광고 시안 하나를 제작 횟수 1개로 센다. 같은 광고의 직접 문구·가격·규격 표시 수정, 단순 비율 변경과 재다운로드를 신규 AI 생성으로 차감하지 않는다. 새 AI 시안·배경·영역 생성은 별도 실제 연산 비용이 발생한다. 릴스용 정지 이미지를 영상으로 설명하지 않는다.

장당 350원을 가격 설계의 원가 기준으로 사용한다. 실제 측정으로 보장된 최대 청구액은 아니며, 실제 사용량과 재처리 비용을 기록하여 운영 상한 목표를 검증한다.

## 월 필수 현금지출: 22,000,000원

사용자가 이전 20,000,000원 기준을 아래 금액으로 변경했다.

| 항목 | 월 금액 |
|---|---:|
| 인건비 | 11,600,000원 |
| 고문료 | 2,500,000원 |
| 차량 렌트·유지관리 | 800,000원 |
| 사무실 | 820,000원 |
| 세무사 | 160,000원 |
| 기술보증기금 은행이자 및 원금상환 | 3,500,000원 |
| 기타비용 | 620,000원 |
| 마케팅 및 연구개발 비용 | 2,000,000원 |
| **총 필수 현금지출** | **22,000,000원** |

월 2,200만원은 충당해야 할 현금지출이다. 사용자는 이후 모든 수수료와 비용 차감 후 매출 대비 약 30%의 수익을 목표로 필요한 매출 계산을 요청했다. 이는 별도로 고정 이익 2,200만원을 추가하라는 지시가 아니다. 원금·이자 구분 전 보수적 계획은 부가세 제외 매출 대비 현금잉여율 30%로 산정하며, [계산 근거](margin-target-2026-10-10.md)를 따른다. 마케팅·연구개발 200만원은 합산 금액이며 두 항목에 각각 200만원을 넣거나 이전 마케팅 100만원·개발비 100만원을 다시 더하지 않는다.

대출 이자와 원금의 세부 금액은 아직 제공되지 않았다. 원금 상환은 회계상 영업비용이 아니다. 이자가 영업외 비용으로 분류되는 경우도 있으므로 전체 2,200만원을 회계상 영업비용으로 보고 영업이익률을 계산하지 않는다. 당분간 **현금지출 충당 목표·현금 잔액**으로 표현하고, 영업이익은 원금·이자와 다른 회계 항목을 분리한 뒤 산출한다.

과거 `release/` 분석 파일의 2,000만원 기준 계산은 당시 가정의 기록이다. 앞으로 가격·재무 계획의 기준은 이 문서의 최신 사용자 확정값을 따른다. 확정되지 않은 결제 수수료·정산비를 실제 요율로 표시하거나, 이미 원가/고정비에 포함한 지출을 중복 계산하지 않는다.

## 출시 방향

외주 MVP와 분리한 `guyhan76/aiadcast-next`를 개발한다. 한국에서 초기 품질을 검증하면서 처음부터 한국어와 영어를 지원하고 영어권 판매를 준비한다. 글로벌 시장의 크기가 구매건수나 수익을 보장한다고 주장하지 않는다. 신규 앱의 실제 AI·계정·결제·Android 설치·기기 테스트·스토어 승인은 각각 검증해야 한다.
