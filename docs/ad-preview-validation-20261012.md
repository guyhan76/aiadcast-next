# 완성 광고 사전 검토 수정 · 2026-10-12

## 발견한 문제와 수정

실제 Render/Supabase 배포, 관리자 로그인, AI 생성 사진 수신까지 사용자 화면에서 확인했다. 생성 결과 검토에는 공급사 사진만 표시되어 광고카피·가격·규격·연락처를 사용 확정 전에 확인할 수 없었다. 상품 설명이80자를 넘으면 초기 광고 문구가 입력 설명 대신 업종 기본 문구로 바뀌었다.

- 사진의 해시와 원본·규격 호환성을 확인한 뒤 내보내기와 같은 `render`로 광고 전체를 합성한다. 완성 광고를 확대 검수하고, 합성 오류가 없으며 검토를 확인한 때만 사용 확정할 수 있다.
- 문구·규격 표시·비율을 바꾸면 같은 사진으로 미리보기를 재합성한다. 새 공급사 호출이나 이용권 차감은 없다. 변경된 광고는 다시 확인해야 한다.
- 긴 설명에서 제공한 특징과 수량/가격을 광고 문구에 반영한다. 단일 가격은 별도 큰 글자로 표시하며, 복수 가격은 원래 문맥을 유지한다. 사용자가 직접 편집한 문구를 덮어쓰지 않고 기존80자 초과 기본 문구만 검토 시안에서 복구한다.
- 새 제작에서 규격 형식을 선택하면 규격 표시를 켠다. 이후 표시를 끌 수 있고, 저장된 작업의 기존 표시 선택은 유지한다. 결과 검토에도 규격 표시 스위치를 제공한다.
- 캠페인 제목에 한글 명조체를 사용하며, 고객 입력 글자도 지원하도록 전체 문자 범위의 폰트를 연결한다. 출력 사진의 원본 파일과 공급사 이미지 메타데이터는 보존한다.

## 검증 범위

- 도메인222건 통과: 새 우체국3호박스 설명·가격 보존, 미리보기/적용 프로젝트의 원본·연락처·규격 보존, 기존 기본 문구 복구, 수동 편집 보존과 오래된 규격 시안 거부 포함.
- TypeScript/Vite/단일 HTML 빌드, PostgreSQL 변형 일치 검사 통과.
- 실제 Canvas 렌더러를 Native Canvas에서 실행해1080×1920 출력, 상품명·후킹·제공 특징·10개19,800원·340×250×210mm·회사·전화·이메일·홈페이지의 그리기와 영역 오류0건을 확인했다. 검토와 적용 후 출력의 PNG 바이트가 같다. 제공된 생성 결과 화면에서 사진을 가져온 검증 예시이며, 추가 OpenAI 호출은0회다.
- Playwright에는 완성 광고 검토 전 미차감, 규격 표시만 수정 시 미호출, 검토 PNG와 내보내기 일치 및 파일 해시 불일치 시 차감 차단 시험을 추가했다. 현재 실행 환경에 Chromium 실행 파일이 없어 이 브라우저 시험은 실행하지 못했다.

## 실제 배포에서 이어서 확인

기존 작업에서 같은 생성 사진을 다시 읽어 완성 광고가 나타나는지 확인한다. 확대 검수 후 사용 확정하고 PNG를 내려받아 문구·사진·규격 표시를 비교한다. 실제 공급사 사용량 대조, 이메일 수신, 결제사 시험 승인은 별도다.

규격 숫자가 광고에 표시되는 것과 사진 상품의 실제3D형상·절대 크기 검증은 다르다. 이 수정은 광고 합성과 검토 흐름을 개선하며, 출원 청구항 전체 구현이나 실물3D검증 완료를 주장하지 않는다.
