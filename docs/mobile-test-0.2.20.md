# aiadcast Preview 0.2.20 휴대폰 시험

2026-10-11 · `com.selluplabs.aiadcast.next.preview` · versionCode 22.

## 설치

`aiadcast-preview-0.2.20.apk`를 실행해 기존 Preview를 업데이트한다. 0.2.18/0.2.19와 같은 개발 서명이다. 기존 앱을 삭제하지 않는다. ZIP에는 같은 APK 한 파일이 들어 있다. 이번 빌드의 실제 휴대폰 설치는 아직 확인하지 않았다.

## 서버 없이 가입부터 내보내기까지

1. 홈 상단 **테스트 계정 · 서버 연결 → 서버 없는 체험 시작**을 누른다.
2. 이메일 형태의 이름으로 체험 계정을 만들고 **체험 인증 완료하기**를 누른다. 실제 이메일 소유 확인이나 메일 발송은 하지 않는다.
3. **내 이용권**에서 이용권을 선택한다. 모의 결제 실패·취소는 잔액을 늘리지 않고, 성공은 한 번만 추가한다. 실제 청구·카드 입력·결제사 승인은 없다.
4. 광고 만들기에서 사진 여러 장을 한 번에 추가하고 상품 설명과 선택적 규격을 입력한다. 사진 첨부 제한은 기존과 같은 최대 10장/총 10MB다.
5. 편집기의 **기기 내 체험 합성**에서 시안을 요청한다. 준비된 이미지 또는 원본 사진과 배경을 기기 안에서 합성한다. 외부 AI 생성·API 비용은 발생하지 않는다. 원본 모드는 사진을 같은 배율로 확대·축소한다.
6. 시안을 반려하면 예약 이용권을 복원한다. 확인 후 사용 확정할 때만 1개 차감한다. 재적용은 다시 차감하지 않는다.
7. **PNG 내보내기**로 저장한다. 체험 합성임을 이미지 하단에 표시한다. 같은 체험 이름으로 다시 로그인하면 이용권과 작업 기록을 확인할 수 있다.

체험 계정·결제·시안은 이 기기에 보관한다. 실제 서버 계정, 이메일 인증, 결제 연동, 여러 기기 동기화와 별도다. 체험 종료 후 서버 모드에는 유효한 HTTPS 백엔드가 필요하다.

## 일반 상품 비례 자동 검사

- 선택한 상품 규격은 가로·세로·높이의 **전체 외곽**을 뜻한다. 손잡이 등을 제외한 본체 치수라면 사진 전체 윤곽과 직접 비교할 수 없다.
- 단색 또는 투명 배경이며 상품 전체가 보이는 정면·측면·윗면 사진을 준비한다. 앱이 상품 외곽을 자동 측정한다. 사용자는 촬영면과 원근 왜곡이 적음을 확인한다.
- 정면은 가로/높이, 측면은 세로/높이, 윗면은 가로/세로를 비교한다. 직육면체는 세 쌍을 모두 확인해야 `선택한 촬영면 비례 일치`로 표시한다. 한 면만 있으면 `일부 촬영면만 확인됨`이다.
- 규격 대비 비율 차이가 10%를 넘으면 차이를 표시하고 새 생성 요청을 막는다. 이 값은 개발 비교 기준이며 제조 공차가 아니다. 규격·촬영면·전체 외곽 조건을 다시 확인한다.
- 복잡한 배경, 여러 상품, 가장자리 잘림, 불안정한 윤곽, 사선 사진은 판정을 보류한다. 임의로 성공 처리하거나 일반 상품을 규격대로 변형하지 않는다.
- 창작 시안도 촬영면 선택 후 검사할 수 있으나 광고 배경에 섞인 상품은 분리되지 않을 수 있다. `자동 검사 기록 저장`으로 사진 해시·규격·비율·누락 면·한계를 JSON으로 저장한다.

사진의 두 축 비례를 비교하는 기능이며 카메라 보정, 실제 깊이, mm 절대 크기, 동일 상품 여부를 증명하지 않는다. 보고서의 `geometryVerified`, `identityVerified`, `externallyCertified`는 false다. 출원 명세서·청구항이 없어 특허 청구항 전체 반영 완료도 표시하지 않는다.

## 홈 광고사례

화장품, 패션소품, 여성패션, 주얼리, 소형가전, 여행, 호텔, 보험, 병원, 리스·렌탈 10개를 새로 생성한 1080×1920 사진으로 교체했다. 상품 메인 사진과 디테일 컷을 함께 사용한다. 한글·영문 문구는 사진에 생성하지 않고 앱에서 합성하며 확대 보기·키보드 이동·스와이프·자동 넘김을 유지한다. 예시는 가상의 상품·서비스이며 실제 고객 납품·실적 자료가 아니다.
