# Completed advertisement history (0.2.51 / code 53)

Opening a stored project previously hid its completed image when current input compatibility keys differed. Pending-job recovery intentionally excludes accepted jobs, so a missing local result also left only the generation controls. This does not prove that any particular production image was deleted.

The consumer result screen now provides a separate historical-original viewer when the current result is unavailable. It verifies and displays the locally saved complete-ad bytes independently of current input keys. If local bytes are missing or invalid, it reads the saved job ID, or accepted complete-ad history scoped to the exact project ID, through the existing authenticated GET endpoints. Detail IDs, project IDs, accepted status, composition, image hashes and image dimensions are checked before display. Multiple history candidates can be selected explicitly. No recovered result overwrites current inputs or is accepted again.

Viewing, retrying and downloading history do not POST generation, accept, reservation or payment requests. New generation remains separate and retains its existing credit rules and pending-request protection. Missing files, access denial and invalid artifacts produce an unavailable message rather than a fabricated replacement. Saved original images exclude subsequent local text edits and dimension overlays; this distinction is displayed. Compatible results retain their current editing/export workflow.

Client-only change; no server deployment, database mutation, paid provider call or dimension-placement redesign. Existing production server e6e9d3299ff5d978d0c661ed0a457fab286551fd remains the deployment baseline. Real monitor output retention/recovery has not been verified.

Validation: targeted domain tests 38 passed; historical-original browser checks 20 passed across desktop/mobile, local text editing 10 passed, existing generation recovery 8 passed and pricing 4 passed. History checks cover byte-exact downloads, reload, unchanged stored projects, compatibility mismatch, missing/corrupt local bytes, saved IDs outside the history list, missing server artifacts, foreign project list/detail responses, access denial and hash mismatch. Mock reopen/retry paths assert zero API writes. Android signing/unit/lint/build evidence accompanies the release artifact. No full browser suite is claimed here.
