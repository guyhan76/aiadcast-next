# 금융·부동산·교육·자동차 광고 추가 품질 기준

사용자가 제공한 9개 이미지를 대화에 표시된 내용으로 분석했다. 디자인과 광고 구성의 참고이며, 이미지 속 금융 조건·분양 조건·성과 주장 등의 사실성을 검증한 문서가 아니다. 첨부 원본을 저장소에 복제하지 않았다.

앞의 세 이미지는 모바일 웹 화면 캡처다. 휴대폰 상태 표시줄, 브라우저 메뉴, 페이지 메뉴·슬라이드 점·외부 버튼은 광고 이미지에 그대로 복제하지 않는다. 마지막 이미지 등의 CTA도 사용자가 요청한 경우에만 광고에 넣는다. 이미지 안의 버튼 모양이 실제 클릭·신청 기능의 구현을 뜻하지 않는다.

## 이번 코드 변경

완성형 광고 서버 경로에서 사진 외에도 적절한 일러스트·그래픽 구성을 선택할 수 있도록 지침을 수정했다. 금융·부동산·교육 서비스에는 목적과 제공 자료에 따라 실사형, 상징 그래픽형, 조건 강조형, 인물·교육 내용 중심 구성을 선택하도록 추가했다. 별도의 소비자 필수 선택 항목은 늘리지 않았다.

확정 문구·숫자·연락처와 CTA 선택을 유지하며, 참조 업체의 금리·한도·등록번호·규제 관련 표현·분양 조건·연락처를 다른 광고에 차용하지 않도록 했다. 이는 공급사에 전달하는 지침이며 생성 후 자동 검수 기능이 아니다. 예시의 실제 조건은 이번 변경의 기본 문구나 가격으로 저장하지 않았다.

모델·생성 수량·예산·무료 호스팅 설정은 유지했다. 서버 배포 전에는 설치된 앱의 실제 생성 결과에 반영되지 않는다.

## 아직 별도로 구현·검증할 부분

- 여러 상품을 한 장에 비교: 현재 기본 요청은 한 상품 또는 한 서비스이며 추가 참조는 같은 대상의 세부·다른 각도다. 여러 차종의 이름·이미지·가격을 각각 연결하는 데이터 구조와 화면, 결과 검증은 이번 변경에 포함하지 않았다.
- 같은 디자인으로 시리즈 제작: 여러 장 간 구도·서체·색상 유지와 항목별 교체, 일괄 저장은 별도 기능이다. 참조 썸네일을 한 이미지에 복제하는 것으로 완료 처리하지 않는다.
- 정확한 한글·숫자 및 편집: 완성형 AI 이미지에 포함된 글자의 오타가 자동 방지되거나 편집 레이어가 생기는 것은 아니다. 실제 결과 검수와 후속 편집 기능 검증이 필요하다.
- 성과: 이미지의 외형만으로 클릭률·상담 전환율·매출을 판단할 수 없다. 실측 전에는 성과를 주장하지 않는다.

## 합격 판정

휴대폰에서 핵심 제목과 조건이 읽히는지, 원본 상품·공간·인물이 일치하는지, 한글·가격·연락처가 정확한지, 조건이 빠지지 않았는지, 참조 화면의 UI가 섞이지 않았는지 확인한다. 업종이 달라도 같은 장면·색·배치만 반복하면 해당 사례의 요구를 충족하지 못한 것으로 본다. 개별 고객이 시리즈의 통일성을 요청한 경우에는 그 요청을 우선한다.

현재 상태: 관련 도메인 검사 37건 통과. 기존 48개 업종·한국어/영어 요청 처리, 확정 정보, 자동차 경로, 사진 전용·원본 배경 경로와 모의 공급사 전달 검사를 실행했다. 이는 코드 동작 확인이며 실제 이미지의 품질 판정은 아니다. 실제 AI 결과 비교·서버 배포·APK 재제작은 이번 변경에 포함되지 않는다.
