# aiadcast 대표자 주도 개발 검증 기록 — 2026-10-15

## 이번 변경과 확인한 범위

무료 Render + Supabase 시험 구성을 유지한다. 호스팅 유료 전환, 공급사 예산 증액, 실제 유료 이미지 호출, 운영 배포는 이번 변경에 포함되지 않는다.

현재 앱의 분류는 총 48개(실물 상품 19개, 서비스 29개)다. 이번 변경은 선택 목록을 늘린 것이 아니라, 이 분류에서 실제 공급사 요청으로 넘어가는 디자인 지침을 보완했다. `other`를 제외한 모든 기존 분류에 해당 업종 또는 업종군에 맞는 연출이 연결된다. 향후 모든 업종의 광고 품질이 검증됐다는 의미는 아니다.

- 포장재: 박스·쇼핑백·라벨·용기·파우치·비닐·기타 포장재를 구분한다. 싸바리박스를 골판지로, 파우치를 박스로 바꾸지 않도록 지시한다.
- 실물 상품: 식품·전자기기·패션·주얼리·뷰티·가구·산업재·자동차에 맞는 재질·조명·사용 장면을 전달한다.
- 서비스: 교육·음식점·카페·숙박·여행·운동·의료·부동산·금융·상담·기업 서비스에 맞는 연출을 전달한다. 서비스 요청에 박스 단면과 제품 치수 지시를 넣지 않는다.
- 서비스 사진: 실제 장소·사람·메뉴·장비를 확인하는 참고 자료로 사용한다. 자료가 없을 때 실제 사업장의 사진처럼 보이는 허구의 장소·직원을 만들어 사실로 제시하지 않도록 지시한다.
- 목적: 브랜드 소개, 제공 조건 안내, 과정·근거 설명에 따라 구성 지침을 구분한다. 사용자 문구·숫자·연락처와 요청한 CTA 여부를 유지한다.
- 출원 내용과 관련된 결과 정보: 이미지와 함께 제작 의도·타깃·추천 채널·중복 제거 검색어를 표시하고 사용 확정 후에도 유지하는 보완안을 포함한다. 세부 대응 관계와 구현 차이는 `image-quality-patent-review-20261015.md`를 따른다.

이 변경의 디자인 지침은 구현된 규칙과 프롬프트다. 자동 이미지 품질 판정, 완전한 상품 동일성, 정확한 실측 3D 복원, 특허 청구항 전체 구현을 증명하지 않는다.

## 대표자가 실제로 수행하고 기록할 3분 시연

1. 포장재 사례: 원본 사진, 규격, 재질, 확정 가격을 입력하고 광고를 생성한다. 사진·수치·인쇄·구조를 결과와 대조한다.
2. 서비스 사례: 사진과 규격 없이 교육 또는 서비스 설명을 입력하고 광고를 생성한다. 없는 시설·성과·자격을 지어내지 않았는지 확인한다.
3. 결과 설명: 광고와 함께 제작 의도, 타깃, 추천 채널, 검색어가 표시되는 것을 보여준다.
4. 재사용: 입력 정보를 수정하고 새 결과를 확인한 후 사용 확정·다운로드·다시 열기를 수행한다. 완성 이미지의 글자를 무료로 직접 수정할 수 있다고 설명하지 않는다.
5. 증거 보관: 코드 커밋, 입력 자료, 실제 결과, 소요시간, 수정 전후, 확인한 오류와 해결 내용을 함께 남긴다.

실제 생성이 실패하면 성공 화면이나 준비된 예시 이미지로 대체해 성공한 것처럼 설명하지 않는다. 실제 수행한 범위를 표시한다.

## 외주 앱과의 비교 기준

같은 상품 원본, 설명, 문구와 출력 비율을 사용한다. 상품 3종과 서비스 2종을 소규모 비교 대상으로 삼고, 각 조건에서 결과를 반복 생성해 좋은 결과만 선별하지 않는다. 무료 호스팅이어도 OpenAI 호출에는 비용이 발생하므로 기존 시험 예산 범위에서 먼저 시작하고, 예산 변경 없이 임의로 반복 호출하지 않는다.

판정 항목은 상품 동일성·규격 비례·글자 정확성·디자인 완성도·모바일 가독성·실사용 가능성이다. API 비용, 생성 시간과 오류도 기록한다. 실제 비교 전에는 외주 앱보다 우수하다고 표현하지 않는다.

## 사실에 근거한 기보 설명 방향

대표자가 직접 요구사항과 마케팅·포장재 지식을 정의하고, AI 개발 도구를 활용해 생성 지침·업종 분기·결과 활용 기능을 개선하는 방식으로 개발을 진행했다. 코드 변경 기록과 검증 자료가 있다. 실제 운영 역량은 대표자가 기능을 설명하고 오류를 재현·수정하며 실제 광고를 생성하는 시연으로 추가 입증한다.

이 기록은 개발 진행 증거이며, 과거 정보통신업 경력이나 독자 AI 모델 개발 실적을 만들어 주는 자료가 아니다. 실제 원격 생성·모바일 시연을 마친 범위에서 설명을 갱신한다.
