# 설명으로 만드는 상품 AI 예시

기본 선택은 ‘내 상품 사진으로 만들기’다. 사용자가 ‘설명으로 예시 만들기’를 선택한 실물 상품만 사진 없이 생성한다. 서비스의 기존 사진 선택 흐름과 기존 프로젝트 기본값은 유지한다.

## 데이터와 표시

- 전환 시 원본·추가 사진, 사진별 용도, 설명과 숫자 규격을 삭제하지 않는다. 사진 모드로 돌아가면 다시 사용한다. 예시 모드의 생성 본문·참조 지침·원본 해시에는 보관 사진을 넣지 않는다.
- `generation.inputMode=text-example`을 저장하고 요청/서버 작업/완료 결과에도 명시한다. 서버는 이 명시적 선택 없이 사진 없는 실물 상품 요청을 계속 거부한다. 예시 요청에 사진을 몰래 포함하면 공급사 호출 전에 거부한다.
- 서버가 `generation.textExamples=true`를 알리지 않으면 새 기능의 요청을 보내지 않는다. 현재 운영 3cc9318에는 이 기능이 없으므로 새 UI만 배포해 우회하지 않는다.
- 예시는 완성 광고 경로와 `/v1/images/generations`를 사용한다. 이미지 편집 경로에 숨긴 사진을 보내지 않는다. 실제 상품·인쇄·색상·물리적 규격을 검증하거나 재현했다고 설명하지 않는다.
- 숫자 규격 입력·숫자 표시는 별도로 유지한다. 사진 기반 형상 제어, 직접/작은 사진 치수선, 평면 보정 등은 차단한다. 사용자가 해당 제어를 명시적으로 끄거나 사진 모드로 돌아가도록 안내한다.
- 검토 화면과 PNG에 ‘AI 예시 · 실제 상품 재현 아님’을 표시한다. PNG에서는 본문 전체를 비례 축소하여 별도 하단 띠에 표시하므로 원본 글자를 덮거나 상품을 늘이지 않는다. 미리보기와 내려받기는 같은 렌더 경로다.
- 동일 요청·응답 유실은 기존 작업을 조회하며 자동으로 새 과금 요청을 만들지 않는다. 서버 이용권·비용 제한을 유지하고, 클라이언트도 준비 중 중복 호출을 잠근다.

## 검사 범위

단색 이미지·대체 공급사로 요청 계약, 사진 제외, 서버 검증, 중복 요청/이용권, PostgreSQL 재시작·소유권, 예시 표시·PNG 일치, 모바일/데스크톱 모드 전환·새로고침·응답 유실을 검사한다. 단색 이미지는 품질 증거가 아니다. 실제 유료 생성, 배포, 신규 키·예산 변경은 실행하지 않았다. 최종 SHA와 검사 수치는 해당 draft PR에 기록한다.
