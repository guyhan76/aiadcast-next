# 승인된 규격·화면 개선 — 2026-10-11

신규 제작의 상품 크기는 cm 기본, mm·inch 선택으로 바꿨다. 가로/세로/높이, 지름/높이, 평면 형식을 유지하고 광고 규격 표시 기본값은 OFF다. 입력 규격은 표시 여부와 별개로 생성 참고값으로 전달한다.

내부 데이터와 생성 API·형상 계산은 mm다. `dimensions.displayUnit`만 추가했고 기존 필드·버전은 유지했다. 없는 경우 mm로 해석해 기존 프로젝트 값을 보존한다. 단위 변경은 원본 수치에 손대지 않는다. 소수 inch를 정확히 환산하기 위해 십진 정수 계산을 사용하고 API·형상·생성 결과 메타데이터 검증이 mm 소수 8자리까지 받도록 통일했다. 사용자 입력은 소수 6자리까지이며 잘못된 입력은 빈 canonical 값으로 처리해 생성·출력을 막는다. 단위 변경만으로 AI 결과를 무효화하거나 재생성하지 않지만 게시글의 규격 문구는 새 단위로 갱신한다.

내 프로젝트는 제목·새 광고·검색·큰 광고 미리보기·이름·날짜로 구성했다. 생성 전에는 참조사진을 유지한다. 편집 가능한 결과가 있으면 실제 편집 구성을 미리본다. 기기 저장과 백업 설명은 하단에서 펼친다. 작업 전환 시 저장 실패 보호와 중복 없는 편집 중 복구를 유지했다.

사용 안내는 세 단계와 시작 버튼 하나로 줄였다. 사진/규격, AI 연결, 재편집/백업, 출력 비율, 가입/결제의 상세 설명은 펼침 항목에 둔다. 한국어·영어를 제공한다.

## 회원가입·결제 화면의 실제 상태

사용자는 이메일 방식에 동의했다. `#signup`, `#login`은 비밀번호 없이 이메일 인증으로 시작하는 화면이다. 이메일 입력 형식을 확인하되 입력 정보는 저장·전송하지 않는다. 현재 초대코드 인증 서버에는 이메일 인증·메일 발송·계정 복구 기능이 없어 인증 실행 버튼은 비활성화했다. 기존 비공개 초대코드 테스트 로그인은 그대로 유지한다.

`#checkout`은 확정 가격 3개/6,900원, 10개/19,900원, 30개/49,900원을 사용한다. USD는 기존 승인 카탈로그의 $4.99/$14.99/$39.99이며 세금 별도 안내를 유지한다. 상품 선택과 주문 확인은 가능하고 결제 실행은 비활성화했다. 카드·계좌를 받거나 구매 완료·이용권 충전·회원가입 성공을 모의 성공으로 표시하지 않는다.

후속 연결에 필요한 것은 운영 이메일 인증 제공자/발신 설정과 검증된 스토어 또는 결제 제공자의 서버 결제·영수증·취소/환불 처리다. 프런트 가격 데이터만으로 고객에게 청구하지 않는다. 이번 작업을 실제 회원가입·결제 개통으로 해석하지 않는다.
