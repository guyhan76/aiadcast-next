# 앱 색상 정리 · 2026-10-10

흰색 #ffffff, 기존 로고 주황 #b65a35, 블랙 #171717, 연회색 #f3f3f3을 공통 팔레트로 적용했다. 본문 보조 글자 #666666과 구분선 #dedede는 무채색 보조 단계다. CSS 공통 변수로 홈·제작·프로젝트·안내·편집·계정·요금·팝업의 베이지/카키 색을 교체했다. 상품 사진과 광고 표지·직접 선택한 광고 색은 변경하지 않는다.

Android 시작 배경·상태 표시줄·탐색 배경과 웹 theme-color를 흰색으로 맞췄다. 휴대폰 프로젝트 화면에서 새 광고 버튼이 두 줄로 잘리지 않도록 최소 폭을 확보했다.

390px 주요 다섯 화면과 1440px 홈을 브라우저에서 확인했다. 배경 RGB(255,255,255), 가로 넘침 없음. 공개 생성 서버 연결 상태는 기존과 같다. 실제 휴대폰 설치 및 시스템 표시줄은 APK 업데이트 후 별도 확인한다.

검증 결과: studio/ui-language 모바일·PC 18개 통과, Android Java 테스트 2개 및 lint·빌드 통과. APK dist assets 144개 바이트 일치 및 기존 서명 확인. 버전 0.2.12-dev, versionCode14.
