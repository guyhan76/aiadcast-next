# 사진 활용 방식과 참조 용도 업데이트

2026-10-15 대표 요청: 실제 사진 반영과 디자인 참조 선택을 기본 제작 흐름에 넣고, 개선 결과를 비교한 후 Google Play 등록과 대표 주도 개발 입증을 진행한다.

## 구현한 변경

- 기본 제작 화면에서 `AI로 새 광고 생성`과 `실사 그대로 사용`을 선택한다. 제출 시 원본 모드를 창작 모드로 덮어쓰던 처리를 제거했다.
- 첨부 사진마다 `실제 상품·공간` 또는 `디자인 참고`를 지정한다. 최대 10장 및 전체 10 MB 제한은 유지한다.
- 용도는 파일 해시를 기준으로 저장한다. 사진 순서 변경·삭제·JSON 복원 후에도 다른 사진에 용도가 잘못 붙지 않는다. 이전 프로젝트는 실제 상품·공간 사진으로 해석한다.
- 생성 요청과 서버 검증에 사진 용도를 전달한다. 디자인 참고가 먼저 업로드되어도 실제 대상 사진의 번호를 정확히 지시한다. 디자인 참고의 상호·가격·조건·연락처·상품·인물을 광고 사실로 복사하지 않도록 구분했다.
- 실제 상품 광고에는 실제 상품 사진이 필요하다. 서비스는 디자인 참고만으로도 개념 광고를 요청할 수 있지만 해당 사진을 실제 사업장·직원으로 주장하지 않는다.
- 원본 모드는 대표 사진 전체를 별도 합성하며 사진을 이미지 공급사에 보내지 않는다. 자동 배경 제거 기능은 아니다. 디자인 참고 사진은 이 모드의 생성에 사용하지 않는다.
- 사진 용도를 바꾸면 호환성 키가 달라져 이전 생성 결과를 그대로 확정 결과로 재사용하지 않는다. 디자인 참고는 실제 상품 비례 점검에서 제외한다.
- 원본 모드도 간단한 결과 확인·사용 확정·PNG 저장 화면으로 이어지며, 직접 입력한 광고 문구와 빈 설명을 보존한다.
- 서버가 사진 용도 지원을 명시하지 않으면 디자인 참고 생성 요청을 보내지 않고 업데이트 필요 안내를 표시한다. 구버전 서버가 사진 용도를 무시한 채 이용권을 소모하는 것을 방지한다.

## 검증

관련 도메인 테스트 53개 통과: 사진 역할 저장/복원, 순서·삭제, 이전 결과 무효화, 서버 검증, 실제 multipart 사진 바이트와 번호 대응, 원본 사진 공급사 미전송, 기존 생성·과금·업종 경로. 공급사 호출은 모의 응답을 사용했다. 실제 광고 품질 판정이 아니다.

웹 빌드와 PostgreSQL 공통 규칙 일치 검사를 통과했다. PC·모바일 브라우저 검사 12건은 Chrome의 프로필 소켓 생성이 실행 환경에서 거부되어 화면 실행 전에 중단됐다. UI 통과나 실제 Android 설치로 계산하지 않는다. 해당 두 신규 흐름 검사는 `tests/consumer-flow.spec.ts`에 남겼다.

서버 생성 지침 revision은 `gpt-image-2.5-sunburst/aiadcast-images-v13-photo-roles/2026-10-15`다. 모델·예산·무료 호스팅 설정은 변경하지 않았다. APK 설치로 서버 코드가 갱신되지는 않는다.

## 실제 품질 비교와 배포 조건

기존 앱과 업데이트 앱에 같은 원본 사진, 용도, 이름, 설명, 가격, 직접 문구, 비율을 사용한다. 포장재·자동차·서비스 사례별 첫 결과와 재시도 결과를 모두 보관한다. 상품 동일성, 사실 정확성, 모바일 가독성, 구도와 완성도, 성공률, 생성 시간·비용을 기록한다. 실제 비교 전에는 ‘월등히 향상’이라는 결론이나 점수를 부여하지 않는다.

최신 서버 배포·로그인 연결, 실제 생성, 실기기 설치와 저장, 기존 Play 앱의 패키지·업로드 서명 확인이 남아 있다. 현재 Preview는 별도 시험용 패키지이며 외주 앱의 기존 스토어 등록정보를 그대로 업데이트할 수 있는지는 미확인이다.

Google 공식 기준 확인 2026-10-15:
- 기존 앱 업데이트에는 동일 패키지, 더 큰 versionCode, 일치하는 업로드 서명이 필요하다. https://support.google.com/googleplay/android-developer/answer/9859350
- 2023-11-13 이후 개설된 개인 계정은 공개 배포 신청 전 최소 12명이 14일 연속 참여하는 비공개 테스트 대상이다. 계정 유형·개설일은 미확인이다. https://support.google.com/googleplay/android-developer/answer/14151465

## 대표 주도 개발 증빙

대표의 실제 요구사항, 이에 대응하는 소스 변경 이력, 테스트 결과, 설치판, 동일 입력 전후 비교, 대표의 직접 시연을 함께 제시한다. ‘초기 버전은 외주 개발했고, 후속 개선은 대표가 요구사항과 검수 기준을 정하며 AI 코딩 도구를 활용해 주도했다’고 설명한다. 모든 코드를 직접 수기로 작성했다거나 생성 모델 자체를 개발했다고 설명하지 않는다. 특허 출원과 등록은 구분하며 전 청구항 구현 완료 또는 보증 승인 보장을 주장하지 않는다.
