# 생성 후 새 광고와 규격 표시 후속 수정

PR33 `669f96e41d1553f3a895bf5b6a1c8a79a14d548c` 기반 `feat/creation-flow-feedback-20261018` 후보다. 공식 SVG와 앱·웹·서버 버전 화면을 유지한다. Android 0.2.35-demo/code37, 기존 패키지·서명을 사용한다. 운영 서버 db15는 전달받은 상태이며 이 작업에서 배포하지 않는다.

## 원인과 복구

확정 결과에도 pending-generation 기록이 남아 재진입할 때 이전 작업 GET 실패가 새 생성 버튼을 계속 잠갔다. 로컬 대체 API로 확정 후 이전 endpoint 404와 새로고침을 재현했다. 확정 결과를 IndexedDB 프로젝트에 먼저 저장하고 완료 요청의 영구 pending 표시를 제거한다. 같은 화면의 다시 적용은 추가 차감 없이 유지한다. 구버전의 남은 표시는 현재 보관된 사용 가능한 확정 결과의 jobId가 일치할 때만 해제한다. 불명확한 요청, ready/running/uncertain 작업은 계속 중복 요청을 차단한다. 결과 화면에서 광고 만들기로 이동하면 이전 프로젝트를 보관하고 새 ID의 빈 초안으로 시작한다. 입력 수정 후 확정 결과를 다시 제작할 때도 별도 프로젝트를 만든다. 이전 요청의 예약·이용권·결제 기록은 지우거나 수정하지 않는다.

## 화면과 규격

제작 선택은 사진 치수선 없음 / 본제품에 직접 표시 / 같은 제품 작은 사진에 표시 세 가지다. 새 제작 화면에서 과거 방식의 초안을 열거나 제출할 때 선택 배치를 유지하고 자동 표시로 해석한다. 기존 결과·합성 좌표·검수 기록 자체를 변환하지 않으며 과거 결과 복구 경로는 별도로 검증한다. 지원하지 않는 서버 차단과 결과 검수는 유지한다.

두 표시 방식과 모든 상품에 가까운 윤곽 여백, 실제 측정 부위의 양 끝 정렬, 짧은 보조선, 수치 겹침 방지, 인셋 자체 크기에 맞춘 글자·여백 지침을 적용한다. 박스 높이는 바닥부터 몸통 상단 접힘선까지다. 용기 높이·지름, 가방 몸통/손잡이 포함 높이, 의류 총장·가슴너비는 제공된 의미를 따른다. 치수와 단위를 추정하지 않는다. 프롬프트·요청 및 검수 UI 개선이며 실제 AI 생성물의 정확도 보증이나 이미지 실측 기능이 아니다. 유료 생성 없이 로컬 fixture로만 검사한다.

이미지 저장 · 공유 버튼은 기존 Android 파일로 저장/다른 앱 공유 선택창을 호출한다. 자동 공유하지 않으며 공유창 열기를 전송 완료로 표시하지 않는다. 웹은 파일 다운로드라는 차이를 안내한다. 추천 채널 표시는 요청한 여섯 항목으로 바꾸되 보관된 생성 입력과 기획 근거는 수정하지 않는다.
