# 시연판 업데이트 APK — 로그아웃·결제 안내·시연 지원

기준 웹/서버 후보는 PR #27 `39d1a84b5ecd8df6ceac0d4536694d2f30405b0e`이며 PR #25 결제 상태, #26 공통 계정·로그아웃을 포함한다. 같은 순간 제작 버튼을 두 번 눌렀을 때 중복 저장·화면 전환을 시작하던 경쟁도 수정했다.

- 앱 이름 `aiadcast 시연`, applicationId `com.selluplabs.aiadcast.next.demo` 유지.
- versionName `0.2.29-demo`, versionCode `31`로 증가(이전 0.2.28-demo/30).
- 기존 승인된 시연 signing key를 그대로 사용한다. 새 키·새 패키지·Play 공개 출시 없음. 기존 인증서 SHA256은 `576ead9f546b2d227250323d688c9087b0e206bf101b8560a9922b1ee793b638`이다.
- 같은 패키지/같은 서명이므로 기존 시연 앱을 삭제하지 않고 업데이트 설치하는 파일이다. 실제 기기의 설치·자료 유지 성공은 별도로 확인해야 한다.
- APK가 웹 화면을 내장하므로 서버 배포만으로 기존 APK의 상단 로그아웃과 결제 안내가 바뀌지 않는다. 이 업데이트는 새 화면을 포함한다.
- 공개 backend 주소는 기존 `https://aiadcast-next.onrender.com`. 주소 변경·디버깅·공급사 키 입력을 활성화하지 않는다.

APK 설치는 서버 배포나 회원 지원 적용이 아니다. 현재 전달된 운영 SHA는 `ffb7b7aab761e0a298f8f918bd5e0d42fb1339d1`이다. 기존 서버에서도 새 계정·로그아웃과 결제 상태 안내는 기존 API를 사용한다. 원자적 시연 지원은 대응 서버가 별도 검증·승인 후 배포되어 capability를 제공해야 보이며, 관리자의 명시적 조회·확인·적용이 추가로 필요하다. 기존 운영에서 회원에게 예산이나 이용권을 자동 지급하지 않는다.

서버 배포는 이번 범위에서 하지 않는다. 서비스·연결 브랜치·정확한 SHA·기존 환경·DB를 먼저 확인한다. 지원 실제 적용 이후 journal을 무시하는 ffb7b7a/3cc9318로 단순 롤백하면 관리자 $5 정책과 회원의 기존 사용액이 충돌할 수 있다. [재배정 및 롤백 조건](atomic-demo-support-20261018.md)을 따른다.

최종 APK의 SHA256, 인증서 일치, 패키지/버전, 내장 웹 일치, native unit tests·Android lint·서명·zipalign 결과 및 Library 파일은 최종 검증 보고에 기록한다. 웹 사용량 숫자를 보여주는 전용 상세 UI는 아직 없으며 실제 운영 usage 분석에 인증 토큰이나 비밀을 요구하지 않는다.
