# 모델 도입과 품질 검증 기준

현재 실제 AI 공급사 어댑터와 모델은 미연결이다. 아래는 신규 상용 앱에 적용할 기준이며 평가를 완료했다는 보고가 아니다.

## 후보 선택

- 이미지 생성, 배경 분리, 영역 수정, 번역, 영상의 후보를 각각 비교한다.
- 공식 문서에서 모델 ID·지원 API·해상도·지역/계정 접근·가격·서비스 조건을 확인한 날짜를 남긴다. 현재 환경에서 최신 공식 문서를 직접 확인하지 못한 항목은 미확인으로 표시한다.
- 품질 우선 후보와 비용 대비 후보를 동일한 입력으로 평가한다. 새 모델이라는 이유만으로 기본값을 바꾸지 않는다.
- 테스트용 API 프로젝트와 예산 한도를 별도로 설정한다. 고객에게 보여주는 이용권 비용과 공급사 비용을 각각 측정한다.

## 초기 평가 자료

포장재 외에 자동차·뷰티·전자제품·의류·유리/금속·식품 및 교육·보험·서비스 광고를 포함한다. 초기 목표는 주요 업종별 실제 사례 5개 이상이며 제공된 원본·확정 문구·치수 또는 규격 없음·기대 편집 범위를 한 묶음으로 관리한다. 브랜드/로고, 투명 물체, 반사, 복잡한 윤곽, 긴 한글·영문, 7가지 출력 비율을 넣는다. 아직 실제 원본 18606.jpg와 대응 규격, 특허 명세서 전체를 받지 못했다.

| 항목 | 통과 판단 |
|---|---|
| 원본 보존 광고 | 원본 레이어를 다른 상품으로 다시 그리지 않음. 원본 해시·합성 범위 기록, 마스크 경계와 로고를 사람도 확인 |
| 창작 광고 | 원본과 다른 디자인일 수 있음을 구분. 사용한 참고 자료와 모델/프롬프트 버전 기록 |
| 한글·다국어 | 확정한 문구를 별도 글꼴 레이어로 출력. 문자열 누락·잘림 없음. 번역 문안은 의미·가격·조건을 대조 |
| 규격 | 같은 값에서 표·선 출력. 규격 없음은 입력/요청/표시 모두 생략. 표시 숨김과 규격 미사용 구분 |
| 부분 수정 | 지정한 배경/문구/영역만 변경. 원본·이미 승인한 내용·이력 보존 |
| 과금 | 중복 요청·실패·앱 종료·늦은 응답에도 이중 차감 없음. 고객 이용권과 API 원장 대사 |
| 운영 | 응답 시간·성공률·실제 단가·메모리·다운로드 실패·복구 시간 측정. 초기 수치는 측정 후 확정 |
| 영상 | 상품/로고/문자 일관성을 프레임별 검사. 생성형 영상의 동일성을 무조건 보장하지 않음 |

## 적용과 되돌리기

`server/model-router.mjs`는 평가 승인된 명시적 리비전만 선택한다. 현재의 evaluationPassed 플래그는 평가 시스템 자체가 아니므로, 실제 연결 단계에서는 평가 보고서·검토자·기준 데이터 버전을 함께 보관한다. 미승인 모델과 원본 보존을 지킬 수 없는 경로는 선택하지 않는다.

개발 → 시험 → 제한된 사용자 → 정식 순으로 적용하고, 기존 승인 모델/템플릿/어댑터 조합을 보관해 되돌릴 수 있게 한다. 진행 중 작업은 시작할 때의 모델·견적·입력 버전을 유지한다. 변경 후 비용 또는 실패율이 기준을 넘으면 신규 요청을 멈추고 이전 조합으로 돌아간다.
