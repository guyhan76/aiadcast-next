# aiadcast 가격 제안과 단위 원가

작성일: 2026-10-09. **출시 제안이며 실제 판매가·최신 공급사 견적·실측 원가가 아니다.** 현재는 AI/결제 연결 전이다. 이번 공식 페이지 7건은 모두 프록시 터널 403으로 열리지 않았다. 다음 과거 가격은 비교 출발점으로만 사용하고 판매 전 공식 계정/견적에서 재확인한다.

## 추천: 초기에는 충전형 3개 상품

| 상품 | 한국어 안내 / KRW | 영어 안내 / USD | 기본 제작 | 고급 제작만 쓸 때 |
|---|---:|---:|---:|---:|
| 10크레딧 | 9,900원 | $7.99 | 최대 10장 | 3장 + 잔여 1크레딧 |
| 30크레딧 | 24,900원 | $19.99 | 최대 30장 | 10장 |
| 100크레딧 | 79,900원 | $59.99 | 최대 100장 | 33장 + 잔여 1크레딧 |

- 국내 제안가는 VAT 포함, USD 제안가는 해당 판매세 별도 기준이다. 두 가격표는 고정 지역 가격 제안이며 현재 환율로 자동 변환한 값이 아니다.
- 기본 제작 1장 = 1크레딧. 고급 제작 1장 = 3크레딧. 기본은 장당 799~990원, 고급은 장당 2,397~2,970원에 해당한다. 실제 모델/작업 비용과 품질을 확인한 뒤 등급을 확정한다.
- ‘1장’은 사용자가 승인한 광고 결과 1개다. 모델 호출 횟수가 아니며 모델이 불필요하게 만든 후보 수만큼 차감하지 않는다.
- 단순 비율 변경·동일 결과 재다운로드·문구/규격 수동 수정은 추가 생성으로 계산하지 않는다. 새 상품/새 콘셉트/AI로 다시 생성하는 작업은 사전 견적을 보여준다.
- 처음에는 비구독 충전형으로 실제 사용량·재구매·오류율을 측정한다. 만료/환불 정책은 출시 전 확정해 구매 전에 알린다. 사용하지 않은 크레딧이 소멸해서 이익이 난다는 가정은 원가 계산에 사용하지 않는다.
- 기존 1회 4,900원은 단일 정지 이미지의 초기 체험 가격으로는 진입 장벽이 높을 수 있다. 추후 여러 소재를 묶은 검증된 광고 패키지에는 별도 가격을 검토할 수 있으나, 아직 없는 기능을 포함 상품으로 판매하지 않는다.

## OpenAI 비용과 소비자 판매 가격은 다르다

과거 GPT Image 1 공개 표의 출력 비용 예시: 1024×1024 medium $0.042 / high $0.167, 1024×1536 medium $0.063 / high $0.25. **출력 이미지 비용만**이며 입력 이미지·입력 텍스트·추가 검사·재시도 등이 붙을 수 있다. 최신 모델의 현행 가격으로 적용하지 않는다. [OpenAI API 가격](https://openai.com/api/pricing/), [상세 가격](https://platform.openai.com/docs/pricing)에서 정확한 모델·해상도·quality·토큰을 확인해야 한다.

사용자가 알려준 선불 결제액 약 $5와 잔액 약 $2만으로는 성공 결과당 원가를 알 수 없다. 해당 기간의 작업별 모델/품질/입력 사용량, 성공·실패·재시도, 고객 승인 건수를 함께 집계해야 한다. 실제 계정의 지출 내역을 이번에 조회하지 않았다.

계획 환율 **$1 = 1,400원**을 사용했다. 현물 환율 조회값이 아니다. 실제 달러 결제에는 카드 환산·해외 결제 수수료·공급사 세금의 적용 여부를 더 확인한다.

계산식:

```
차감된 결과 1개당 예상 원가 =
  ((출력 원가 + 입력·검사 원가) × 평균 시도 횟수 + 작업당 인프라비)
  ÷ 고객 승인·차감 비율
  + 결과당 지원·복원 준비금
```

평균 시도 횟수는 최초 요청을 포함한다. 승인 비율을 분모로 넣어, 고객에게 청구하지 못한 실패·거절 작업의 공급사 비용도 성공 작업의 수익으로 감당하도록 계산했다. 최종 확정 후 현금 환불·분쟁 수수료 등은 운영 데이터로 추가 조정한다.

| 가정 | 기본 | 고급 | 비용 악화 상황 |
|---|---:|---:|---:|
| 출력 $/시도 | 0.063 | 0.250 | 0.250 |
| 입력·검사 $/시도 | 0.025 | 0.040 | 0.070 |
| 평균 시도 횟수 | 1.3 | 1.4 | 1.8 |
| 인프라 $/작업 | 0.020 | 0.030 | 0.040 |
| 승인·차감 비율 | 90% | 90% | 75% |
| 지원 준비금 $/차감 결과 | 0.030 | 0.050 | 0.080 |
| **예상 변동 원가/차감 결과** | **$0.1793 / 약 251원** | **$0.5344 / 약 748원** | **$0.9013 / 약 1,262원** |

출력 참고 단가를 제외한 수치는 모두 운영 가정이다. 원본 사진 합성만 하는 요청은 더 저렴할 수 있고, 다중 참조·세부 편집·고해상도·여러 차례 수정은 더 비쌀 수 있다. 표의 금액을 모든 업종·모델의 확정 원가로 약속하지 않는다.

## 남는 금액: 30크레딧 24,900원 사례

Google Play 수수료 **15% 적용을 가정**한 계산이다. 가입 프로그램·매출·상품·지역 정책에 따라 다르므로 모든 판매에 15%라고 단정하지 않는다. 30% 상황도 아래 계산 파일에 함께 반영했다. 카드 PG나 다른 스토어는 각각 별도로 계산한다.

| 기본 광고 1장 기준 | 금액 |
|---|---:|
| 판매가 24,900 ÷ 30 | 830원 |
| 부가세 제외 | 약 755원 |
| 가정한 스토어 수수료 | 약 113원 |
| 정산 수입 | 약 641원 |
| 예상 변동 원가 | 약 251원 |
| **남는 기여이익** | **약 390원** |

기여이익은 급여·개발·고정 서버비·마케팅·법인세 등을 빼기 전이다. 순이익이라고 부르면 안 된다. 정산 수입 기준 약 60.9%가 남는 예시다. 같은 조건에서 스토어 수수료가 30%라면 장당 기여이익은 약 277원이다.

월 고정비를 가정으로 100만원 잡으면 이 30팩/15% 조건에서 약 2,563장의 기본 광고가 승인·차감되어야 그 고정비를 감당한다. 고객 획득 비용이 들면 더 필요하다. 이는 수요/매출 예측이 아닌 산술 예시다.

가장 할인한 100팩의 15% 수수료 조건에서 정산액의 절반을 남기려면 기본 원가 약 309원 이하, 고급 원가 약 926원 이하가 필요하다. 수수료 30%라면 각각 약 254원/763원으로 좁아진다. 환율·원가 악화 시 해당 목표가 깨질 수 있어, 실측 전 무제한 할인/무제한 재생성을 약속하지 않는다.

[전체 팩별·통화별·수수료별 계산](pricing-calculation.md)은 다음 명령으로 재생성한다.

```bash
npm run pricing:report
# Markdown 결과만 저장하려면:
node --experimental-strip-types scripts/pricing-report.mjs > docs/pricing-calculation.md
```

기준 데이터: `config/pricing-assumptions.json`, 제안가: `src/pricing.ts`. 계산기는 결제 금액 확정이나 실제 이용권 차감 기능이 아니다.

## 오류 비용을 고객에게 떠넘기지 않는 운영

1. 모델 호출 전 예상 비용/크레딧 예약. 승인된 결과를 고객이 수락할 때만 이용권 확정 차감.
2. 시스템 오류·확인된 오타/잘못된 상품 생성은 회사 부담으로 수정하거나 예약 해제/차감 복원. OpenAI에서 발생한 사용료까지 취소된다고 가정하지 않는다.
3. 자동 재시도는 우선 1회 한도와 작업별 비용 한도를 둔다. 이후 해결되지 않으면 이용권 복원 및 오류 기록으로 전환한다. 위 평균 횟수는 모든 작업에 매번 1.3회를 허용한다는 뜻이 아니다.
4. 고객이 광고 방향을 바꾸는 추가 생성은 별도 견적을 안내한다. 화면에서 새 요청과 결함 수정 요청을 구분하되, 품질 실패를 고객 취향 변경으로 일괄 처리하지 않는다.
5. 무료 가입 체험은 예를 들어 계정당 기본 1회부터 시험하되 전체 체험 비용 한도·중복 계정/자동화 방지를 갖춘 이후 제공한다. 현재 무료 API 호출을 실행하거나 프로모션을 활성화하지 않았다.
6. 번역문/맞춤법은 이미지에 그려 넣기 전에 문자 데이터로 검토·편집한다. 수동 오타 수정 때문에 이미지 생성 API를 다시 호출하지 않는다. 자동 번역의 비용·제한은 별도 기능 설계에서 확정한다.

## 한국어 원화 / 영어 달러 표시

- 편집 검증판 상단 **이용 요금**에 한국어/KRW와 English/USD 안내를 추가했다. 선택을 기기에 저장하며 광고 문구의 한/영 선택·프로젝트 데이터와는 독립적이다. 전체 앱 UI 영어 번역을 완료한 것은 아니다.
- Google Play 안에서 실제 결제할 때는 Play Billing이 내려주는 제품/제안 식별자와 `formattedPrice`를 사용한다. 스토어 국가와 청구 통화가 권위 있는 값이며 언어로 임의 변경하지 않는다. 한국 스토어 사용자가 영어를 골라도 실제 결제는 원화일 수 있다.
- 웹 결제를 추후 지원하면 결제 지역/통화를 별도로 선택하고 서버가 세금·판매 상품·가격 버전을 검증한다. 번역을 바꾸는 클릭을 구매 국가 변경으로 취급하지 않는다.
- 실제 견적에는 상품 ID, 크레딧 수, 결제 통화, 최소 단위 정수 금액, 가격 버전, 만료 시각을 넣고 서버에서 검증한다. 클라이언트의 locale/price/credits를 신뢰해 잔액을 지급하지 않는다.
- 표시가와 최종 결제가가 다르면 최종 확인 전에 실제 통화·세금·총액을 보여준다. 금액 승인과 영수증 검증 없이 구매 성공으로 표시하지 않는다.
- USD 7.99는 내부 금액 799센트, KRW 9,900은 내부 금액 9,900원이다. 표시 단계에서 Intl.NumberFormat을 사용한다. 제안가에서 실제 결제 어댑터로 자동 연결하지 않는다.

## 가격 확정 전에 측정할 것

실제 원본/규격이 있는 물리 상품과 규격 없는 업종을 섞어 최소 100~200건의 평가 표본부터 확보한다. 성공 건만 뽑지 않고 모든 요청 비용을 집계한다. 모델·원본/창작 모드별로 결과당 총 원가의 평균과 p95, 재시도율, 승인율, 결함 복원율, 지연, 고객 재사용을 본다. 이 표본만으로 장기 수익성이 확정되지는 않는다.

기본/고급 품질을 실제 비교하고 최신 단가·환율·계정 수수료를 확인한 뒤 제안 가격을 확정한다. 모델 교체 때마다 동일 자료로 다시 평가한다. 원가가 오르면 신규 상품 가격/구성을 검토하고 기존에 구매한 이용권 조건을 임의로 악화시키지 않는다. 영상은 원가가 다르므로 이미지 크레딧과 같은 가격을 약속하지 않고 별도 견적으로 확장한다.

공식 결제 수수료 재확인: [Google Play 수수료 안내](https://support.google.com/googleplay/android-developer/answer/112622?hl=en). 이번에는 최신 본문을 확인하지 못했으며 현재 계약 조건은 미확인이다.
