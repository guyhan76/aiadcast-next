# aiadcast 확정 출시 가격과 과금 기준

2026-10-10 사용자 확정. 가격 카탈로그의 상태는 **approved**이고 실제 결제 연결은 **purchasesEnabled: false**다. 가격 승인과 판매·영수증 검증·이용권 지급 구현을 구분한다. 이전 10/30/100크레딧 제안과 기본/고급 1/3크레딧 차등은 폐기했다.

## 가격과 제공 단위

| 상품 | 광고 제작 수 | 한국 KRW — VAT 포함 | USD — 현지 판매세 별도 |
|---|---:|---:|---:|
| 체험용 / Trial | 3개 | 6,900원 | $4.99 |
| 기본형 / Essential | 10개 | 19,900원 | $14.99 |
| 묶음형 / Bundle | 30개 | 49,900원 | $39.99 |

- 신규 광고 1개 = 1크레딧. 공급사 호출 수·다운로드 파일 수를 고객 과금 단위로 삼지 않는다. 모든 팩은 동일한 핵심 편집 기능을 제공한다. 구매량으로 품질 등급을 나누지 않는다.
- 저장한 광고의 수동 문구·가격·기간·규격 표시 수정, 단순 비율 변경, 재다운로드는 생성 크레딧을 차감하지 않는다. 광고 하나를 피드·스토리·릴스 이미지로 저장해도 신규 광고 3개로 차감하지 않는다.
- 릴스용 9:16 출력은 정지 이미지 소재다. 영상 생성·영상 파일·음원은 이 이미지팩에 포함하지 않는다.
- 새 연출·배경·AI 부분 재생성은 실행 전 견적을 보여주는 별도 요청이다. 시스템 오류·확인된 생성 결함은 회사 부담 보정 또는 이용권 복원으로 처리한다. 공급사 사용료까지 취소된다고 가정하지 않는다.
- 비구독 충전형으로 시작한다. 만료·환불 등 소비자 계약 조건은 실제 판매 전 결제 화면과 일치시킨다. 미사용 이용권이 소멸해야 이익이 나는 모델은 사용하지 않는다.

## 언어·통화·결제 국가 분리

가격 화면에서 안내 언어 한국어/English와 표시 통화 KRW/USD를 각각 선택한다. 두 선택은 서로 독립적으로 기기에 저장되며 광고 문구 언어와 무관하다. 영어로 읽어도 원화 가격을, 한국어로 읽어도 달러 가격을 확인할 수 있다.

표시 통화는 실제 청구 국가 선택이 아니다. Google Play 결제 연결 후에는 Play Billing이 제공하는 상품·제안 식별자와 `formattedPrice`를 사용한다. 구매 국가, 실제 통화, 현지 세금, 최종 총액을 결제 전 보여주고 서버의 구매 영수증 검증으로만 크레딧을 지급한다. 고객이 보낸 금액·크레딧 수나 화면 locale을 신뢰해 지급하지 않는다. KRW 금액은 원 단위 정수, USD는 센트 단위 정수로 저장한다.

## 원가와 현금지출 기준

사용자가 선택한 **신규 광고당 계획 원가 350원**을 적용한다. 실측 청구액이나 모든 요청의 공급사 비용을 350원 이하로 보장한다는 뜻은 아니다. 실제 입력량·재시도·무과금 보정·인프라를 기록해서 평균과 높은 비용 사례를 검증한다. 이미 원가 또는 고정 현금지출에 넣은 항목을 중복 계산하지 않는다.

2026-10-10 사용자는 회사 유지에 필요한 현금지출을 기존 2,000만원에서 **월 2,200만원**으로 변경했다.

| 항목 | 월 금액 |
|---|---:|
| 급여 | 11,600,000원 |
| 고문 | 2,500,000원 |
| 차량 | 800,000원 |
| 사무실 | 820,000원 |
| 세무 | 160,000원 |
| 기보 대출 원금+이자 | 3,500,000원 |
| 기타 | 620,000원 |
| 마케팅+연구개발 | 2,000,000원 |
| **합계** | **22,000,000원** |

대출 원금/이자 분할은 미확인이다. 대출 원금 상환은 회계 영업비용이 아니므로 월 2,200만원을 모두 영업비용으로 넣어 영업이익률을 주장하지 않는다. 아래 목표는 **현금지출 충당**이다. 회계 손익분기점·영업이익률은 원금과 이자를 분리한 후 계산한다.

계산 가정: 10개팩 70%·30개팩 30%, 계획 환율 1달러=1,400원, 원화 VAT 10%, 정산액의 2% 현금 환불 준비금, 모든 구매 크레딧 사용. 체험팩은 반복 구매 믹스에 넣지 않는다. 스토어 수수료 15%·30%는 계약 확인 전 시나리오이며 실제 계정 조건이 아니다. 일반 인앱결제에 카드 PG 수수료를 무조건 중복 가산하지 않는다. 해외 정산·환전 비용이 추가되면 별도로 반영한다.

[재현 가능한 전체 계산](pricing-calculation.md)은 다음 명령으로 갱신한다.

```bash
npm run pricing:report
node --experimental-strip-types scripts/pricing-report.mjs > docs/pricing-calculation.md
```

가격: `src/pricing.ts`. 원가·현금지출 가정: `config/pricing-assumptions.json`. 계산: `server/pricing-economics.mjs`. 유료 광고 수요나 재구매를 보장하는 예측이 아니며 실제 결제 어댑터에 자동 연결하지 않는다.

## 출시 전 검증

일반 상품과 규격 없는 서비스의 실제 생성 요청을 섞어 입력 토큰·모델·품질·수정 횟수·무과금 복원·총 공급사 비용·승인 결과 수를 기록한다. 작업별 비용 한도와 제한된 자동 재시도로 비용 폭주를 막고, 해결되지 않은 결함은 고객 과금을 완료하지 않고 오류 기록과 복원으로 처리한다. 급여에 포함된 고객 지원과 예산에 포함된 마케팅을 장당 원가에 다시 넣지 않는다.

소비자는 AI 모델 공부 없이 광고를 완성하고 다시 고쳐 쓰는 데 대가를 지불한다. 가격을 낮춘 효과는 무료 가입 수가 아니라 첫 정상팩 구매, 고객 확보 비용, 다음 구매, 재사용률로 검증한다. 영상·고해상도 확장은 실제 원가와 품질을 검증한 뒤 별도 상품으로 결정한다.
