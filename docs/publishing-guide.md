# 광고에서 실제 게시로 이어지는 가이드

2026-10-10 개발판. 미리보기의 **게시글과 활용 방법 보기**로 이동한다.

## 고객 흐름

1. 상품·서비스명과 광고 문구를 입력한다. 업종·목적에 따라 추천 매체 두 개가 먼저 표시된다.
2. 매체를 고르고 준비된 제목·본문을 수정한다. 인스타그램·숏폼은 게시글 복사에 해시태그를 함께 넣는다. 검색어는 별도로 수정할 수 있다.
3. 해당 매체용 이미지를 저장하고 각 매체에서 게시한다. 편집 중인 비율과 원본은 변경하지 않는다.
4. 매체별 게시 요령과 반응을 살펴볼 기준을 확인한다. 수정한 글은 프로젝트 저장·백업/불러오기에 포함된다.

| 매체 | 안내 및 출력 |
| --- | --- |
| 인스타그램 | 피드용 4:5 이미지, 캡션·해시태그, 프로필 연결과 잘림 안내 |
| 블로그 | 16:9 대표 이미지, 검색 제목·본문 초안, 자연스러운 검색어 사용 |
| 숏폼·릴스 | 9:16 정지 이미지, 0–3/3–10/10–15초 장면 구성 가이드 |
| 홈페이지·상세페이지 | 3:4 상품 소개 이미지, 텍스트·사진 설명·문의 경로 안내 |
| 광고 룩북 | 3:4 단일 이미지, 표지→상품 정보→문의의 페이지 구성 가이드 |

매체 요구사항은 게재 위치마다 다르며 플랫폼 미리보기에서 확인한다. 동영상, 다중 페이지 PDF, 자동 게시, 실제 성과 수집 기능은 구현하지 않았다.

## 사실·비용·저장

- 현재 문구, 소재/소개, 광고 속성, 표시하도록 선택한 유효 규격을 조합한다. 새 가격·기한·효능·평가를 만들어내거나 사진을 AI로 분석하지 않는다. 초기 제안은 규칙에 따른 초안이며 입력 정보 자체의 정확성을 자동 검증하지 않는다.
- 검색어 후보는 상품·브랜드·업종과 명시적으로 입력된 지역을 사용한다. 검색량/순위/트렌드를 조회하지 않는다. 일반 추가 속성의 가격·전화번호를 SEO 후보로 자동 선정하지 않는다.
- 사용자가 수정한 게시글은 매체·광고 언어별로 보관한다. 앱 언어 전환은 게시글을 번역하지 않는다.
- 관련 사업 정보가 바뀌면 수정본을 보존하면서 변경 안내를 표시하고 복사를 중단한다. 최신 초안으로 교체하거나 수정본의 정보 확인을 마치면 복사가 가능하다. 새 프로젝트에는 이전 프로젝트의 글이 넘어가지 않는다.
- 복사 권한이 없으면 선택 가능한 텍스트를 제공하며 복사 완료로 표시하지 않는다. 게시글은 React 텍스트/입력값으로 취급하며 HTML로 실행하지 않는다.
- 편집/복사/비율별 내보내기에 공급사 호출은 없다. 입력 정보만으로 사용 가능하며, 기존 AI 문구 도우미에서 승인·적용한 문구도 활용한다. 별도 유료 모델을 호출하는 새 기능은 아니다.
- 프로젝트의 선택 필드 `publishing`에 최대 10개(5매체 × 2언어) 초안을 보관한다. 이전 프로젝트 파일은 이 필드 없이 열 수 있다. 기획 JSON에는 매체별 현재 초안과 수정/변경 상태가 포함된다.
