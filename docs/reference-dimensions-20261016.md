# 참조사진·입력 규격 전달 보완

2026-10-16 · Android 검증판 0.2.26

## 변경

- 검정 업로드 버튼: `사진 첨부`. 안내: `한번에 여러 장 선택 가능`. 최대 10장·전체 10MB와 파일 형식은 별도로 표시하며 기존 다중 선택을 유지한다.
- AI 연출의 `creativeDirection.referenceGeometry`에 실제 상품 사진 해시, 축별 mm 값, 정규화 비례, 규격 표시 여부를 함께 넣는다. 기존 서버의 생성 요청 정규화와 완성형 광고 프롬프트를 통해 전달된다.
- 디자인 참고 사진 해시는 상품 형상 근거에서 제외한다. 실제 사진은 상품 형태·재질·구조의 근거, 디자인 참고는 구성·분위기의 근거로 구분한다.
- 물리적 축의 비례와 원근 투영·광고 캔버스 비율을 구분한다. 사진 전체를 늘이거나 박스의 열린 날개·손잡이·그림자를 몸체 치수로 취급하지 않도록 지시한다.
- 규격 표시를 꺼도 비례를 전달한다. 규격 없는 상품·서비스에는 없는 치수를 만들지 않는다. 원본 합성은 사진 형태를 유지하며, 입력 규격에 맞춘 새 연출을 원할 때 AI 광고를 선택하도록 안내한다.

## 확인

사진 역할·완성형 광고·규격 전달·소비자 입력·연출 관련 도메인 검사 38개가 통과했다. 400×300×350mm 입력은 width=1, depth=0.75, height=0.875로 전달되고, 높이를 200mm로 바꾸면 height=0.5로 갱신된다. 출력 비율 변경은 물리적 비례에 영향을 주지 않는다. 원통형은 지름·높이만 전달한다. 사진의 용도와 해시가 유지되며, 디자인 참고는 실물 근거에 포함되지 않는다.

서버 코드를 새로 배포했다는 의미는 아니다. 기존 서버가 보존하는 creativeDirection 안에 보완 지침을 넣는 클라이언트 변경이다. 실제 Render 요청과 실기기 생성 결과, 상품 동일성·물리적 비례는 아직 추가 검증이 필요하다. geometryVerified는 false를 유지한다.
