## 확인한 원인과 변경

일반 완성 광고 생성은 치수를 JSON/문장으로 전달하면서 사진 실루엣을 유지하라는 상충 지시를 함께 보냈다. 수치 기반 기하 경로는 별도 로컬 증명 모드에만 있었다. 숫자 표기가 맞아도 제품 형태가 맞는 것은 아니다.

새 광고는 입력 규격을 우선하는 서버 정규화 계약을 사용한다. 지원 몸통은 치수로 세계 좌표를 만든 뒤 하나의 원근 카메라로 투영한 구조 PNG를 첫 참고 이미지로 전달한다. 기존 사진 원본 바이트와 순서를 보존하며 이후 이미지 번호를 보정한다. 사진은 재질·인쇄·색상·디자인을 제공한다. 350×300×250의 투영 전 몸통 비율은 7:6:5다. 화면 픽셀 길이를 실물 비율과 동일시하지 않는다.

박스 직육면체, 명시적으로 확인한 일정 지름 원통 몸통, 평면 직사각형을 지원한다. 의류·가방·불규칙 상품을 임의의 박스로 만들지 않는다. 병 목·어깨·뚜껑, 덮개·손잡이, 내부 치수에서 외부 치수로의 변환은 추가 정보 없이는 확정하지 않는다. UI에 부족한 측정 부위와 실루엣 정보를 알린다.

구조 가이드에는 숫자/화살표가 없다. none/main/inset은 동일한 기하 계약을 사용한다. 본제품과 인셋은 같은 규격을 따르도록 요청하고, 사람의 형상 검수와 기존 수치·단위/축/누락 검수를 별도로 유지한다. 숨긴 치수·몸통 형태·측정 기준 변경도 이전 결과 재사용 키를 무효화한다. 기존 저장 광고는 기존 키를 유지하고 새 생성 시 명시적으로 새 계약으로 전환한다. 빈 치수를 편집하는 중에도 화면이 충돌하지 않는다.

## 검증의 한계

이는 **결정론적 구조 가이드와 생성 요청 연결**이다. AI가 다시 그린 최종 픽셀을 기하에 고정한 렌더러나 완성 이미지의 자동 치수 검증기는 아니다. 치수 표시는 현재 같은 생성 호출의 요청이며, 생성 후 결정론적으로 치수선을 입히는 새 엔진이 아니다. 기존 완성 광고 합성은 이미지 전체를 균일 배율로 배치하지만, AI가 규격을 준수했다는 증거가 되지 않는다. 모든 계약/결과는 `outputGeometryVerified: false`이며 검수 UI에서 명확히 알린다.

로컬 검사는 실제 유료 provider 대신 주입한 fetch/이미지 fixture를 쓴다. 구조 가이드의 세계 좌표·투영·가이드 해시, 사진 바이트/순서, 요청 정규화, 입력 변경 무효화, 구서버 차단, 복구·검수·허위 검증 표시 거부를 검사한다. `artifacts/dimension-first` 자료는 구조 가이드이며 실제 AI 광고 품질 증거가 아니다. 실제 AI 형상·인쇄·치수선 정확도, 실물 기기 설치·인증은 아직 확인하지 않았다. 새로운 실사진 품질 평가에는 별도 승인과 운영 비용/인증 준비가 필요하다.

## 배포와 남은 조건

프런트와 API를 함께 갱신해야 `generation.dimensionGeometry`가 지원된다. APK만 설치하면 기존 운영 API가 새 규격 경로를 지원하지 않을 수 있으며, 이때 입력을 보존하고 생성 요청 전에 차단한다. 이는 유료 호출 후 조용히 사진 비례로 되돌아가는 것을 막는다.

이번 작업은 운영 배포, 기존 PR 병합, 강제 push, 키/권한/플랜/이용권/예산/DB 변경을 수행하지 않는다. 관리자 이용권 무제한은 API 비용 무제한 승인이 아니다. 운영자가 배포 직전에 Render 서비스 `srv-db65sol9fdbs73eu33i0`, 저장소 `guyhan76/aiadcast-next`, 실제 연결 브랜치·환경·자동 배포 OFF·승인된 SHA를 다시 확인해야 한다. 기존 연결 브랜치 `feat/patent-product-generation-20261011`의 latest를 배포 대상으로 사용하지 않는다. 이 작업에서 운영 상태를 새로 인증하지 않았다. 기존 DB/스토리지 백업·복구 검증 및 인증 단계도 배포 전 남아 있다.

PR40 CI는 테스트 통과 후 artifact storage quota로 업로드가 실패했다. 후속 CI는 별도로 확인하여 코드 검사와 아티팩트 업로드 실패를 구분한다. 한도를 변경하거나 기존 아티팩트를 삭제하지 않는다.
