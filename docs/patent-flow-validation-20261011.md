# 상품 정보와 광고 생성·결과 안내 연결

기준: `feat/mobile-private-beta-20261010`의 `30923a41a25004d1236d5472fec7ed57d7d9ffc2`.

## 수정한 문제

브라우저의 생성 요청에는 속성·타깃·콘텐츠 형식이 있었으나 서버 정규화와 공급사 프롬프트가 일부를 버렸다. 활용 가이드도 생성 결과와 독립된 현재 폼의 정보로만 계산했다.

- 공유 기획 모듈에서 분류·입력 규격·속성·광고 목적을 이용해 타깃과 추천 채널을 결정한다. 규격이 있는 상품은 해당 크기 조건을 비교하는 고객을 식별한다. 기존 산업재 및 포장재 부피·수량 규칙도 유지한다.
- 창작 모드의 공급사 요청에 검증한 참조 이미지, 규격값·정규화 비례, 항목명/값 속성, 타깃, 카드형/포스터 형식이 함께 전달된다. 원본 합성은 기존처럼 사진을 별도 보존하고 배경만 요청한다.
- 결과 이미지와 제작 의도·추천 채널 2개·중복 제거한 검색어 6개를 같은 결과 화면에 제공한다. 기획은 생성 당시 작업과 승인 프로젝트에 저장한다.
- 현재 입력이 바뀌면 과거 생성 설명과 최신 게시글 초안을 구분한다. 오래된 프로젝트에는 존재하지 않는 생성 당시 설명을 만들어 붙이지 않는다.
- 문구와 규격 숫자는 기존 편집기의 별도 렌더링을 유지한다. 기획 계산·검색어·결과 안내 때문에 AI 호출이나 이용권 차감을 추가하지 않는다.

## 검증

- `npm run build`: 통과. 기존 번들 크기 경고는 남아 있다.
- `npm run test:domain`: 180개 통과. 상품·서비스·원본 보호·서버 요청·입력 검증·작업 보관·프로젝트 복원·이용권 관련 회귀 테스트 포함.
- 새 `tests-domain/patent-flow.test.mjs`: 실제 서버 정규화와 어댑터 프롬프트 사이의 값 전달, 사진 해시, 숨긴 규격, 타깃 변화, 양 언어·전체 분류의 6개 검색어, 서비스 무규격, 생성 이후 입력 변경을 검증한다. 공급사는 모의 구현을 사용한다.
- `tests/generation-ui.spec.ts`에 결과 안내·스냅샷 백업/복원·모바일 너비 검증을 추가했다. 이번 환경에는 `/usr/bin/chromium`이 없고 Playwright 브라우저 다운로드가 빈/불완전 ZIP으로 실패해 **브라우저 테스트는 실행 환경 준비 단계에서 차단**되었다. 통과로 계산하지 않는다.
- 실제 유료 이미지 생성, 신규 배포, APK 설치, 상품 실측 정확도 또는 사진 동일성 평가는 수행하지 않았다.

## 출원 관련 표현

사용자가 알려준 상태는 출원 완료·등록 전이다. 이 변경을 등록 특허 구현, 청구항 전체의 상용 구현 완료, 정확한 3D 복원으로 표현하지 않는다. `geometryVerified`는 계속 `false`다. 결과의 설명은 생성 기획이며 이미지가 그 기획을 정확히 충족했다는 판정이 아니다. 출원 대응표는 `patent-implementation-map.md`를 참고한다.
