# 자동 규격 표시 평가 준비 — 실제 분석 미실시

사용자 목표는 생성 직후 실제 상품 위치에 규격선을 자동 배치하고 필요할 때만 수정하는 흐름이다. 별도 추상 도면이나 최초 수동 좌표 입력으로 대체하지 않는다. 이 변경은 그 목표를 위한 **격리된 분석·합성 평가 경로**이며 운영 기능 완성이 아니다. 현재 운영 기준 `d6032b3efa9aff1b3f9440e7d5572474a2c89d0a`를 자동 배포하거나 변경하지 않는다.

## 구현 범위

- `server/vision-evaluation/analysis.mjs`: 고정 비전 모델로 실제 이미지의 상품 영역·축별 본체 모서리·문구 보호영역·기존 규격 표시를 요청한다. 임의 프롬프트, 생성 API, 도구, 모델 변경, 리다이렉트, 자동 재시도는 없다.
- `overlay.mjs`: 좌표 유효성과 원본 해시를 검사한 뒤 저장 치수로 선과 숫자를 합성한다. 본체 직접 표시 또는 같은 상품 픽셀을 잘라 작은 사진으로 배치하는 평가 모드를 제공한다. 복사할 빈 영역이 없거나 보호 문구와 선이 겹치면 원본을 유지한다. 사진 배경 제거·상품 재생성은 하지 않는다.
- 모든 합성 성공도 `review-required`, `verified:false`다. 모델의 위치·축 선택이 옳다는 보증이 아니다. 본체 위쪽이 손잡이를 제외했는지는 실사진 평가에서 확인해야 한다.
- 기존 앱의 생성·이용권·저장 흐름에는 아직 연결하지 않았다. 실패는 원본 보존으로 끝나며 이미지 재생성을 시도하지 않는다.

## 승인 범위와 비용 강제

승인은 첨부된 박스·쇼핑백 광고 분석 **총 10회 및 US$0.30 이하**, 추가 이미지 생성 없음이다. 두 자료 모두 기존 화살표가 있으므로 이를 새 출력이나 자동 검출 성과로 보고하지 않는다. `22925.png`는 승인 범위에서 제외한다.

자료: `22932.jpg` / Library `libfile_5aca4b318fbc81918717e3bb2931f243`, `22935.jpg` / Library `libfile_76fc0c91a4f481918f7d51f32dbd25d6`. 실제 다운로드·육안 확인 후 파일명과 박스/쇼핑백 대응 및 SHA-256을 확정해야 한다. 현재 승인 해시는 비어 있어 실제 호출이 차단된다. 이름만 바꾼 제3의 이미지는 통과할 수 없다.

SQLite 공유 원장은 `secrets/vision-analysis-20261017.sqlite` 하나다. `BEGIN IMMEDIATE`와 `synchronous=FULL`로 호출 전에 US$0.03을 예약하고, 다른 프로세스와 재시작 후에도 합산 횟수와 예약 합계를 검사한다. 정산해도 승인 한도를 다시 늘리지 않는다. 타임아웃·불명확한 응답·사용량 누락·상한 초과는 후속 호출을 차단한다. 오류 후 재시도·원장 자동 초기화 기능은 없다. 운영 API 원가 예산과는 별개인 이번 평가 전용 원장이다.

가격 기준: 2026-10-17 확인, `gpt-5.4-mini-2026-03-17`, 입력 $0.75/1M·출력 $4.50/1M. 한 장을 최대 1024×1024로 축소하며 최대 1229 이미지 토큰, 전체 고정 텍스트·스키마의 UTF-8 바이트 수와 프레이밍 여유를 합친 입력 상한 8000, 출력 상한 1500을 적용한다. 보수적 요청 비용 상한은 약 **$0.013672**, 호출 예약은 **$0.03**이다. 캐시 할인을 가정하지 않는다. 입력 토큰 상한은 고정 요청에 대한 보수적 추정이고 공급사 청구서의 강제 상한은 아니다. 반환 사용량으로 비용을 정산하며 실제 초과가 발견되면 중단한다.

공식 근거: [모델 및 가격](https://developers.openai.com/api/docs/models/gpt-5.4-mini), [이미지 토큰과 공간 위치 추론 한계](https://developers.openai.com/api/docs/guides/images-vision). 가격·모델 계약이 바뀌면 실행 전에 상한을 재검토한다.

## 자격 증명과 실제 실행 전 조건

기존 키 재사용 선택은 완료됐다. 현재 테스트 환경에는 키가 없고 도구 목록에는 기존 키 보안 입력/주입 기능이 없다. 새 키 생성 도구는 사용하지 않는다. Render 비밀값 조회, 채팅을 통한 키 전달도 하지 않는다.

안전한 연결 경로가 제공되면 테스트 프로세스 `OPENAI_API_KEY`로 재사용한다. 지속 파일 저장이 필요하면 `.env.local`의 정확한 대상 확인을 먼저 받는다. CLI는 키를 출력하거나 저장하거나 env 파일을 자동 로드하지 않는다. 프로젝트·결제 연결은 아직 확인하지 못했다.

실행 순서: 안전한 키 연결 → 승인 자료 다운로드·육안 확인 및 해시 고정 → 공유 원장 최초 생성(기존 원장이 없고 이번 승인 호출 0회임을 재확인) → 한 건씩 분석 → 원본/진단 오버레이 비교 → 사람 검토. CLI는 `node scripts/evaluate-dimension-placement.mjs <22932.jpg|22935.jpg> <input> <new-output.png>`이며 전제 조건 미충족 시 차단된다. 원장 초기화나 승인 해시 설정을 편리한 우회 옵션으로 노출하지 않았다.

## 평가 및 남은 기능

박스의 기대값: 앞 가로 300mm, 오른쪽 깊이 200mm, 오른쪽 높이 100mm. 쇼핑백: 가로 350mm, 깊이 130mm, 손잡이 제외 본체 높이 260mm. 정확한 기준 좌표는 실제 이미지 확인 후 정한다. 기존 화살표와 모델 제안선을 구분해 끝점 오차, 축 대응, 문구 겹침, 본체/손잡이 구분을 검토한다. 주석이 없는 광고로 일반화된다는 주장은 하지 않는다.

`node scripts/vision-evaluation-evidence.mjs`는 **고정 좌표를 가진 로컬 모형**의 원본/직접 표시/작은 사진 비교 PNG를 만든다. 실제 사용자 광고·AI 분석 결과가 아니다. CI의 `vision-evaluation-mock` 아티팩트에서 받을 수 있다.

남은 작업: 안전한 키 연결, Library 실제 파일 확보, 제한된 실사진 분석, 실패 사례 검토, 운영 UI 선택·좌표 수정·저장/복구 통합, 검증된 SHA에 대한 별도 배포 확인. 이 평가 브랜치를 운영 자동 배치 완료본으로 배포하지 않는다.
