# 눈에 보이는 내 계정과 로그아웃

로그인한 주요 화면 상단에 `내 계정`과 `로그아웃`을 표시한다. 320px 이상 모바일에서 줄바꿈을 허용하고 버튼 높이는 44px 이상이다. `내 계정`은 기존 이용권 화면으로 연결한다.

로그아웃 확인 후 현재 사진·입력·프로젝트의 기기 저장이 완료되어야 서버 세션을 해제한다. 중복 클릭은 같은 작업을 공유한다. 저장 실패 또는 서버 응답 실패 시 로컬 인증과 작업을 지우지 않고 재시도를 안내한다. 서버가 이미 세션을 만료시킨 경우 재시도의 401 응답으로 로컬 로그아웃을 완료한다. 처리 중 계정이 바뀌면 새 계정의 인증을 지우지 않는다. 기존 계정 도구와 오프라인 시연도 같은 처리 함수를 사용한다.

기기 작업은 계정과 서버 주소별 저장 공간으로 분리한다. A에서 로그아웃하고 B로 로그인하면 A의 입력·사진·프로젝트를 표시하지 않으며 A로 다시 로그인하면 복원한다. 브라우저 저장은 서버 동기화나 기기 자체의 암호화 보장이 아니다.

브라우저 회귀 검증은 주요 8개 경로, 320/390/1440px, 취소, 중복 클릭, 503 및 401 재시도, IndexedDB 저장 실패, 사진 포함 계정 전환·복구를 확인한다. 기존 계정 및 오프라인 시연 테스트도 함께 실행한다. 새 테스트의 첫 실행 실패는 비밀번호 로그인 버튼의 이전 이름을 사용한 selector였으며 실제 `로그인하고 계속`으로 바로잡았다.

이 변경은 코드 검토용이며 운영 배포·APK 재패키징·회원 지원금 적용을 수행하지 않는다. 기존 APK에 포함된 화면을 바꾸려면 검증된 새 APK가 필요하다.
