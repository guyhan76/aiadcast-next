# Result usage guide (local UI revision)

The accepted image and save/share remain primary. The prior local text-editor entry removal is retained; stored edits and original exports are not rewritten.

- Omit the dimension card when `dimensionGuide` cannot produce an actual diagram. Valid saved dimensions remain available in a closed optional disclosure, with the existing separate PNG export. This does not measure or modify the advertisement.
- Replace repetitive intent, audience and rationale sections with one closed Usage guide. Use up to three supported still-image channels from the existing category/goal ranking, with a brief usage instruction. Do not imply that a still image is a generated video.
- Show up to six related search phrase candidates in the saved advertisement language. Do not pad sparse inputs with unrelated generic terms. Named hoodies use explicit hoodie/zip-up vocabulary; no search volume, ranking or performance claim is made.

## Capability boundary

`marketing-plan.ts` and `seo-keywords.ts` use input-based rules. The previous screen ignored the ranked channels and displayed the same six channels. Neither those templates nor the revised guide are semantic AI analysis of the generated image. `marketing-presentation.ts` only adapts presentation and does not rewrite saved plans, generation requests or hashes.

True image-aware placement recommendations and product-specific semantic keyword selection require a separately approved provider integration, cost policy and evaluation. Disabled image analysis remains disabled. No provider call, video feature, database migration or billing change is part of this revision.
