## 요청 목표와 사업 설명

목표는 aiadcast의 기술 검증과 사업화를 위한 **2억원 규모의 보증부 은행 대출 상담**이다. 2억원은 대표자의 희망 조달액이며 승인 금액, 보증 한도, 은행 조건은 아직 확인되지 않았다.

**aiadcast는 판매자가 실제 상품 사진과 규격·가격·회사 정보를 넣으면, 상품 특징과 규격을 반영한 광고를 만들고 문구와 매체 비율을 수정해 재사용하도록 개발하는 플랫폼이다.** 포장재뿐 아니라 가방·화장품 용기·시계·소형가전 등 일반 상품과 규격 없는 서비스 광고를 다룬다.

해결할 핵심 문제는 AI가 원래 상품을 바꾸거나 비례를 왜곡하는 현상, 한글·규격·가격 오류, 작은 수정 때 반복되는 생성 비용이다. 구현 중인 차별 요소는 사진·규격·속성 결합, 원본 보존 경로, 정확한 정보의 별도 렌더링, 비교 기록, 생성 결과와 연결된 광고 활용 안내다. 자동 3D 재현이 이미 완성됐다는 주장은 하지 않는다.

## 공식 기준과 상담 경로

기보는 기술력, 신용상태, 사업전망, 신청금액 적정성 등을 심사한다. 따라서 개발 결과, 사업 증거, 재무 상태를 함께 설명해야 한다. 실제 적용 상품·한도·보증비율·보증료·은행 금리는 상담 후 확인한다. 공고상의 최대한도를 이 회사의 승인 예상액으로 쓰지 않는다.

## 매출과 상환 근거를 만드는 방법

과거 채팅에 나온 영화패키지·엠플러스·대양기획·MTTS·유성기업의 이미지 제작 요청은 그 자체로 유료 계약이나 매출 증빙이 아니다. 계약서, 발행 세금계산서, 입금 또는 실제 사용 확인이 있는 항목만 실적으로 분류한다. 제안·관심·시범 사용·유료 계약·입금 완료를 각각 구분한다.

가격과 판매량은 아직 확정 실적으로 사용할 수 없다. 다음 계산표를 실제 자료로 채운다.

| 입력 또는 산식 | 현재 상태 |
|---|---|
| 현재 회사 월매출·입금액·고정비 | 자료 필요 |
| 앱 유료 고객 수·재구매율·요금제별 결제액 | 확인 전; 목표와 실적 분리 |
| 고객당 순수입 | 실제 수금에서 부가세·환불·플랫폼 비용을 반영 |
| 고객당 변동비 | 성공과 실패를 모두 포함한 AI·저장·결제·지원 비용 |
| 월 영업현금 기여 | 유료 고객 수 × 고객당 공헌액 − 월 고정 현금지출 |
| 대출 월 상환액 | 은행이 제시한 원금 일정 + 잔액에 대한 이자 |
| 보증 관련 지출 | 확인된 보증료와 납부 시점 반영 |
| 월말 현금 | 월초 현금 + 실제 유입 − 운영·개발·세금·원리금 등 지출 |

기준·매출 지연·원가 상승 상황을 나눠 12개월 현금표를 만든다. 매출이 예상보다 30% 낮고 변동비가 30% 높아지는 경우는 스트레스 가정의 예시이며 예측이나 심사 기준이 아니다. 신규 대출금 자체를 매출 또는 장기 상환 재원으로 계산하지 않는다.

## 상담 시 설명문 초안

“셀업랩스는 소상공인과 제조·판매업체가 실제 상품 사진과 규격을 이용해 광고를 제작하고 수정·재사용하는 aiadcast를 개발하고 있습니다. 관련 기술은 출원 완료, 등록 전입니다. 현재 사진·규격·속성을 연결하는 요청 구조와 원본 보존, 문구의 별도 출력, 개발용 승인·복원 흐름을 구현했습니다. 일반 상품 비례 비교 기록도 추가했으며, 실물 반복 검증과 상용 운영 구축이 남아 있습니다. 해당 개발과 고객 실증에 필요한 2억원 규모의 보증부 대출을 상담받고 싶습니다. 실제 자금 산출 근거와 재무·매출 자료를 바탕으로 적합한 보증상품과 가능 규모를 검토받고자 합니다.”

이 문구는 준비한 상담 초안이며 외부에 발송하지 않았다. 검증 전 기능은 완료된 표현으로 바꾸지 않는다.

## 바로 확보할 자료

1. 대출 신청 주체의 사업자등록증·법인등기, 설립일, 업종, 사업장 소재지.
2. 최근 결산 재무제표와 2026년 매출 자료, 현재 현금과 월 고정비. 신규 회사라 결산 전이면 해당 기간의 실제 자료.
3. 회사의 기존 대출·보증별 잔액, 월 상환액, 만기, 연체·국세/지방세 체납 여부. 없으면 없음으로 확인.
4. 출원 접수증과 권리 귀속 자료, 실제 계약·입금·사용 증거, 개발 견적.
5. 실물 시연용 정면·사선 사진과 측정 범위가 확인된 규격. 먼저 일반 상품 1개와 박스 1개로 시작.

이번 작업은 코드와 상담 준비자료 작성까지다. 보증 승인 가능성, 은행 대출 실행 가능성, 금리·기간은 아직 판단하지 않았고 대출 신청도 하지 않았다.
