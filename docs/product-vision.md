# aiadcast 핵심 제품 목표

사용자 확정 목표 · 2026-10-09

핵심 차별점·고객 문구 추가 확정 · 2026-10-10

> 마케팅 전담 직원 없이, 프롬프트 작성 능력 없이, AI 전문 지식 없이, 여러 AI 서비스를 따로 구독하지 않고도 누구나 언제 어디서든 필요한 만큼 원하는 광고를 만들 수 있는 앱.

이 목표를 신규 aiadcast의 기능·디자인·개발 우선순위·사업 설명의 공통 판단 기준으로 삼는다. 아래 내용은 제품이 도달할 목표와 설계 원칙이며 현재 구현 완료를 뜻하지 않는다. 실제 구현과 한계는 README 및 validation.md에 별도로 기록한다.

사용자는 글로벌 출시를 선호한다. 한국어·영어를 지원하는 하나의 앱으로 설계하며 앱 언어, 광고 문구 언어, 스토어 결제 국가·통화를 서로 구분한다. 2026-10-10 개발판에는 한국어·영어 UI와 별도 광고 문구 언어 선택을 구현했다. UI 전환만으로 기존 문구를 번역하거나 결제 통화를 바꾸지 않는다. 국내·영어권 테스트와 단계적 공개를 제안한 [글로벌 출시 계획](global-launch-plan.md)은 실행 준비와 검증을 위한 문서이며 이미 글로벌 판매가 가능하다는 의미는 아니다.

## 고객이 aiadcast를 선택할 이유

### 1차 검증 우선순위 — 사용자 확정 2026-10-10

**규격이 있는 실물 상품의 실제 사진과 규격을 함께 사용해, 해당 상품의 특징을 유지하고 입력 규격에 부합하는 비례로 표현하며 치수를 표시하는 것**을 첫 번째 검증 목표로 한다. 서비스 확장·일반 광고 연출·저장 인프라보다 이 기능의 실물 검증을 먼저 해결한다. 기존 서비스 경로와 규격 표시 선택권은 유지하며, 이번 시연에서는 규격 표시를 켠다.

치수 숫자만 정확하게 붙이기, 원본 사진을 그대로 합성하기, 입력 규격을 프롬프트에 넣기는 각각 부분 기능이며 전체 목표 달성으로 계산하지 않는다. 원본 상품 동일성, 입력 규격 대비 형상/비례, 각 축에 맞는 치수 표기를 별도 판정한다. 개발 범위·현재 차이·합격 기준은 [규격 상품 1차 검증 기준](dimension-product-priority.md)을 따른다.

사용자가 확정한 핵심 차별점은 **내 상품과 확정한 정보를 지키는 것**, **완성한 광고를 필요한 부분만 고쳐 다시 쓰는 것**이다. 이미지 생성 모델 자체보다 처음 광고를 완성하고 반복 사용하는 과정의 편의·일관성으로 가치를 증명한다. ChatGPT에서도 가능한 작업을 독점 기능처럼 설명하지 않는다.

첫 화면과 고객 설명의 중심 문구는 다음과 같다.

> **내 상품과 서비스를, 프리미엄 광고로.**
>
> 사진과 설명을 넣으면,  
> AI광고가 광고이미지와 문구를 만듭니다.

2026-10-11 사용자 확정: 홈 상단에는 위 슬로건과 설명만 남긴다. 설명은 사용자가 지정한 쉼표 뒤에서 줄바꿈해 두 줄로 표시한다. 기존 상단 안내·상품/브랜드/서비스 나열·기능 나열은 제거하며 사진 입력과 매체별 저장 안내는 해당 단계에 배치한다.

서비스 광고는 사진 없이도 시작할 수 있다. 위 문구를 서비스 선택 화면의 사진 필수 조건으로 해석하지 않는다. 고객에게 보여주는 기능 설명과 버튼은 실제 연결 상태를 따르며, 이 문구가 AI 생성·자동 번역·브랜드 잠금·영상 제작의 구현 완료를 뜻하지 않도록 한다.

## 한 광고를 고쳐 쓰고, 필요한 매체로 저장한다

대표 흐름은 **신메뉴 사진·가격 등록 → 신메뉴 홍보 방향 선택 → 결과 확인·가격 수정 → 인스타그램 피드·스토리용 저장 → 다음 주 같은 프로젝트에서 행사 기간만 변경**이다. 같은 흐름을 포장재, 의류, 일반 상품과 숙박·교육 등 규격 없는 서비스에도 적용한다. 카페 전용 앱이나 인스타그램만 지원하는 앱으로 범위를 좁히지 않는다.

- **상품과 확정 정보 보호:** 사용자가 확정한 가격·기간·연락처·규격·상품명을 AI 제안과 구분해 저장하는 방향으로 개발한다. 원본 활용 모드에서 상품 사진을 임의로 다시 그리거나 로고를 바꾸지 않는다. 사용자가 창작·상품 변경을 선택한 경우에는 변경 범위를 분명히 확인한다. 원본 파일 보존, 브랜드 전체의 자동 잠금, 사진 한 장으로 실제 입체 형상·규격을 재현하는 기능은 서로 다른 문제다.
- **저장한 광고 다시 열기:** aiadcast의 기기 저장 프로젝트 또는 원본과 편집 정보를 포함한 JSON 백업을 다시 열면 문구·배경·규격 등 저장된 편집 정보를 활용한다. 가격 한 줄을 고치기 위해 상품 사진과 사업 정보를 다시 입력하게 하지 않는다. 기기 저장은 현재 브라우저에 한정되며 클라우드·기기 간 동기화와 구분한다.
- **외부 완성 이미지 다시 올리기:** 일반 PNG/JPG는 이미지 한 장으로 합쳐진 결과물이다. 업로드만으로 기존 글자·상품·배경의 편집 레이어가 자동 복원된다고 설명하지 않는다. 향후 선택 영역 수정은 사용자가 수정 범위와 변경안을 확인하는 흐름으로 구현·검증하며, 영역 밖 상품과 확정 정보의 보존 여부도 확인한다. 현재는 AI 마스크 편집이 연결된 상태가 아니다.
- **매체에 맞는 출력:** 인스타그램 피드는 4:5·1:1, 스토리는 9:16, 릴스에는 9:16 이미지 소재를 활용하도록 용도별 선택을 제공한다. 동일한 광고를 다른 비율로 출력해도 문구·상품·가격·기간이 이어져야 한다. 핵심 문구·로고의 잘림과 매체 UI 가림을 확인하고, 안전 영역·게재 위치별 미리보기와 실제 업로드 검증을 완료한 범위에서만 ‘최적화’를 주장한다. 비율을 맞춘 것만으로 플랫폼 승인·광고 성과를 보장하지 않는다.
- **릴스 이미지와 영상 구분:** 9:16 PNG 저장은 릴스용 정지 이미지 소재 준비다. 재생 가능한 릴스 영상·음원·자막·전환 효과를 만든 것이 아니며, 실제 영상 생성·편집·내보내기는 별도 구현과 검증이 필요하다.
- **반복 편집의 과금 원칙:** 동일한 광고의 수동 문구·가격·기간·규격 표시 수정, 단순 비율 변경과 재다운로드를 신규 AI 생성으로 차감하지 않는다. 한 광고를 피드·스토리·릴스 이미지 소재로 저장했다고 신규 광고 세 개로 과금하지 않는다. 새로운 배경·상품 시안·AI 부분 재생성처럼 공급사 호출이 필요한 작업은 실행 전에 비용과 범위를 안내한다. 시스템 실패·확인된 생성 오류는 별도 보정·이용권 복원 기준을 적용하며, 공급사 비용과 고객 차감은 분리한다. 이는 과금 설계 원칙이며 실제 결제 연결 완료를 뜻하지 않는다.

2026-10-10 개발판에는 원본 사진 합성, 직접 문구·배경·규격 편집, 기기 저장·JSON 백업과 복원, 여러 비율의 PNG 출력에 더해 다음 기반을 구현했다.

- 한국어·영어 UI, 영어 업종 검색, 광고 문구 언어와 별도인 앱 언어 설정.
- `gpt-image-2.5-sunburst` 로컬 API 어댑터와 결과 검토·사용 확정·편집·출력 흐름. 원본 모드는 사진을 공급사에 보내지 않고 배경을 생성해 합성하며, 창작 모드는 참조 사진을 사용할 수 있다.
- CopyAssistant의 한국어·영어 문구 제안·번역 요청과 원문 비교 후 승인 흐름. 제안은 자동 적용하지 않는다.
- SQLite에 보관하는 작업·사용량·추정 비용과 개발 테스트 이용권의 예약·확정·실패/반려 복원. 고객 결제나 실제 환불 실행이 아니라 개발용 과금 흐름이다.
- 별도 applicationId의 Android debug APK와 파일 선택·저장·공유·뒤로가기 연결. 실기기와 Play 등록 검증은 별도다.

[실제 시험 기록](live-test-2026-10-10.md)을 참고한다. 개발 API는 `127.0.0.1:8787`, 예산 0달러, 이미지·문구 호출 비활성이 기본이며 공개 고객용 서버가 아니다. [로컬 API 실행과 제한](backend-local-api.md)을 따른다. 운영 사용자 인증·실결제·클라우드 동기화·확정 정보의 자동 검수·자동 배경 제거·선택 영역 AI 수정·브랜드 자동 적용·실물 3D 형상 재현·광고 영상은 후속 구현과 검증이 필요하다. 상세 상태와 검증 근거는 README, [Android 개발 안내](android-development.md), [검증 기록](validation.md)을 기준으로 설명한다. 이전 단계의 화면·검증 기록을 최신 완료 기능으로 소급 해석하지 않는다.

## 사용자는 사업을 설명하고, 앱은 광고 제작을 맡는다

사용자가 알려줄 것은 광고할 상품·서비스와 사실 정보, 달성하고 싶은 목적이다. 실물 사진·규격은 해당하는 경우에만 받는다. 광고 전문 용어, 긴 프롬프트, AI 모델 이름, 생성 파라미터를 이해해야 다음 단계로 갈 수 있는 흐름을 기본값으로 만들지 않는다.

기본 흐름은 **광고 대상 알려주기 → 앱이 제안한 방향 고르기 → 광고 확인 → 필요한 부분만 수정 → 사용할 매체로 내보내기**다. 처음부터 모든 세부 조건을 작성하게 하지 않는다. 이미 받은 회사·브랜드 정보와 이전 광고를 다시 활용한다.

## 설계 원칙

1. **프롬프트를 못 써도 시작할 수 있다.** 사진·상품/서비스명·목적 선택과 추천만으로 첫 광고를 만드는 경로를 제공한다. 자유 입력과 대화는 추가 의사를 표현하는 선택지다. 정확한 명령어를 외우게 하지 않는다.
2. **마케팅 판단을 돕는다.** 타깃, 핵심 장점, 광고 문구, 시각적 연출, 매체·비율을 앱이 제안하고 이유를 쉽게 설명한다. 사업자가 확인할 수 없는 제품 효능·가격·실적을 지어내지 않는다.
3. **하나의 앱에서 끝낸다.** 사용자가 이미지·번역·디자인·영상 도구마다 가입하거나 API 키를 가져오는 것을 일반 고객의 이용 조건으로 삼지 않는다. 공급사 연동과 모델 선택은 운영 측에서 관리한다. 영상은 구현·검증 후 같은 제작 흐름으로 확장한다.
4. **말로 수정할 수 있다.** “좀 더 고급스럽게”, “인쇄만 금색으로”, “배경만 바꿔줘” 같은 일상적인 표현을 현재 작업과 앞선 요청에 연결한다. 모호할 때는 필요한 한 가지를 짧게 묻거나 비교할 선택안을 보여준다. 모든 수정에서 다시 시작하게 하지 않는다.
5. **내 상품과 사실 정보를 지킨다.** 원본 보존/새로운 창작, 규격 사용/표시, 인쇄·상품 색상 변경을 구분한다. 허용받지 않은 상품 변경을 성공으로 처리하지 않는다. 서비스·교육·보험 등은 규격이나 상품 사진 없이도 사용할 수 있어야 한다.
6. **어디서든 이어서 만든다.** 휴대폰 중심으로 촬영·요청·확인·수정·내보내기가 가능하고, PC에서도 같은 프로젝트를 이어가는 것을 목표로 한다. 현재의 기기별 로컬 저장을 기기 간 동기화 완료로 설명하지 않는다.
7. **반복 제작과 수정의 부담을 낮춘다.** 저장한 브랜드·상품을 활용해 여러 목적·매체·언어용 광고를 재사용한다. 단순 문구·규격 표시 수정 때문에 전체 이미지를 다시 생성하지 않는다. 시스템 실패·잘못된 결과에 대한 이용권 보호와 재처리 기준을 갖춘다. ‘필요한 만큼’은 반복 사용의 접근성을 뜻하며 무조건 무료·무제한 생성 약속으로 바꾸지 않는다.
8. **복잡한 기술은 제품 안에서 처리한다.** 새 모델은 운영 측 평가를 거쳐 교체하며 고객에게 모델 비교 공부를 요구하지 않는다. 하이엔드 디자인은 첫 화면에서 서비스 목적과 다음 행동이 분명하고, 최소한의 입력으로 실제 쓸 광고를 얻는 경험으로 평가한다.

## 새 기능을 채택하기 전 확인할 질문

- 마케팅/AI 경험이 없는 사람이 프롬프트를 작성하지 않고 첫 광고를 만들 수 있는가?
- 사용자의 결정·반복 입력·별도 도구 사용을 얼마나 줄이는가?
- 자유롭게 요청하면서도 원본 상품·사실 정보·수정 범위가 지켜지는가?
- 포장재 밖의 일반 상품과 규격 없는 서비스에도 적용되는가?
- 휴대폰에서 결과 확인과 작은 수정, 원하는 매체용 저장까지 마칠 수 있는가?
- 가격·실패 처리·수정 범위를 사용자가 이해할 수 있는가?

모든 기능에 이 질문을 기계적으로 적용하기보다 해당 기능의 사용자 부담 감소와 해결하는 문제를 설명한다. 기술의 신기함이나 설정 항목 수를 제품 가치의 근거로 삼지 않는다.

## 현재 검증판에서 이어갈 우선순위

직접 편집·요청 기록에 로컬 이미지/문구 어댑터, 결과 검토, 테스트 이용권 보호와 Android 패키징 기반을 연결했다. 다음 단계는 예산을 제한한 실제 생성 품질 검증과 고객이 반복 사용할 수 있는 운영 구조의 완성이다.

- **프롬프트 없이 첫 결과:** 최소 정보·추천 선택·생성 요청·사람의 검토로 이어지는 경로를 실제 상품·서비스 사례로 확인하고 원가와 완료 시간을 측정한다.
- **문맥을 이해하는 수정:** 명령 패턴에 한정된 빠른 편집을 넘어 앞선 조건을 이해하는 AI 대화, 변경안 확인, 선택 영역 수정.
- **한 서비스로 완결:** 개발 원장과 모델 어댑터를 운영 인증·권한·결제·품질 검수·클라우드 동기화에 연결하고, 실제 Android 기기와 Play 출시 조건을 검증한다. 별도 AI 구독을 고객에게 요구하지 않는 운영 구조를 유지한다.

첫 결과까지의 입력 수·완료 시간, 프롬프트 없이 완성한 비율, 수정 성공률, 재작업·불만·환불 비율을 향후 사용자 테스트에서 측정한다. 목표 수치와 효과는 실제 측정 전까지 실적으로 표시하지 않는다.

## 비공개 다중 사용자 시험 기반 — 2026-10-10

동일 날짜 후속 개발로 닫힌 직육면체 사진의 세 면을 입력 치수 형상에 투영하는 수동 시험 모드를 추가했다. 일곱 모서리 지정과 확인이 필요하며 자동 3D 복원·실물 검증 완료가 아니다. 현재 기능과 직접 시험 순서는 [규격 박스 시험판](box-projection.md)을 따른다.

초대코드 로그인과 세션 취소, 계정별 기기/서버 저장·생성 DB·예산·이용권, 서버 프로젝트 버전 충돌 보호를 추가했다. 명시적 서버 저장/열기를 지원하며 자동 동기화가 아니다. 일반 고객용 회원가입·이메일 인증·개인정보 보관/삭제·구매 영수증 검증은 별도다. 배포 패키지를 실제 컨테이너에서 검증했지만 외부 서버·Android 실기기·Play 출시 완료를 뜻하지 않는다. beta-server.md가 실행과 한계의 기준이다.

## 사용자 수정 지시 · 2026-10-10 후속

기본 고객 화면을 사진·상품 상세설명·선택적 요청사항 → 비율·선택적 회사/연락처 정보로 단순화한다. 참조사진 최대10장, 하단 회사명·전화·이메일·홈페이지 각각 표시 여부를 제공한다. 상세 편집·규격·대화·활용 가이드는 선택적으로 펼친다. 고급스러운 조명·재질·여백을 생성 지침과 출력 구성에 반영하되, 실제 결과 검증 없이 “하이엔드 완성”으로 표현하지 않는다. [재설계 및 실제 시험](premium-redesign-20261010.md)을 참조한다.

최신 지시: 분위기 선택을 제거한다. 상품 특징·참조·요청사항으로 AI가 단일 연출을 판단하고 결과에서 수정 요청을 받는다. 고정 분위기 프리셋을 생성에 강제하지 않는다.

홈의 시작 행동은 광고 만들기 하나로 통합한다. 상품·서비스는 제작 첫 화면에서 고르고, 이전 작업과 편집 중인 작업은 내 프로젝트에서 찾는다. 홈에 중복 작업 복귀 링크·최근 작업 카드를 나열하지 않는다.

앱 UI는 흰색 바탕, aiadcast 로고 주황, 블랙, 연회색을 기본 팔레트로 사용한다. 베이지·카키 UI 표면을 사용하지 않는다. 광고 사진과 사용자가 선택한 광고 자체의 색상은 UI 테마와 구분한다.

2026-10-11 사용자 승인: 광고 만들기는 `광고 정보 → 크기·연락처` 두 단계로 정리한다. 제목·단계·설명 중복을 제거하고 사진, 이름, 설명을 먼저 받는다. 사진 추가 영역과 버튼은 넓게 중앙 배치하고 파일 형식·최대 장수·용량은 항상 표시한다. 업종·규격과 광고 목적·요청은 선택적으로 펼치며, 상품·서비스 선택을 업종 안에서 반복하지 않는다. 기존 세부 업종·규격 형식·광고 목적과 일곱 출력 비율은 유지한다. 연락처는 두 번째 단계에서 한 번 입력하고 항목별 표시 여부를 고른다. 공통 푸터는 상단과 같은 주황색 `ai`를 사용하고 로고와 회사 표기를 키운다.


2026-10-11 후속 승인: 홈 광고는 상표 없는 독자적인 화장품·패션소품·패션·주얼리·소형가전·여행·호텔·보험·병원·자동차 리스/렌탈 10종을 보여준다. 기본 CTA는 제외하고 고객이 요청사항에 명시한 때만 넣는다. 광고 사진과 정확한 문구는 분리하며 업종별 재질·조명·구도와 공통 문구 여백을 생성 지침에 반영한다. 사진의 형태·잡티·인물과 문구의 오타·잘림은 확대 검수한다. 생성 지침의 자체 점검을 자동 품질 검증 완료로 설명하지 않는다.

2026-10-11 사용자 승인 후 적용: 신규 제작의 규격 단위는 cm를 기본으로 하고 mm·inch를 선택한다. 내부 mm 값은 유지하고 표시만 환산해 단위 반복 변경으로 크기가 변하지 않게 한다. 기존 단위 없는 프로젝트는 mm로 해석한다. 광고에 규격 표시 기본값은 끈다. 내 프로젝트는 큰 광고 미리보기·이름·날짜와 검색으로 단순화하고 백업은 접어둔다. 사용 안내는 사진·설명 → 확인·수정 → 저장·활용 세 단계와 펼침 설명으로 구성한다. 이메일 인증 기반 가입·로그인, 이용권 선택·결제 확인 화면은 UI 검토용으로 추가했으며 실제 이메일 인증과 결제·구매 크레딧 지급은 아직 연결하지 않았다.
