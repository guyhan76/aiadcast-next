# 로컬 글씨 편집 — 0.2.49-demo / code51

0.2.48의 생성·복구·참조사진·과금 정책은 유지한다. 새 서버 배포는 필요 없다.

사용 확정한 AI 완성 광고의 `글씨 편집`을 연다. 원본 해상도의 이미지 사본을 고정 배경으로 보관하고 최대20개 글씨 레이어를 추가한다. 내용(한글 포함), 위치, 사각형 크기, 글씨 크기, 색상, 굵기, 정렬을 조절한다. 기존 글씨 수정은 사용자 지정 사각형을 선택한 단색으로 가린 후 글씨를 합성한다. OCR·생성형 삭제·배경 복원은 하지 않는다. 숫자 수정은 표시만 바꾸며 실제 상품 비례, 입력 규격 및 생성 검수 기록은 바꾸지 않는다.

레이어의 모든 그리기는 정수 픽셀 사각형으로 clip하며 배경은 원본 자연 해상도로 한 번 그린다. 원본 보기에는 레이어를 적용하지 않는다. 되돌리기는 현재 열린 편집의 최근40단계이며, 취소는 마지막 수정 사본 저장 때의 레이어(최초에는 없음)로 돌아간다. 편집 초안과 저장 시점은 프로젝트의 별도 textEdit에 보존하고 기존 즉시 workspace 저장을 이용한다. 프로젝트 JSON 가져오기에서도 원본과 레이어를 검증·복원한다. PNG는 평면 이미지이므로 PNG만 다시 열면 레이어를 복구하지 못한다. 프로젝트를 함께 보관해야 한다.

수정 사본 저장은 원본 다운로드와 별도이며 PNG로 출력한다. 원본 생성 asset, 상품사진, 기존 copy/규격 및 과금 데이터는 변경하지 않는다. 원본 이미지가 바뀌어도 기존 글씨 편집은 편집을 시작한 원본에 묶여 유지된다. 새 AI 결과에 자동으로 옮겨붙이지 않는다. 현재 진입점은 완성 광고 비트맵용이다. 별도 레이어를 이미 쓰는 직접 합성·규격 제어 모드, 별도 규격분석 오버레이, AI 예시 고지 합성이 필요한 텍스트 예시 모드에는 기존 편집을 유지한다.

자동 보관 실패 시 기존 workspace 경고/이탈 보호를 사용하며, 명시적 사본 저장의 프로젝트 저장 실패는 PNG 내보내기도 중단한다. 글씨 편집 모듈은 AI API, 생성 POST, 결제/크레딧 API를 호출하지 않는다. 이미지30MP·원본 dataURL14MB·내보내기 PNG10MB 제한을 적용한다. 이 제한 때문에 저장 실패해도 원본과 초안을 유지한다.

검증은 로컬 모의 원본과 네트워크 차단/관측으로 수행한다. 요청된 Library 예시 libfile_8844bfc850b48191bb798a5d45b19cef의 다운로드는 helper의 download failed로 실패했으며 해당 실제 이미지 검사는 미완료다. 실기기 업데이트 설치, 키보드/색상 선택기, Android 저장·공유 및 재실행 복구는 기기에서 확인해야 한다. 기존 동일 서명을 재사용하며 유료 AI나 운영 서버 변경을 실행하지 않는다.

## Play 준비와 이번 산출물 구분

동일 웹 빌드로 demo APK와 demo AAB를 만든다. 둘 다 com.selluplabs.aiadcast.next.demo / 0.2.49-demo / code51이며 기존 시연키를 사용한다. debuggable=false, ALLOW_TEST_CONFIG=false, target/compile SDK36, minSDK29, 인터넷 권한만 선언한다. 신규 키·Play 서명 설정·스토어 등록·업로드·운영 배포는 실행하지 않는다. 기존 외주 앱 com.selluplabs.aiadcast와 무관하다.

AAB 생성은 Play 제출 승인이나 심사 통과를 뜻하지 않는다. `.demo`라는 문자열 자체가 제출 금지 사유는 아니지만 패키지는 최초 등록 전에 영구 ID로 확정해야 한다. 현재 시연용 키를 업로드키로 등록할지, Play App Signing의 앱 서명키를 어떻게 설정할지, 안전한 키 보관은 소유자 결정이 필요하다. `release` 타입은 별도 서명 미설정이며 이번에 변경하지 않는다.

읽기 점검 결과 남은 항목:
- 현재 토스 `test_orders`/test API 기반 결제이며 Play Billing 연동은 없다. 디지털 생성 크레딧 판매는 Google Play 결제 또는 적격 대체결제 프로그램 요건 검토가 필요하다. 실제 결제로 전환하지 않았다.
- `server/password-auth.mjs`는 테스트 비밀번호 로그인이다. 이메일 주소 소유 인증·운영 계정 복구가 완료됐다고 볼 수 없다. 관련 UI나 운영 인증을 이번에 변경하지 않는다.
- 공개 개인정보처리방침 URL, 계정 삭제 요청 경로, 보유/삭제 정책, Play 데이터안전 설문과 앱 접근 심사용 계정 설정을 이 저장소만으로 완료 확인하지 못했다. 소스 내 사용자 계정삭제 화면·엔드포인트도 확인되지 않았다.
- 스토어 이름·아이콘·스크린샷·등급·콘텐츠/데이터 신고와 테스트트랙 설정은 Console에서 확인해야 한다. 현재 표시 이름은 aiadcast 시연이다.
- 새 개인 개발자 계정의 프로덕션 접근에는 해당하는 경우 최소12명/연속14일 비공개 테스트와 신청 심사가 필요하다. Console 계정 종류·상태는 조회하지 않았다.

공식 기준(확인일 2026-10-19): [결제 정책](https://support.google.com/googleplay/android-developer/answer/9858738), [앱 서명](https://developer.android.com/studio/publish/app-signing), [앱 생성](https://support.google.com/googleplay/android-developer/answer/9859152), [개인 계정 테스트 요건](https://support.google.com/googleplay/android-developer/answer/14151465).

최신 사용자 지시로 Google Play 준비는 보류했다. 이후 추가 조사·설정·등록·AAB 재빌드를 하지 않는다. 시연 APK만 전달하며 기존 AAB는 최종 전달 대상이 아니다. 최종 화면 검증에서는 긴 세로 이미지의 상속된 최대 높이 제한을 제거해 표시 영역과 편집 좌표가 일치하도록 했다.
