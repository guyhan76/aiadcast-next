사용 확정한 광고 아래에 **규격 안내 이미지**와 별도 **규격 안내 이미지 저장** 버튼을 제공한다. 광고 저장은 기존 파일을 그대로 출력한다. 안내 파일은 `aiadcast-dimensions-{rectangular|flat|cylindrical}.png`, 1920×2080px다. 안내 도식의 SVG 미리보기와 PNG는 동일한 결정적 벡터 명령을 사용한다. 숫자 생성·사진 분석·추가 AI 요청을 하지 않는다.

## 저장된 규격과 치수 기준

데이터는 현재 폼이 아니라 생성 당시 `GeneratedAsset.specificationKey`의 축별 규격과 `dimensionPlan` 스냅샷에서 읽는다. 저장된 canonical mm 문자열을 반올림·재환산하지 않고 출력한다. 예를 들어 cm로 입력한 치수가 저장 시 450mm가 됐다면 안내에는 `450 mm`를 표시한다. 단위 없는 숫자나 용량을 치수로 바꾸지 않는다. 현재 폼의 치수·이름 수정으로 이전 스냅샷을 덮어쓰지 않는다.

규격 기반 생성의 치수 기준에 `상품 본체 내부`와 `본체 · 내부/외부 미지정`을 추가했다. 기존 외곽·펼친 의류 기준도 유지한다. 서버에서 허용된 기준을 재검증하여 저장하고, 내부/외부를 변환하거나 벽 두께를 추정하지 않도록 생성 지침에도 명시한다. 평면 픽셀 보정은 기존 외곽 기준만 지원하며 내부/미지정 기준으로 실행하지 않는다.

이전 결과에 명시적인 치수 기준이 없으면 **치수 기준 미지정 · 내부/외부 확인 필요**라고 표시한다. 내부/외부 기준을 이전 결과에 소급해 만들어 넣지 않는다. 기존 결과에 저장된 유효 규격만 있으면 추가 생성 없이 도식을 내려받을 수 있다.

## 형상 범위

- 직육면체: 가로 W·깊이 D·높이 H에 공통 배율을 적용한 사투영 본체 도식. 깊이의 화면 벡터는 `(0.6D, -0.4D)`다. 치수선·화살표와 W/D/H 색상 표기를 정확한 mm 범례로 연결한다. 열린 날개·손잡이는 본체 높이에 포함하지 않는다.
- 평면: 입력 가로 W·세로 L의 직사각형. 두께를 지어내지 않는다.
- 원통: 입력 지름 Ø·높이 H의 원통 도식. 용량에서 지름·높이·벽 두께를 역산하지 않는다.
- 의류·가방·신발·주얼리·패션잡화·쇼핑백·파우치 및 펼친 의류 기준은 지원하지 않는다. 사진에서 실제 형상을 자동 식별하는 기능이 아니며, 저장된 규격 형식의 기하학적 설명 도식이다.

누락·잘못된 숫자·규격 없는 서비스 또는 읽기 어려운 극단적인 비율에는 저장 버튼 대신 이유를 표시한다. 표시를 위해 입력 비율을 임의로 바꾸지 않는다. 모든 안내 이미지에는 **생성 사진의 실측 결과가 아님 / 제조 도면·CAD·공차 보증이 아님**을 표시한다.
