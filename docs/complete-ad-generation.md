# 완성형 원페이지 광고 생성 · 2026-10-13

이전 자동 캠페인은 사진만 생성한 뒤 앱의 고정 표제·3열 장점·규격·푸터 틀에 넣어 사용자가 요청한 완성형 원페이지 광고와 달랐다. 자동 캠페인은 모델 고정과 기존 인증·예약·검토·수락 원장을 유지하면서 완성 광고 페이지를 생성하도록 변경했다. 기존 결과를 새 형식으로 소급 해석하지 않는다.

## 입력과 결과

- 규격 상품: 원본 및 추가 참조 사진, 상품명·재질·설명, 명명된 mm 축과 비율을 함께 전달한다. 표시를 켠 경우에만 선택 단위로 변환한 치수와 선택적 치수선을 광고에 요청한다. 클라이언트의 임의 규격 문자열 대신 서버가 검증한 축 값으로 표시 지침을 만든다.
- 규격 없는 상품: 참조 사진과 설명을 사용하고 수치·치수선·규격표를 만들어 넣지 않는다.
- 서비스: 사진 없이도 광고 내용으로 생성할 수 있다. 서비스 업종별 연출을 선택하고 상품이나 규격을 발명하지 않는다. 제공하지 않은 시설·성과·보장·자격·요금·조건을 만들지 않는다.
- 상품·서비스명, 승인 문구, 제공 장점·수량·가격, 표시를 켠 회사명·전화·이메일·URL을 포함하는 한 장의 광고를 요청한다. 숨긴 푸터 정보는 공급사 요청에서 제외한다. CTA는 명시적으로 요청할 때만 넣는다.
- 일반적인 재질·구조 정확성 지침과 B골의 두 라이너/한 겹 골 구조 지침을 추가했다. 구조가 확인되지 않은 내부 단면을 만들지 않으며 습기에 강하다는 설명을 방수 실험으로 과장하지 않는다.

## 이미지 처리와 수정

서버가 반환한 composition 메타데이터를 작업 이력에 저장한다. 완성 광고는 사진 전용 결과와 구분해 페이지 전체를 균일 배율로 미리보기·수락·PNG 출력한다. 고정 캠페인 틀, 중복 문구, 새 치수선이나 푸터를 다시 덧씌우지 않는다. 9:16 네이티브 864×1536 결과는 1080×1920으로 출력한다. 다른 비율 저장은 자르거나 늘이지 않고 여백을 추가한다. 1.91:1의 네이티브 16:9 결과도 여백을 두어 1200×628로 맞춘다. 비율 저장 자체는 공급사를 호출하지 않는다.

완성 광고 렌더러 지원은 요청의 문구 스냅샷으로 구분한다. 이 필드가 없는 구형 설치 APK에는 기존 사진 전용 결과를 반환해, 완성 광고를 다시 고정 틀에 넣는 오류를 막는다. 웹 앱을 배포해도 APK 안의 화면 코드가 자동 업데이트되지는 않는다. 설치형 앱에는 최신 웹 자산을 포함한 APK 재빌드와 실제 설치 확인이 필요하다.

완성 이미지의 글자는 합쳐져 있다. 문구·가격·상품명·언어·규격 표시/단위·치수선·공개 연락처가 바뀌면 입력 스냅샷이 달라져 이전 결과의 적용·수락·출력을 막는다. 원래 정보로 복원하거나, 새 생성 버튼으로 명시적으로 다시 요청해야 한다. 자동 재생성이나 자동 추가 차감은 없다. 새 생성은 현재 시험 이용권 예약 흐름을 따르며 부분 AI 편집은 구현하지 않았다. 이전 사진 전용 결과와 원본 사진 합성은 기존 수동 편집을 유지한다.

## 검증 범위와 한계

이미지 바이트·해시·디코딩·네이티브 크기, 공개 입력·표시 조건, 원장 처리, 스냅샷 변경 시 이전 광고 차단을 코드로 검증한다. 사람의 상품/재질/치수/가격/문구 검토 전에는 수락하지 않는다. 모델의 자체 점검 지침은 OCR·잘못된 골 구조 검출·상품 동일성·실물 3D 재현의 자동 검증이 아니다. 완성 광고 전체를 상품 윤곽으로 측정하지 않도록 자동 비례 비교 대상에서 제외한다. 기존 깨끗한 정면/측면/윗면 참조 사진의 제한적 두 축 비교는 유지한다.

9:16 프롬프트에는 보수적인 내부 여백을 요청한다. 플랫폼 UI·게시 위치·기기별 가림은 실제 게시 전 확인해야 하며 안전 영역을 실측 검증했다고 표현하지 않는다. 내장 이미지 생성 도구로 확인한 단일 우체국3호박스 시안은 앱의 Render 공급사 호출 결과나 모든 업종 품질 검증으로 계산하지 않는다.

출원 내용의 정확한 청구항은 이 문서에서 확인하지 않았으며, 이 변경을 특허 구현 완료·등록 특허·보증 대출 승인 근거로 주장하지 않는다. 실제 결제·이미지 글자 부분 수정·일반 상품 3D 자동 인증은 별도다.

검증: 도메인 테스트, TypeScript/Vite/단일 HTML 빌드, PostgreSQL 변환 일치와 diff 검사. 승인한 내장 생성 시안으로 Native Canvas의 9:16·1:1·16:9 출력을 확인했고 추가 텍스트 그리기 0회, 전체 광고 그리기 1회, 검토/수락 출력 픽셀 일치를 확인했다. 새 Render 키 호출은 실행하지 않았다.
