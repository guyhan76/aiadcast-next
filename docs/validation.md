- 브라우저: **서로 다른 36개 검사 통과**(PC/모바일 각 18개). 기존 편집/요금 26개는 전체 실행에서 통과했다. 새 제작 8개와 추가 저장 전환 2개는 수정 후 각각 실행해 통과했다. 실패한 검사를 제외하거나 조건을 완화하지 않았다.

## 브라우저 기능 검사

`npm test`: **12개 통과, 실패·건너뜀 0개**. Desktop Chrome 설정과 Pixel 7 화면 설정으로 각 6개 시나리오를 실행했다.

1. 상품 사진 업로드 → 문구·언어·배경·비율 변경 → 백업 파일에서 원본 바이트와 SHA-256 동일 확인. 한/영 문구가 별도로 보존되는지 확인.
2. 규격 변경 → 기기 저장 → 새로고침 → 작업 다시 열기 → JSON 가져오기에서 원본과 치수 복원 확인.
3. 두 출력 비율의 실제 다운로드 PNG가 1080×1920 / 1080×1620인지 검사. 단색 테스트 사진의 내부 대표 픽셀 색상 유지 확인.
4. 상품 사진 누락, 음수 규격, 텍스트 넘침에 대한 내보내기 차단 확인.
5. 치수 값·치수선 위치 수정과 되돌리기, 표시 설정 보존 확인.
6. 320 / 390 / 768 / 1440 px 너비에서 각 편집 탭의 가로 넘침과 JavaScript 오류가 없는지 검사.

첫 실행에서 4건은 textarea의 암시적 레이블 텍스트를 찾는 테스트 선택자가 맞지 않아 시간 초과가 났다. 실제 접근성 이름으로 textbox를 찾도록 수정했고 모든 검사가 통과했다. 검사나 검증 조건을 제거하지 않았다.

## 이번 검증이 보장하지 않는 것

- 테스트 입력은 합성한 단색 PNG다. 사용자가 업로드했던 원본 `18606.jpg`는 아직 없으므로 실제 상품의 로고·인쇄·모서리 보존 품질은 별도 검증 대상이다.
- 원본 파일 바이트 보존과 최종 합성 PNG의 모든 픽셀 일치는 서로 다르다. 최종 출력은 배율·리샘플링·문구·치수선 합성이 적용된다.
- 단일 사진으로 치수와 입체 형상을 복원하지 않는다. 치수선은 입력값을 수동 위치에 표시한다.
- 자동 배경 제거, 마스크/영역 편집, AI 이미지 생성, 자동 번역, 맞춤법 교정, 추가 언어, 결제·인증·서버 저장은 미연결이다.
- 모바일 검사는 Chromium 화면·터치 에뮬레이션이다. Android 실제 기기, iOS Safari, APK/AAB, Google Play 심사는 미검증이다.
- 상용 앱이나 공개 체험 URL을 배포하지 않았다. 회사 홈페이지 작업 트리는 변경 없이 유지했다.

## 규격 표시 선택 개선

- 소비자 선택을 ‘표시 안 함 / 규격 요약만 / 요약과 치수선’ 라디오 버튼으로 통합했다. 기존 프로젝트 데이터는 그대로 사용한다. 규격 정보 없음 선택 시 표시를 끄며, 나중에 치수 입력 형식을 바꿔도 사용자 선택 없이 자동 표시하지 않는다.
- 타입 검사·프로덕션 빌드 통과. 이번 변경에 관련된 Playwright 8개 검사 통과(PC·모바일 각 4개). 저장·다시 열기 후 숨김 설정과 치수가 유지되는지 확인했다.
- 실제 다운로드 PNG를 비교하여 숨김/요약 모드에서 상품 영역 픽셀이 동일하고, 치수선을 켤 때만 해당 영역이 바뀌는지 검사했다. 규격 요약 영역 역시 설정에 따라 표시·숨김되며 원본 파일 바이트와 치수는 유지됨을 확인했다.
- 화면 캡처: docs/previews/dimension-choice-mobile.png. 공개 Google Play 앱에 배포한 변경이 아니라 현재 편집 검증판의 변경이다.

## 이미지 제작 방식 선택

- 원본 보존(기본)/규격 참고 창작을 업로드 단계에 추가하고 기존 프로젝트는 원본 보존으로 호환했다. 제작 방식·창작 문구를 저장/복원하며 원본 사진·규격 표시 선택은 유지한다.
- `npm run build` 통과. `npm test` 브라우저 **18개 통과**, `npm run test:domain` **21개 통과**. 창작 선택의 기기 저장·JSON 가져오기·모드 복귀, 원본 바이트 보존, 숨김 규격의 창작 참고값 유지·검증, 창작 모델의 원본 보존 주장 차단을 포함한다.
- 창작 모드에서는 ‘생성 전·참고 사진’으로 구분하고 실제 AI 연결 전 출력/생성을 비활성화했다. 생성한 결과처럼 위장하지 않는 상태를 PC·모바일에서 확인했다. 창작 화면도 320/390/768/1440 px에서 가로 넘침이 없음을 확인했다.
- 실제 AI 생성 및 공개 앱 배포는 수행하지 않았다. 선택 화면은 docs/previews/generation-choice-mobile.png, 창작 대기 화면은 docs/previews/creative-mode-mobile.png에 있다.

## 광고 이미지 비율 확장

- 비율을 1:1, 4:5, 3:4, 9:16, 2:3, 16:9, 1.91:1로 확장했다. 픽셀·용도 정의를 공통 모듈로 관리하고 선택·저장·백업·가져오기·생성 요청에 적용했다. 1.91:1 출력은 표준 근사 크기 1200×628이다.
- 세로형·정사각형은 상하 배치, 가로형은 좌우 배치다. 모든 비율에서 서로 다른 종횡비의 원본 사진이 사진 영역 안에 균등 배율로 배치되는지 검증했다. 문구·규격 요약이 상품 영역과 겹치지 않고 캔버스를 벗어나지 않는지도 검사했다.
- 새 영역 검사에서 기존 9:16/2:3 설명의 세 번째 줄 배정 영역이 사진 영역과 약 2 px 겹치는 점을 발견했다. 설명 글꼴을 28→27 px로 조정하고 재검사해 통과했다.
- `npm run test:domain`: 24개 통과, 실패·건너뜀 0개. 원본/창작 요청 모두 비율과 최종 출력 픽셀을 유지하고 지원하지 않는 비율을 거절하는지 포함한다.
