# 무료·구매 이용권의 생성 예산 연결 — 2026-11-18

고도화 앱 개발 후보에 신규 회원 무료 1장과 구매 이용권을 이미지 생성 비용 원장에 연결했다. Render/Supabase 클라우드 경로에서는 검증된 누적 예산 정책을 적용하면 회원별 예산을 수동 배정하지 않아도 이용권으로 생성할 수 있다. 기존 외주 앱, 운영 서버, 실제 결제 설정은 변경하지 않았다.

## 동작

- 무료·구매 이용권은 기존 인증·영수증 검증 원장을 사용한다. 계정 권한·장수·가격·예산을 클라이언트 입력으로 신뢰하지 않는다.
- 기존에 승인된 총 100달러 누적 한도 안에서 관리자와 모든 회원의 비용을 함께 계산한다. 회원 추가, 월 변경, 재시작으로 한도가 새로 생기지 않는다.
- 공급사 호출 전에 비용을 예약한다. 이미지의 기본 예약액은 기존 0.50달러이며, 일부 편집 작업은 기존 추가 예약액을 유지한다. 성공 시 실제 비용으로 정산하고 정상 결과 제공 시 이용권을 차감한다.
- 확인된 실패는 이용권과 미사용 예약액을 돌려준다. 이미 발생한 공급사 비용은 보존한다. 응답 단절·사용량 불명은 이용권을 복구하되 비용 예약은 유지하고 같은 요청의 자동 재호출을 막는다.
- 실제 청구가 예약액을 초과하더라도 비용을 숨기거나 한도에 맞춰 잘라 기록하지 않는다. 초과분을 기록하고 후속 호출을 차단한다. 공급사 자체의 과금 상한을 설정하는 기능은 아니다.
- 기존 이미지·문구·추천 비용은 `budgets`에서 한 번만 집계한다. 별도 사진 분석 비용, 비활성 회원 비용, 과거 월 기록, 탈퇴 후 비용 합계를 포함한다. 기존 분석 시험은 새 회원 혜택으로 개방하지 않는다.
- 탈퇴 시 비용 합계와 미확정 예약액만 별도로 보존한다. 이메일·광고 파일·계정 ID를 비용 보관 표에 추가하지 않는다. 신규 무료 이용권 대상 기록도 함께 삭제해 탈퇴가 외래 키 제약으로 막히는 문제를 수정했다.
- 관리자 화면은 전체 공유 누적 한도와 광고 장수 잔액을 표시한다. 회원마다 100달러씩 배정된 것으로 표시하지 않는다.

## 운영 적용 조건

기본값은 비활성이다. 로컬 SQLite 베타 서버의 기존 수동 예산 정책은 그대로 유지한다. 새 공유 정책은 클라우드 PostgreSQL 경로에 구현했다.

1. 실제 운영 비용 내역과 기존 누적 정책을 확인한다. 생성 작업이 멈춘 상태에서 적용하며 기존 계정별 비용·보류액·외부 분석 기록을 삭제하거나 초기화하지 않는다. 이전에 이미 삭제된 기록을 이 코드가 복원하거나 증명하지는 못한다.
2. `AIADCAST_MEMBER_GENERATION_BUDGET_OWNER_ID`에 기존 100달러 누적 정책의 관리자 계정 UUID를 지정한다. 새 정책이나 금액을 임의로 만드는 설정이 아니다. 기존 정책, 관리자 권한, 비용 원장 대사, 외부 비용 기록 중 하나라도 확인되지 않으면 활성화를 거부한다.
3. 서버는 같은 예산 트랜잭션 잠금 안에서 공유 정책과 예약 차단 트리거를 설치한다. 활성화된 정책은 DB에 지속되며 환경변수 제거·재시작으로 월 예산 정책으로 되돌아가지 않는다. 소유 계정 변경·중지 등 정책이 무효화되면 새 비용 예약을 차단한다.
4. 롤백 시 공유 정책을 모르는 구버전으로 바로 되돌리지 않는다. 기존 테이블의 트리거는 구버전 SQL도 제한하지만 구버전이 새로 만드는 회원 테이블까지 보장하는 것은 아니다. 작업 정지 및 원장 점검을 포함한 별도 롤백 절차가 필요하다.
5. 누적 비용이 한도에 근접하면 신규 생성이 중단될 수 있다. 이용권 판매 개시 전 운영 한도와 판매 가능 수량을 함께 검토해야 한다. 이번 개발은 한도 상향이나 판매 개시를 수행하지 않는다.

검증된 공유 정책이 있어도 생성 스위치, 공급사 연결, 이용권 잔액, 저장 공간, 동시 작업 제한은 모두 적용된다. 회원용 별도 문구 API를 자동 개방하지 않는다. 실제 Google Play 결제·환불 및 운영 광고 품질은 별도 검증 대상이다.
