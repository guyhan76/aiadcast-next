## 실제 코드 반영

`server/openai-image-adapter.mjs`의 완성형 광고 경로에 다음을 보완했다.

- 호텔·숙박·여행: 실제 장소 중심의 주 사진과 제공된 보조 사진, 회원·숙박 조건을 묶는 구성 지침.
- 일반 서비스·기업 홍보: 실제 서비스 장면 또는 문구 중심으로 행사·채용·구독 내용을 설명할 수 있는 지침. 기존 교육 광고에서도 실제 행사에 해당할 때 일정 정보를 우선하도록 함.
- 행사명·날짜·장소, 구독 금액·주기, 채용 역할·시간·급여 조건을 서로 분리하지 않도록 명시.
- 차량 정면 사진도 참조 구도로 존중. 참고 광고의 차량 나열이 실제 재고·배송·시승 보상을 입증하는 것으로 해석되지 않도록 함.

이 지침은 기존 상세설명·업종·광고 목적·사진 용도를 활용한다. 새 소비자 입력 단계나 행사·채용 전용 화면을 구현한 것은 아니다. 여러 차종별 사진·가격·재고를 구조적으로 연결하는 기능도 아직 별도 개발 사항이다. 동일 장소의 여러 사진을 한 장에 정돈하는 것은 이 기능과 구분한다.

모델·생성 수량·품질 설정·예산은 유지하고 생성 지침 revision을 `v15-service-reference`로 변경했다. 유료 이미지 생성, 원격 서버 배포, APK 재빌드 또는 Play 등록은 수행하지 않았다. 완성 이미지에서 정확한 글자와 원본 동일성이 보장되는 것은 아니므로 실제 결과 확인이 필요하다.

## 비교할 품질 기준

- 한 번에 읽히는 제목과 하나의 우선 메시지.
- 실제 상품·장소·인물·화면의 동일성과 관계 유지.
- 금액·날짜·시간·최대·월 단위 등 조건의 정확성 및 가독성.
- 사진 장수에 맞춘 정돈된 구도. 없는 자료를 채우려고 사실을 만들지 않음.
- 원본 비율을 지키고 9:16 등 출력 비율에 맞춰 재배치. 첨부 예시 자체를 모두 9:16으로 취급하지 않음.
- CTA 선택을 존중하고 화면에 겹친 플랫폼 이동 화살표를 자동 복제하지 않음.

검증: 기존 업종·자동차·완성 광고·사진 용도·이미지 연출 관련 도메인 검사 24건 및 PostgreSQL 파생 코드 일치 검사 통과. 모의 공급사 호출을 포함한 코드 검사이며 실제 생성 품질 비교 결과가 아니다.
