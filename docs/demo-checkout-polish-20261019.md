# 시연 화면과 결제 표시 정리 · 2026-10-19

APK 0.2.46은 0.2.45의 사진 필수 제작, 제거된 옵션, 결과 복구와 크레딧 보호를 유지한다.
상단 버전 배지는 사용안내 끝으로 이동한다. 일반 사용안내의 테스트 계정/서버 연결 도구는 숨기며, 기존 지원 도구는 명시적 `?support=1#guide`에서만 표시한다. 이 경로는 인증 또는 서버 권한을 부여하지 않는다.

결제 동작 버튼은 ‘결제’, 동의 문구는 ‘이용권 수량과 금액을 확인했습니다’다. 동의 전 비활성은 유지한다. 결제 화면에는 ‘시연용 · 실제 청구 없음’을 표시하며 실결제 전환이나 결제 키 변경은 없다. 실패·취소·조회 오류를 성공으로 바꾸지 않는다. 구매 영수증 확인, 중복 지급 방지, 기존 입력 복귀를 유지한다.

운영 a0931d7에는 `/api/version` 경로가 없다. 앱에 값을 하드코딩하거나 앱 commit을 서버 commit으로 표시하지 않는다. 서버 후보 `fix/public-server-version-20261019`는 운영 코드 기반에 공개 읽기 전용 조회를 추가한다. 응답은 package 버전과 검증된 RENDER_GIT_COMMIT 또는 실제 저장소 HEAD만 사용한다. 기존 Android 출처 허용과 인증/결제/예산 정책은 유지한다. 서버 업데이트 전의 조회 실패는 그대로 안내한다.

앱 브랜치는 `fix/demo-checkout-polish-20261019`, 서버 후보는 `fix/public-server-version-20261019`로 구분한다. APK 브랜치를 운영 서버 배포 대상으로 대체하지 않는다. 운영 배포는 수행하지 않는다. 운영 서비스·브랜치·환경 확인 후 서버 후보의 정확한 commit 배포와 Android 출처 GET /api/version 확인이 남는다. 실제 서버 로그인 정보나 테스트 결제 승인은 추측·생성하지 않는다.
