# 한국 Google Play 공용 크레딧 충전

베타 계정은 0크레딧으로 시작합니다. 이미지와 AI 영상이 한 잔액을 사용합니다. 이미지 1장은 5크레딧, AI 영상은 초당 2크레딧입니다. AI 영상은 생성 요청을 보내기 전에 선택한 길이의 금액을 표시합니다. 기기에서 편집·저장하는 작업은 무료입니다.

| Play 상품 ID | 공용 크레딧 | 베타 기준 가격 |
| --- | ---: | ---: |
| `topup_50` | 50 | 18,000원 |
| `topup_100` | 100 | 33,900원 |
| `topup_250` | 250 | 79,900원 |
| `topup_500` | 500 | 159,900원 |

웹 베타 월간 구독은 플러스 33,900원, 비즈니스 79,900원, 울트라 159,900원입니다. 연간 결제 총액은 각각 310,800원, 742,800원, 1,486,800원입니다. 결제 주기와 관계없이 매월 100·250·500크레딧을 지급합니다. 연간 테스트 결제는 매월 같은 날짜를 기준으로 지급하며 말일을 보정합니다. 실카드 자동 갱신과 Play 정기결제 상품은 연결 전입니다.

앱 패키지는 `com.selluplabs.aiadcast.next`입니다. Play Console에 실제로 등록한 상품과 원화 가격을 구매 화면에 표시합니다. `credits_180`은 영수증 복원만 지원합니다.

### 내부 테스트 연결

1. 셀업랩스 조직 계정에서 이 패키지의 앱을 만들고 한국 판매용 상품에 기본 구매 옵션을 설정합니다.
2. 내부 테스트용 release AAB를 빌드할 때 `-PAIADCAST_API_ORIGIN`에 테스트 서버의 HTTPS 주소를 지정합니다. 회사 업로드 키로 서명해 내부 테스트 트랙에 올립니다. Preview와 시연 APK는 별도의 패키지를 사용합니다.
3. 백엔드의 Google 서비스 계정에 해당 앱 구매 조회 및 처리 권한을 부여하고 Android Publisher API를 활성화합니다. 테스트 서버의 비밀 파일 경로를 `AIADCAST_PLAY_SERVICE_ACCOUNT_FILE`에 설정하고 `AIADCAST_PLAY_BILLING_ENABLED=true`로 연결합니다.
4. Play Console의 내부 테스터와 라이선스 테스트에 구매용 Google 계정을 추가합니다. 내부 테스트 초대 링크를 통해 앱을 설치한 뒤 테스트 결제수단이 표시되는지 확인합니다.
5. 잔액 0인 일반 테스트 계정으로 네 가지 추가 충전 상품을 각각 조회합니다. 100크레딧 구매 후 같은 영수증을 재전송했을 때도 잔액이 100인지 확인합니다.
6. 이미지 한 장과 17초 AI 영상을 생성하고 화면에 표시한 금액만 차감되는지 확인합니다. 공급사 거절, 중복 요청, 재다운로드, 재로그인 후 잔액도 확인합니다.


운영 고객 계정은 Google 라이선스 테스트 영수증으로 충전할 수 없습니다. 내부 테스트는 별도 서버에서 진행하며, 운영 고객 설정과 잔액을 유지합니다.

서버는 Google에서 받은 구매 상태, 계정 식별자, 상품 및 수량을 검증합니다. 완료된 구매 토큰을 기준으로 크레딧을 지급한 뒤 소모 처리합니다. 운영 판매 전에는 스토어 환불·구매 취소 후의 잔액 조정과 앱을 다시 열지 않은 구매의 서버 재처리도 검증해야 합니다.
