# 실제 공급사 시험 — 2026-10-10

사용자가 **테스트 예산 $1, 이미지 1장과 문구 제안 1회**를 승인했다. 이 기록은 신규 aiadcast 개발용 테스트이며 상용 결제·운영 출시 완료가 아니다.

## 이미지 결과

- 실제 `POST /v1/images/generations`: HTTP 200. 모델 `gpt-image-2.5-sunburst`, high, 1024×1280(4:5).
- 가상 카페의 아이스 라테·실내 분위기를 요청했다. 참조 사진·규격 없이 만드는 서비스 창작 모드다. 실물 참조 사진 보존/사진 편집 능력을 시험한 결과가 아니다.
- 입력 텍스트 438 토큰, 이미지 입력 0 토큰, 이미지 출력 1,510 토큰.
- 기록된 요율 계산: `438 × $5/1M + 1510 × $30/1M = $0.04749`.
- 계획 환율 1,400원 기준 **약 66.486원**이다. 공급사 usage 기반 이미지 API 비용 추정이며, 실제 청구·세금·환전·스토어·저장·지원 비용이 모두 포함된 장당 사업 원가는 아니다. 이 한 장으로 평균 원가나 최대 원가를 확정하지 않는다.
- 육안으로 라테, 따뜻한 햇살, 크림·브라운 카페 공간을 확인했다. 뚜렷한 생성 문자·워터마크는 보이지 않았다. 실제 상품 동일성·광고 성과·다양한 입력 품질을 보장하지 않는다.

## 문구 결과

- 실제 `POST /v1/responses`: **HTTP 401 인증 오류**. 사용 모델 설정은 `gpt-5.4-mini`.
- 문구 결과를 얻지 못했다. 원인을 API 키 오류나 특정 권한 문제로 단정하지 않는다. 동일 키의 이미지 요청은 성공했으므로 Responses API 접근 설정을 추가로 확인해야 한다.
- 이후 읽기 전용 모델 정보 조회 `/v1/models/gpt-5.4-mini`는 HTTP 200이었다. 모델 조회 권한이 문구 생성 권한을 보장하지 않으므로 이 결과만으로 인증 원인을 확정하지 않는다.
- 공급사 문구 토큰 사용량은 반환되지 않았다. 서버 원장은 확정 거절을 0 비용으로 처리했지만, 계정 청구 내역과의 대조는 별도다.
- 추가 유료 재시도·새 모델 대체 호출은 하지 않았다. 발생한 요청은 이미지 1회, 문구 1회다.

## 이용권과 재사용

- 개발용 3개에서 이미지 요청 시 available 2 / reserved 1.
- 생성 결과를 검토한 뒤 승인: available 2 / reserved 0.
- 같은 결과를 다시 승인해도 available 2 / reserved 0으로 **중복 차감 없음**.
- 실제 생성 이미지를 포함한 프로젝트 JSON을 편집기에서 가져와 1080×1350 PNG로 내보냈다.

## 환경 게시 후 재확인

- 게시 후 관리 환경은 running, observations_current=true, 네트워크 enforced, 새 앱 비밀값 ready로 보고됐다. 준비 상태가 각 API 작업의 권한까지 보장하는 것은 아니다.
- 복원된 APK의 SHA-256이 기존 빌드 증거와 일치했다. 개발 서버를 다시 시작해 `/api/status` HTTP 200, 이미지·문구 비활성, 예산0, commercialReady=false를 확인하고 시험 서버를 종료했다.
- 읽기 전용 `/v1/models/gpt-5.4-mini` HTTP 200. 생성 모델과 입력을 전혀 지정하지 않은 빈 JSON의 `POST /v1/responses`는 HTTP 401, `invalid_api_key`를 반환했다. 이는 생성 시험이 아닌 인증/입력 검증 진단이며 추가 이미지·문구 생성 요청은 하지 않았다.
- 현재 증거만으로 원인을 키 권한, 비밀값 주입 또는 공급사 설정 중 하나로 단정하지 않는다. 사용자에게 기존 키의 All/Restricted 권한 종류를 확인 요청했다. 새 키 발급이나 비밀값 재입력은 요구하지 않았다.
- 문구 어댑터 관련 모의 테스트12개 통과. 실제 문구 생성 성공과 별개의 결과다. 안전하게 추린 진단 정보는 `release/live-test-2026-10-10/post-publish-auth-check.json`에 저장했다. 비밀값이나 원문 인증 오류 메시지는 기록하지 않았다.

## All 권한 확인 후 문구 연결 복구

사용자는 기존 키의 권한이 All임을 확인했다. 동일 인증·빈 JSON으로 비교한 결과 images/generations와 chat/completions는 필수 입력 누락 HTTP400, responses만 invalid_api_key HTTP401이었다. 이 비교와 이전 이미지 성공만으로 Responses의 근본 원인을 특정하지는 않는다.

- 문구 어댑터를 공식 Chat Completions 경로로 변경했다. 모델은 기존 `gpt-5.4-mini`를 유지한다. JSON Schema, 출력 토큰 한도1,200, store=false, 사용자 검토, 연락처 분리, 숫자 차이 확인을 유지한다. 자동 재시도 또는 실패 시 다른 API로 자동 전환하지 않는다.
- 기존 승인 $1 공유 예산 안에서 문구 제안 1회를 재시험해 **HTTP200**을 확인했다. 이미지 추가 생성은 없다.
- 제목: “오늘의 여유, 한 잔의 라테.” / 설명: “가상 카페 테스트. 아이스 라테 6,000원.” 가격 유지, 추가·누락 숫자0. ‘가상 카페 테스트’라는 입력 설명도 문구에 포함되어 있어, 상용 문구 품질과 내부 설명 구분은 추가 평가가 필요하다. 이 결과는 연결·사실 보존 최소 확인이며 최고의 광고 문구 품질을 입증하지 않는다.
- 입력409토큰, 출력42토큰. 기록된 요율과 올림 계산으로 **$0.000496**, 계획 환율1,400원 기준 약0.6944원. 이전 이미지와 합산 **$0.047986, 약67.18원**. 청구서·세금·환전·지원 등 사업 원가를 포함한 값은 아니다.

- `copy-chat-result.json`에 실제 응답·사용량·원장·중복 요청 검증을 저장했다. `endpoint-auth-comparison.json`에 민감 정보를 제외한 경로 비교를 저장했다.
