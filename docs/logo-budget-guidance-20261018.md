# 로고 색상과 관리자 예산 안내 — 2026-10-18

기준은 사용자가 운영 배포를 확인한 PR #13의 `81ccc452b02ce78c39ea8fd83aaef2697a1c69c6`이다. 후속 후보는 `fix/logo-admin-budget-guidance-20261018`이며 실제 배포는 별도다.

상단 헤더·하단 푸터가 공유하는 BrandLogo의 `ai` 글자만 `#FF8A00`으로 바꾼다. 공통 CTA·경고 팔레트, 검정 adcast, 로고 형태·크기는 유지한다.

관리자의 BUDGET_NOT_AVAILABLE 안내를 다른 관리자에게 문의하라는 문구에서 본인 계정의 월 배정·사용·보류액을 확인하는 안내로 바꾼다. 기존 인증된 /api/status 응답의 숫자만 표시하며 배정액/보류액 변경 요청은 하지 않는다. 예약금은 서버 응답을 표시하며 실제 1회 요금과 다름을 설명한다. 별도 승인 원본 사진 분석 예산과도 구분한다.

일반 광고 생성은 관리자 이용권이 면제돼도 `월 배정액 - 이번 UTC 월 사용액 - 보류액 >= $0.50`을 충족해야 한다. 초기 관리자 배정은 잔여 총예산 안에서 최대 $0.50이며 기존 계정의 역할만 바뀌면 배정액은 유지된다. 비용 미확정 요청의 보류는 안전장치로 남는다. 실제 운영 배정·사용·보류 수치는 아직 확인하지 않았으므로 부족한 항목을 단정하거나 증액/해제하지 않는다.

운영자가 확인할 위치: 관리자 → 승인 원본 사진 분석 아래 → 공급사 월예산/사용량 기준 비용 카드 → 회원 목록의 관리자 행. 카드는 전체 회원 합계이고 이번 안내 숫자는 로그인한 계정의 값이다.

이 변경은 생성 차단을 해제하거나 유료 생성 성공을 입증하는 수정이 아니다. 일반 분석 OFF와 기존 승인 한도, 서버 생성 비용 보호를 유지한다. 테스트는 로컬 대체 응답으로 예산 안내·읽기 전용 재조회·생성 POST 없음·모바일 화면을 확인한다. 최종 검사와 CI 증거는 후속 draft PR에 기록한다.

## 추가 로고 일관성 점검 — 2026-10-18

사용자 후속 요청에 따라 PR #15 후보에서 로고 전체를 조사했다. PR #14 운영본은 상단·하단만 `#FF8A00`으로 바뀌었고, 사이드바·상세 편집기의 독립 `.wordmark`·이메일 인증과 결제 전용 화면의 `.account-brand`에는 기존 `#B65A35`가 남아 있었다. 공통 `.brand-lockup`과 편집기 `.wordmark`의 **ai 부분만** 모두 `#FF8A00`으로 통일한다. 검은 adcast, 작은 삼각형, 버튼·강조·광고 색상은 유지한다.

홈·제작·내 프로젝트·안내·로그인·가입·결제·관리자·상세 편집기·이메일 인증·결제 창·결제 복귀 경로를 데스크톱/모바일 브라우저에서 실제 계산된 색상으로 확인한다. 별도 로고 SVG/PNG는 웹 런타임 자산에 없다. `BrandFooter`는 고객 회사/연락처 입력 컴포넌트이며 앱 로고가 아니다. 초기 `aiadcast…`는 꾸밈없는 로딩 상태 텍스트이고, 관리자/요금 페이지의 `AIADCAST / …`도 일반 구분 텍스트다.

저장소의 Android 실행 아이콘 `android/app/src/main/res/drawable/ic_launcher.xml`은 검은 바탕·흰색 a·`#FF761F` 삼각형으로 된 별도 자산이며 ai/adcast 워드마크가 아니다. 아이콘과 네이티브 `colorAccent=#B65A35`는 변경하지 않았다. WebView에 새 웹 번들을 포함해 다시 빌드하면 내부 웹 로고 수정이 포함되지만, 기존 설치 APK나 스토어 아이콘이 자동 변경되는 것은 아니다. APK 재빌드·설치·실기기 검증은 이번 작업에서 하지 않았다.
