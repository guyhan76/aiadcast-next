# 부분수정 PostgreSQL 및 출력 검수 — 2026-11-08

PR: https://github.com/guyhan76/aiadcast-next/pull/61

부분수정과 비용 원장의 실제 PostgreSQL 검사를 실행했다. 출력한 원본 보존 합성본은 제품과 문구의 접점이 부자연스러워 광고 품질 불합격으로 기록했다. 운영 활성화나 광고 사용 승인 보고가 아니다. 사용자 사진·사진 파일명·사진 해시·새로 조정한 마스크 데이터는 이 후속 기록에 포함하지 않는다.

## 코드 변경

- GitHub Actions에 격리된 PostgreSQL 17 서비스와 전용 검사 작업을 추가했다. Unix 소켓을 사용하며 운영 DB·API 키·유료 이미지 공급사에는 연결하지 않는다.
- 기존 실제 PostgreSQL 검사에서 원본과 수정 응답이 동일했던 낡은 픽스처를 수정했다. 합성한 테스트용 제품 사진, 최초 광고, 수정 응답을 서로 다른 바이트로 검사한다.
- 새 서비스 인스턴스에서 연속 수정해도 최초 제품 사진을 유지하는 검사와, 무변경 응답이 고객 예약을 해제하면서 공급사 지출은 기록하는 검사를 추가했다.
- 기존 오프라인 검수 스크립트에 `--preview 새파일.png`를 추가했다. 앱의 실제 합성 함수를 사용하고 `wx` 쓰기로 기존 파일 덮어쓰기를 거절한다. 기존 픽스처 마스크를 유지하며 자동 제품 분할이나 새로운 이미지 생성 기능은 아니다.

## 출력 검수 결론

기존 후보를 사용했으며 이번 검사에서 새로운 이미지 생성 호출은 0회다. 최초에는 메모리에서만 검사했던 합성 결과를 파일로 내보내 확인했다. 선택 밖 픽셀 보존 성공과 별개로 기존 제품 조각과 각진 접점이 남을 수 있음을 확인했다. 이전 문서의 메모리 검사 결과를 광고 품질 통과로 해석하면 안 된다.

마스크 범위를 조정한 검토용 사본에서도 문구 옆 제품 경계가 부자연스러워 광고 사용 불합격으로 기록했다. 조정한 사본과 상세 사진 메타데이터는 별도 검토 자료로 유지한다. 제품의 내측이 보이지 않는 결과로 내측 디자인 보존을 검증할 수 없으며, 제품 동일성도 최종 합격으로 처리하지 않는다.

## 운영 전 남은 조건

- 문구·제품 접점을 정확히 지정하고 그림자·끈 경계의 시각적 결함을 해결한 후 다시 비교한다. 픽셀 보존 판정과 제품/합성 품질 판정을 분리한다.
- 실제 다중 참조 + 마스크 공급사 호출과 사용량·비용 상한을 검증한다. 500,000 microUSD 예약은 실제 청구 상한 보장이 아니다.
- 전체 원격 브라우저 검사 완료, 증빙 업로드 용량 문제, Android 실기기 및 큰 이미지 동시 처리 검증이 남아 있다.

`selectiveEditingEnabled`와 `selectiveEditReady`는 비활성을 유지한다. 운영 병합·배포·DB·키·예산 설정 변경은 없다.
