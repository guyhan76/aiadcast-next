## 실제 원인

## 수정과 경계

- 생성 전에 사진 치수선 없음/본제품 직접/같은 제품 작은 사진을 선택하고 프로젝트 초안·저장·복구에 보존한다. 기존 숫자 요약 설정과 사진 치수선을 구분한다.
- 사진 치수선을 선택하면 새 광고 요청에서 숫자 요약을 표시하지 않도록 한다. 생성 모델의 결과를 사진 규격 표시 완성으로 판정하지 않는다.
- 원본 광고 검수를 별도로 안내한다. 선택한 후처리에 위치 정보가 없거나 원본/치수가 바뀌면 완성본 저장을 막고 미완료 상태를 표시한다. 원본 광고는 원래 바이트로 별도 저장하며 파일명과 버튼에 후처리 없음이 표시된다. 기존 프로젝트/생성 이미지는 덮어쓰지 않는다.
- 사용 가능한 자동 분석 capability가 확인된 경우에만 자동 위치 요청을 시작한다. 실패·중단 후 선택을 보존하고, 시도 상태도 저장해 새로고침으로 자동 재호출하지 않는다. 재시도는 명시적 동작이다. 분석 OFF일 때 다시 확인은 GET뿐이다.
- 유효하고 현재 원본에 대응하는 위치 정보가 있으면 기존 실제 원본 픽셀 crop과 벡터 치수선 합성을 사용한다. 위치 수정은 자동 결과 뒤 선택사항이다. 안전한 빈 영역/축/문구 충돌 검증 실패는 완료로 표시하지 않는다. 물리적 실측 또는 3D 비례 검증은 아니다.
