# 한국어 출시 요금 개발 기록 — 2026-11-18

후속 개발: 무료·구매 이용권의 클라우드 생성 예산 연결은 [생성 예산 개발 기록](member-generation-budget-20261118.md)을 따른다. 아래 내용은 요금·무료분 지급 단계의 검증 시점 기록이다.

기준: 고도화 앱 0.2.113의 저장·공유 수정본(34622c3)에 미배포 Google Play 결제 코드(f4174cc)를 통합한 개발 후보입니다. 기존 외주 앱은 변경하지 않았습니다.

## 반영한 확정 가격

| 구분 | 광고 수 | 내부 크레딧 | 금액 |
| --- | ---: | ---: | ---: |
| 신규 가입 혜택 | 1장 | 10 | 무료, 계정당 1회 |
| 소량 이용권 | 3장 | 30 | 3,300원 |
| 기본 이용권 | 10장 | 100 | 9,900원 |

- 요금 안내와 구매 선택은 광고 장수를 중심으로 표시합니다. 신규 요금의 달러 가격을 만들지 않았으며, 기존 USD·판매 종료 상품 선택값은 현재 원화 상품으로 전환합니다.
- 웹 견적과 표시 가격은 동일한 카탈로그를 사용합니다. Android 구매 화면은 Google Play가 반환한 원화 가격을 표시하므로 Console 상품 가격도 별도로 맞춰야 합니다.
- 기존 결제 대기 주문은 주문 당시 금액·크레딧을 유지합니다. 180크레딧 상품은 신규 목록에서 제외하되 기존 구매 영수증은 복구할 수 있습니다.
- 이메일 인증·Google·시험용 비밀번호 신규 가입에 무료분 대상 여부를 기록하고, 서버가 이를 확인해 지급합니다. 반복 로그인·동시 요청·재시작으로 추가 지급하지 않습니다. 무료분을 실제 구매 매출로 기록하지 않습니다.
- 정상 결과 제공 시 무료분 10크레딧을 사용합니다. 시스템 실패 시 복구하며, 취향 반려만으로 다시 지급하지 않습니다. 기존 회원 잔액·관리자 권한·공급사 예산 한도는 유지합니다.

## 남은 출시 작업

1. **실제 무료 생성의 예산 연결:** 신규 회원의 서버 생성 예산은 아직 0입니다. 이번 변경은 무료 1장에 해당하는 크레딧 지급까지 구현했습니다. 운영 무료 생성과 구매 후 연속 생성에는 기존 총 지출 한도 내 회원 예산 배정·회수 흐름을 연결하고 검증해야 합니다. 비용 한도를 임의로 늘리지 않았습니다.
2. **실제 Play 결제:** 조직 계정·상품 가격 설정, 서비스 계정 연결, 회사 업로드 키를 이용한 내부 테스트 설치가 필요합니다. 현재 실제 결제·소모 처리·환불·스토어 제출은 검증하지 않았습니다.
3. **배포와 기기 확인:** 이 후보는 로컬 변경입니다. GitHub 공개 업로드·운영 서버 배포·새 APK/AAB 빌드·실기기 저장/공유 시험을 진행하지 않았습니다. 이번 Android 확인은 웹 자산 패키징과 브라우저에서의 파일 저장 브리지 모의 검사까지입니다.
4. **출시 일정:** 한국어 이미지 광고 앱을 우선하며, D-U-N-S 및 통신판매업 접수 이후 스토어 진행이라는 기존 방향을 유지합니다.

다음 개발은 총 비용 한도를 유지하는 무료/구매 회원의 생성 예산 처리부터 이어갑니다.
