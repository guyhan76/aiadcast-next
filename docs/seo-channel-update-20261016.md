# 추천 채널 및 SEO 검색어 개선 · 2026-10-16

## 문제와 결과

기존 로직은 포장재·기업 업종의 채널을 홈페이지·상세페이지와 블로그로 제한했다. 검색어는 상품명·회사명·업종명 뒤에 소개·선택 가이드·상세 정보 등을 붙여 항상 6개를 채웠다. 상품 관련 검색 의도가 약한 문구가 추천되는 문제가 있었다.

채널의 우선순위는 업종·광고 목적을 유지하되 인스타그램, 유튜브·쇼츠, 홈페이지·상세페이지, 블로그, 기업 홍보물·제안서와 룩북을 함께 제안한다. 유튜브와 기업 홍보물의 활용 가이드·게시글 초안·이미지 저장 비율도 연결한다. 정지 이미지 출력이며 영상 제작이나 다중 페이지 문서 제작이 연결된 것은 아니다.

SEO 후보는 실제 상품명을 먼저 두고 해당 품목·용도의 관련 명사를 사용한다. 상품명으로 세부 품목을 구분하며 우체국박스와 선물박스, 공기청정기와 다른 가전, 영어 수업과 코딩 수업의 후보를 분리한다. 명시된 지역은 관련 검색 표현에 반영하고 연락처·가격·회사명을 후보 채우기에 사용하지 않는다. 일반 상품처럼 정보가 부족하면 개수를 억지로 늘리지 않는다.

## 저장 및 비용

`category-spec-rules-v3`로 계산하며 v2 저장 정보도 읽는다. 결과 화면은 저장된 광고 입력을 기준으로 추천을 갱신하므로 이미 생성한 광고도 재생성 없이 개선된 추천을 표시한다. 이미지·입력·크레딧을 바꾸는 작업은 아니다. 수동 편집한 게시글은 유지한다.

## 검증 및 한계

우체국박스 후보·채널 확장, 상품군 구분, 명시 지역 반영, 연락처·가격 제외, 부족한 정보에서 임의 개수 채우기 방지, 구버전 저장 정보 재계산을 검사한다. 기존 게시글 보존, 서버의 기획 재계산 및 상품·서비스 정규화 검사도 함께 실행한다.

검색량·광고 경쟁도·실시간 연관검색어·검색 순위를 조회하는 API는 연결하지 않았다. 입력과 품목 사전을 사용하는 후보 추천이다. Google Search Central의 SEO 시작 가이드가 설명하는 사용자 검색 표현과 자연스러운 제목·본문 사용을 기준으로 삼는다: https://developers.google.com/search/docs/fundamentals/seo-starter-guide

웹 빌드와 서버 공통 규칙 검증을 통과한 뒤에도 Render 업데이트 배포와 실제 로그인 화면 확인은 별도로 진행해야 한다. 이 변경에서 유료 이미지·문구 API 호출은 수행하지 않는다.

실행 결과: 채널·게시글·SEO·저장 호환·기획 서버 정규화 및 업종 지침 검사 31개 통과, `npm run build` 통과, PostgreSQL 파생 규칙 일치 검사 통과. 브라우저 화면 및 배포 검증을 완료한 것으로 표시하지 않는다. 기존 Android 0.2.23 APK에는 이번 웹 UI 변경이 포함되지 않으며, Android 재배포는 별도로 빌드해야 한다.
