# 3호 박스 시각 시험 — 합격 처리하지 않음

일자: 2026-10-10 (한국 시간)

사용자가 조립된 우체국 3호 사진과 펼친 ③ 사진을 추가로 제공하고 규격을 340×250×210mm로 지정했다. 조립 사진에는 우측 면 캐릭터가 보이며 펼친 사진의 인쇄 배열과 다르다. 두 인쇄 버전을 섞지 않고 조립 사진만 결과의 시각 기준으로 사용하도록 요청했다. 치수는 사용자 제공값이며 내경/외경과 측정 방식은 미확인이다.

## 시험 방식

채팅 이미지 도구에 조립 사진 보존과 외곽 치수 표시를 요청했다. 앱의 OpenAI API 어댑터나 `gpt-image-2.5-sunburst`를 통해 실행한 시험이 아니다. 사용량/청구 명세를 받지 않았으므로 이 결과에서 API 원가를 산출하지 않는다. 개발 프로젝트의 API 키를 사용한 추가 호출도 하지 않았다.

로컬 결과: `release/dimension-study/postbox-3-visual-candidate-not-accepted.png`

SHA-256는 해당 파일과 함께 확인한다. 생성된 파일을 원본 사진 또는 상품 보존 검증용 기준 이미지로 재분류하지 않는다.

## 육안 검토

| 조건 | 결과 |
| --- | --- |
| 치수 문자열과 축 | 340 mm, 250 mm, 210 mm가 각각 가로·세로·높이 방향에 표시됨 |
| 원본 인쇄·세부 보존 | 미달. 원본보다 인쇄/QR 세부가 새로 표현되었으며 원본 화소 보존을 입증할 수 없음 |
| 입력 규격에 맞는 실제 형상 | 미검증. 치수 문자열만으로 원근을 포함한 비례를 확인할 수 없음 |
| 앱 재현 및 모델 비용 | 이 시험의 검증 대상 아님 |

결론: 세 조건을 모두 충족한 결과가 아니다. 기술보증기금 설명에서 성공 사례나 특허 내용 구현 완료 증거로 사용하지 않는다.

## 다음 구현에 반영할 점

상품 전체를 모델이 다시 그리게 하면 원본 인쇄/QR 보존 검증을 통과시킬 수 없다. 다음 실험은 원본 각 면의 화소를 추출하고, 입력 규격으로 계산한 직육면체 표면에 투영하는 방식으로 진행한다. 각 면의 모서리 대응과 촬영 원근을 보정해야 하며, 가려진 면은 자료 없이 임의 생성하지 않는다. 기존 `box-geometry.ts`는 이 과정의 수학적 형상 기준이며 아직 원본 면 투영 기능은 아니다.

현재 채팅 인라인 원본은 육안으로 볼 수 있지만 작업 공간에 파일 경로나 다운로드 식별자가 없다. 실제 원본 픽셀 기반 시험에는 이 입력 연결이 필요하다. 생성 시안을 그 원본 대신 사용하지 않는다. 별도 환경 설정 변경이나 재게시로 해결되는 문제로 설명하지 않는다.
