# aiadcast 새 앱 전용 개발 API

2026-10-10. 이 서버는 개발자 한 명이 로컬에서 앱 흐름을 검증하기 위한 구현이다. 운영 서버 인증·실결제·클라우드 보관·Google Play 출시 완료를 뜻하지 않는다. 기존 외주 MVP 서버, 기존 이용권 또는 일반 `OPENAI_API_KEY`를 연결하지 않는다.

## 지금 구현한 범위

- Sunburst 이미지 생성/참조 이미지 편집을 호출하는 실제 HTTP 어댑터 코드. 모델은 `gpt-image-2.5-sunburst`, 품질은 `high`, 요청당 결과는 1개로 고정한다. 공식 모델·가격·크기 문서는 2026-10-10 자료를 기준으로 했으며, 이후 승인된 시험에서 이미지 1회 HTTP 200, 문구는 Responses HTTP 401 후 Chat Completions로 수정해 HTTP 200을 기록했다. [실제 시험 기록](live-test-2026-10-10.md)과 모의 테스트 결과를 구분한다.
- 원본 활용에서는 원본 파일을 SHA-256으로 검증·보관하고 **공급사에 원본을 전송하지 않는다**. 빈 배경만 생성한 뒤 클라이언트가 원본을 합성한다. 자동 배경 제거 또는 실물 규격에 맞춘 3D 재구성은 포함되지 않는다. 원본이 불투명한 사진이면 그 사진의 기존 배경도 유지된다.
- 창작 모드는 참조 이미지가 있으면 `/v1/images/edits`, 사진이 없는 서비스는 `/v1/images/generations`를 사용한다. 창작 결과는 실제 상품과 동일하다는 보장을 하지 않는다. 서비스는 규격 없이 요청할 수 있다.
- 문구는 생성 이미지에 그리지 않도록 요청하고, 앱의 별도 텍스트 레이어로 편집한다. 모델이 금지한 문자를 전혀 그리지 않는다는 자동 검증은 아직 없다. 결과를 사람이 확인한다.
- 한국어·영어 문구 제안/번역은 `gpt-5.4-mini` 어댑터를 별도로 호출하며 결과 승인 전에 원문과 비교한다. 번역 결과는 자동 적용하지 않는다.
- SQLite에 요청·원본·결과·모델·토큰·예상 공급사 비용·개발용 이용권 예약/복원을 보관한다. 서버 재시작 뒤 작업 조회가 가능하며 불확실한 작업을 자동 재실행하지 않는다.

## 기본 실행은 비용 0, 실제 결제 없음

```bash
npm run api:dev
```

현재 Node 24 환경에서 `node --use-env-proxy server/generation-server.mjs`를 사용한다. 앱은 같은 출처의 `/api`로 연결하고 Vite가 `127.0.0.1:8787`로 전달한다. 앱과 API 모두 로컬에서만 접근하도록 유지한다. 개발 API를 외부에 프록시하거나 터널로 공유하지 않는다. 모바일 기기에 이 로컬 서버를 바로 연결하는 것은 운영용 모바일 서버 구현을 대신하지 않는다.

| 설정 | 기본값 | 의미 |
|---|---:|---|
| `AIADCAST_SERVER_PORT` | `8787` | 로컬 API 포트 |
| `AIADCAST_SERVER_HOST` | `127.0.0.1` | 다른 호스트 지정은 거부 |
| `AIADCAST_NEXT_LOCAL_DATABASE` | `release/local-runtime/aiadcast-next.sqlite` | 새 앱 개발 데이터. Git 제외 |
| `AIADCAST_NEXT_ENABLE_GENERATION` | 비활성 | 문자열 `true`일 때만 이미지 실호출 허용 |
| `AIADCAST_NEXT_ENABLE_ASSISTANT` | 비활성 | 문자열 `true`일 때만 문구 실호출 허용 |
| `AIADCAST_NEXT_TEST_BUDGET_USD` | `0` | 이미지와 문구가 공유하는 월 공급사 테스트 예산 |
| `AIADCAST_NEXT_LOCAL_OPENAI_API_KEY` | 없음 | 새 앱 전용 서버 비밀값. 브라우저에 전달하지 않음 |
| `AIADCAST_NEXT_LOCAL_ORIGINS` | 로컬 Vite 출처 목록 | 쉼표로 구분한 로컬 HTTP 원점만 허용 |

키가 있어도 기본 설정에서는 공급사를 호출하지 않는다. 유료 테스트를 시작하기 전에 운영자가 총 테스트 예산을 정하고 두 실행 스위치를 필요한 범위만 활성화해야 한다. 이 문서는 활성화·지출 승인이나 실측 성공을 뜻하지 않는다. 실제 API 키는 소스·프로젝트 JSON·화면·로그에 넣지 않는다.

`NODE_ENV=production` 실행을 명시적으로 거부한다. 실서비스에는 사용자 인증/권한, HTTPS API, 비공개 저장소, 구매 영수증 검증, 서버의 상품 카탈로그, 개인정보 보관/삭제, 실제 기기 검증과 출시 심사가 필요하다. 기존 생산 모델 라우터의 빈 승인 목록을 변경하거나 우회해 상용 모델로 등록하지 않는다. 개발 어댑터의 리비전 문자열은 앱 어댑터 버전이지 공급사 모델 가중치의 불변 스냅샷 보장이 아니다.

## API 계약

모든 변경 요청에는 `Content-Type: application/json`, `X-Aiadcast-Client: local-studio`가 필요하다. 이 헤더와 Origin 검사는 로컬 브라우저 보조 보호이며 상용 인증을 대신하지 않는다. 일반 브라우저 교차 출처, 외부 Host와 외부 소켓은 거부한다. 본문은 최대 14,100,000바이트, 참조 원본은 PNG/JPEG/WebP 10MiB·3,000만 화소 이하로 제한한다. 외부 이미지 URL·SVG·애니메이션은 받지 않는다.

- `GET /api/status`: `mode`, `commercialReady:false`, `generation`, `assistant`, `wallet`, `budget`, `limitations`.
- `POST /api/generations`: `{requestId, projectId, request:buildGenerationRequest(project), source:project.product}`. 모델/금액/이용권/고객 식별자는 클라이언트 값으로 정하지 않는다. `projectId`/`requestId`는 8~100자 영문·숫자·하이픈·밑줄. 응답은 `{job,wallet,reused}`.
- `GET /api/generations?projectId=...`: 최근 30개 작업. 큰 이미지 데이터는 제외한다.
- `GET /api/generations/:id`: 해당 작업과 결과 데이터. `job.requestId`는 최근 요청 별칭, `job.requestIds`는 중복 방지를 위해 묶인 요청들이다. POST 응답을 잃어도 같은 ID를 조회하거나 다시 제출해 복구할 수 있다.
- `POST /api/generations/:id/accept`: `{artifactId}`. 올바른 결과를 확인한 경우에만 개발용 이용권 1개 사용 확정. 이미 확정한 같은 결과의 중복 승인은 다시 차감하지 않는다.
- `POST /api/generations/:id/reject`: `{}`. 확인 전 결과 반려, 예약한 개발용 이용권 복원. 같은 요청을 두 번 반려하면 자동 반복을 막고 조건 조정/검토가 필요하다.
- `POST /api/assistant`: `{requestId, kind:'suggest'|'translate', sourceLocale:'ko'|'en', targetLocale:'ko'|'en', productName, description, copy:{title,description}}`. 숫자/가격 변화 검토 안내와 제안 문구 반환. 이미지 이용권을 차감하지 않지만 공급사 토큰 비용은 예산에서 기록한다.

작업 상태는 `running`, `ready`, `accepted`, `rejected`, `failed`, `uncertain`, `expired`다. `ready`는 파일 디코딩과 요청 해상도 등 기본 검사를 통과해 **사람의 검토를 기다리는 상태**다. 상품 정확도·문구·광고 법규 등 의미 검수를 자동 통과했다는 표시가 아니다. 승인/반려 응답과 원장의 상태를 사용하며 클라이언트의 성공 팝업으로 이용권을 확정하지 않는다.

원본 사진·원본 해시·규격·제작 방식·광고 비율이 생성 중 바뀌었다면 오래된 결과를 자동 적용하지 않도록 프런트엔드가 프로젝트 호환성을 확인해야 한다. API 원본 저장은 SQLite의 수정 없는 콘텐츠 해시 레코드이며 암호화된 클라우드 원본 보관 기능과 구분한다.

## 과금/예산 보호

- 시작 시 3개의 **개발 테스트 이용권**을 한 번만 지급한다. 실제 돈, Google Play 구매 또는 고객 계정 잔액이 아니다. 재시작으로 재충전되지 않는다. 구매/충전 HTTP 경로도 없다.
- 생성 요청에서 1개 예약, 사람이 결과를 사용할 때만 사용 확정, 실패/반려/미승인 만료(24시간)에는 복원한다. 공급사 비용은 별도 원장에 남는다.
- 요청 ID 재사용 시 입력이 달라지면 충돌로 거부한다. 동일 프로젝트·동일 입력의 진행 중/검토 중/불확실 작업은 새 ID로 눌러도 재호출하지 않는다. 이미 승인한 뒤 새 시안 버튼으로 보내는 새 요청은 별도 시안으로 허용한다.
- 요청별 자동 재시도는 없다. 시간 초과, 연결 종료, 공급사 5xx, 잘못된 결과나 사용량 누락은 공급사 처리 여부를 단정할 수 없어 `uncertain`으로 기록한다. 고객 이용권은 복원하고 공급사 예산 예약은 유지한다. 서버 재시작도 이 상태를 없애지 않는다.
- 이미지 요청은 미화 0.50달러, 문구 요청은 0.03달러를 호출 전에 공유 예산에 예약한다. **예약액은 공급사 한 번 호출의 과금 상한 보장이 아니다.** 실제 사용량이 예약액을 초과할 수 있으며 실제 응답 원가를 기록하고 남은 예산이 부족하면 다음 호출을 중단한다. 병렬 요청은 사용 중 예약액을 포함해 검사한다.
- OpenAI 응답의 토큰과 2026-10-10 요율로 추정 비용을 계산한다. 회계상 실원가는 공급사 청구와 대조해야 한다. 직접 이미지 API에 캐시 할인은 적용하지 않는다. 사용량 없는 성공 응답을 원가 0으로 처리하지 않는다.
- 실행 중인 같은 데이터베이스를 둘 이상의 서버가 사용하지 않도록 파일 잠금을 둔다. 재시작 후 자동 발행/재생성을 하지 않는다. 활성 월 예산을 바꾸면 기존 원장의 월 한도와 불일치해 새 요청이 차단될 수 있다. 현재는 운영자가 원장을 검토해 한도를 바꾸는 별도 운영 절차가 필요하다.
- 일반 문구·가격·규격 표시·비율 수정·재다운로드는 이 생성 API를 호출하지 않는다. 새 AI 배경/새로운 시안만 별도 생성 요청이다. 영상/영역 수정/배경 제거는 아직 미구현이다.

## 검증

`node --experimental-strip-types --test tests-domain/generation-server.test.mjs tests-domain/billing.test.mjs`

네트워크 공급사 호출은 주입한 mock 응답으로 검증한다. 실제 로컬 HTTP 서비스·SQLite 재시작·트랜잭션·이미지 디코딩은 실행한다. 중복, 반려, 불확실 응답, 사용량 누락, 예산 부족, 원본 해시 변조, 잘못된 MIME/크기, Origin/Host/헤더, 운영 모드 거부, 원본 파일의 공급사 미전송, 창작 multipart 전송, 문구/이미지 공유 예산을 확인한다. 실과금·실제 생성 품질·Android 기기에서 운영 API 접속 성공은 별도 검증 대상이다.

문구 어댑터는 `gpt-5.4-mini`의 `/v1/chat/completions`를 사용한다. 공급사 usage의 prompt_tokens/completion_tokens를 내부 input_tokens/output_tokens로 정규화하며 reasoning 토큰을 중복 계산하지 않는다. 자동 API 전환이나 재시도는 없다. 실제 한정 시험 결과는 위 시험 기록을 따른다.
