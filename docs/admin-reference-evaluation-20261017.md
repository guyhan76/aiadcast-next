# 관리자 승인 원본 평가 — 2026-10-17

현재 사용자 화면으로 확인한 Live는 `dbc34f8b739ea23a0cf2b1a87adc8c091223cb82` (PR #12)다. 이 후속 후보 `feat/admin-reference-evaluation-20261017`은 관리자에게 원본 업로드·예산 조회·결과 복구·진단 저장 경로를 제공한다. 일반 광고 자동 분석 및 기존 CLI의 유료 실행은 계속 닫혀 있다. 실제 유료 호출·배포·키/권한/플랜 변경은 이번 검증에서 하지 않았다.

## 원본 결합 근거

상위 대화에서 원본을 직접 내려받아 확인한 뒤 계산하여 전달한 값이다. 이 실행 환경의 Library 정상 materialization은 `downloadfailed`로 실패했다. 따라서 여기에서 실제 원본을 다시 해시 계산하거나 시각 검증했다고 주장하지 않는다. 대화에서 확인된 실제 원본 해시의 등록 승인을 적용했으며 파일명으로 추정하지 않았다.

| 원본 | bytes | SHA-256 | 알려진 규격 |
|---|---:|---|---|
|22932.jpg|321791|d24f9214030cf8482daca04981b3dc2ece16f2d12c3f3e8937420895550d71c3|박스 300 × 200 × 100 mm|
|22935.jpg|240662|b878decae3ad8287330451da90e8f83b044b039407eda831bdd37248bee1054b|쇼핑백 본체 350 × 130 × 260 mm, 손잡이 제외|

재압축·다른 원본·세 번째 사진은 허용하지 않는다. 원본 bytes와 SHA를 서버에서 다시 확인한다. 이미지 분석 전송용 축소본과 사용자 원본 저장은 별개이며 원본 다운로드는 업로드 bytes 그대로다. 진단 PNG는 원본 해상도 위에 자홍색 검출 선/끝점만 더한다. 사진에 원래 있던 치수선·숫자를 새 AI 결과로 설명하지 않는다. 자동 검출 정확도는 미검증이다.

## 배포 후 실행 순서

1. 후보 PR의 최종 SHA와 해당 CI 성공, 기존 Render 서비스·저장소·환경을 확인한다. 운영자가 기존 설정을 유지하여 지정 SHA를 배포한다.
2. 기존 관리자 계정으로 로그인하고 **관리자 → 승인 원본 사진 분석**을 연다. 일반 회원/미인증 API 접근은 서버가 거절한다. 역할을 새로 부여하거나 키를 입력하는 단계가 아니다.
3. **상태를 재확인**은 읽기 전용이다. 기존 키 설정 여부와 공통 원장 상태를 확인한다. 원장 없음은 검증된 사용량 0회와 다르게 표시한다. 최초 허용된 POST 때만 원장이 생성된다.
4. 승인 원본 JPG를 그대로 선택한다. 파일 크기와 해시가 일치해야 **분석 1회 요청**이 활성화된다. 사용자 승인 범위인 두 장 합계 10회·US$0.30 안에서 명시적인 클릭으로 1회씩 실행한다.
5. 원본과 자홍색 검출 좌표를 비교한다. 박스 축 대응과 쇼핑백 본체/손잡이 분리를 확인한다. 원본/진단 PNG를 별도로 저장한다. 검출 실패는 성공으로 표시하지 않는다.
6. 응답 유실·새로고침 때는 자동 POST하지 않는다. 계정/서버별로 저장된 요청 ID를 GET으로 조회한다. 원본을 다시 선택하면 저장된 결과를 재표시한다. 서버에 요청이 없다는 상태에서만 같은 ID로 재확인할 수 있다. 예약/비용 미확정 요청은 새 호출을 차단한다.

## 비용·복구 불변조건

계정 스키마의 기존 공통 원장과 승인 ID를 그대로 쓴다. 관리자별·프로세스별로 한도를 새로 만들지 않는다. 각 호출은 원자적으로 $0.03을 예약하고, 최대 10개 예약/$0.30을 소비한다. 확인된 추정 비용과 승인 한도 사용은 구분한다. 요청 ID/관리자/원본 해시/정제된 결과가 PostgreSQL에 남아 동일 요청은 추가 provider 호출 없이 복구된다. 결과 저장 전에 프로세스가 죽어도 예약은 남고 새 호출을 막는다. 알 수 없는 비용을 0으로 정산하지 않는다. 다른 관리자의 결과는 조회하지 못하며 예산 합계만 공유한다.

## 검증과 남은 단계

도메인 검증은 실제 PostgreSQL 문법을 실행하는 로컬 PGlite와 대체 provider를 사용한다. 원장 없는 GET의 무변경, 동시 중복 요청 1회, 재시작 결과 복구, 관리자별 결과 격리, 비용 미확정 시 차단을 검사한다. 데스크톱/모바일 브라우저는 합성 JPEG로 원본 byte 보존, 원본 해상도와 표시 밖 픽셀 보존, 자홍색 선, 중복 클릭, 응답 유실/새로고침 무추가 호출을 검사한다. 실제 사진 정확도나 실제 운영 인증 성공의 증거가 아니다.

최종 검사 수치와 원격 CI 링크는 draft PR 본문을 따른다. 이 환경은 Render 인증 도구가 없고 공개 접근은 프록시에서 차단된다. 실제 배포, 관리자 로그인과 읽기 전용 상태 조회, 승인된 실제 원본 분석/시각적 검토가 남아 있다. 과거 분석 사용량을 별도 경로에서 썼다면 실행 전에 공통 승인 잔여량과 대조해야 한다.
