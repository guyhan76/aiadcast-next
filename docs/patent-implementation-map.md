현재 상태를 **청구항 전체의 상용 구현 완료**라고 표시하지 않는다. 이번 변경은 상품 정보와 생성·결과 안내를 연결한 개발 구현이다. 실제 배포, 실물 비례·동일성 평가 및 권리범위 판단과는 별개다. 원본 합성 모드는 사진을 재생성하지 않고 배경만 요청하므로, 사진+규격을 모델에 함께 보내는 창작 모드와 구분한다.

생성 당시 기획은 서버 작업 기록과 승인한 프로젝트에 함께 저장한다. 이후 상품명·규격·속성 등을 바꿔도 과거 시안의 제작 의도가 바뀌지 않는다. 활용 가이드는 과거 생성 설명과 최신 입력을 이용한 게시글·채널 제안을 구분해 표시한다. 이전 프로젝트에 스냅샷이 없으면 생성 당시 정보로 꾸미지 않고 현재 입력 기준의 기획을 보여준다.

## 2. 원본 이미지와 규격을 함께 사용하는 방식

명세서 [0036]은 mm 값·비례·부피(11–12쪽), [0037]–[0039]는 상품별 규격과 확장 가능한 속성(13쪽), [0041]은 상품 영역 추출·화소 비율과 규격 비교(14쪽)를 설명한다.

신규 앱의 원칙은 다음과 같다.

1. 원본 보존 모드에서는 **업로드 파일을 별도 레이어로 사용**한다. 문구와 배경색을 바꿔도 상품을 생성 모델이 다시 그리지 않는다. 사진 내부의 배경·인쇄 글자도 원본의 일부로 남는다.
2. 입력 규격은 숫자와 단위, 축, 정규화한 비례, 원본 해시와 함께 저장한다. 표와 치수선은 동일한 데이터에서 출력한다. ‘표시 안 함’은 생성 참고 규격을 삭제하지 않는다.
3. 정면 사진에서 사용자가 실제 상품의 두 변에 치수선을 맞추고 확인한 경우에만 **평면상의 비례**를 비교한다. 기본 허용 오차 10%는 개발용 정책이며 명세서의 수치가 아니다. 불일치하면 생성 요청 계약 내보내기를 막고 확인을 안내한다.
4. 이 점검은 자동 상품 영역 추출을 구현한 것이 아니다. 사용자가 지정한 두 변에 의존한다. 사선 사진, 새로 교체한 사진, 확인 전 자료는 미검증으로 유지한다. 세로·높이의 의미도 촬영 면에 맞춰 확인해야 한다.
5. 실물 깊이·곡면·숨은 면·다른 촬영 각도를 정확히 재현하려면 **대응하는 실측값·다각도 사진·도면/전개도 또는 형상 모델**이 필요하다. 모든 상품을 사진 한 장과 세 숫자로 정확히 3D 복원한다고 약속하지 않는다.
6. 창작 모드는 규격과 이미지를 참고한 다른 디자인을 허용한다. 원본 동일성·설계 정확성을 주장하지 않는다. 요청 계약은 항상 `geometryVerified: false`, `exactGeometry: false`로 유지한다.

현재 비례 점검은 생성 요청 준비 단계의 검증이다. 직접 편집 PNG는 입력한 치수의 광고용 표기이며 측정 성적서나 설계 도면이 아니다.

## 3. 포장재 외 확장

청구항은 상품명·분류·규격을 다루므로 구현 데이터 구조를 ‘박스’에 고정할 이유는 없다. 포장재, 식품, 뷰티, 전자제품, 의류, 가구, 산업용품, 자동차, 기타 실물 상품을 공통 구조로 제공한다. 규격은 직육면체·평면·지름/높이·없음 중 선택한다.

교육·보험·매장·전문 서비스는 **규격 없는 광고 경로**를 제공한다. 이름·설명·확인된 조건·사진/로고·문구가 입력이며 사진도 선택 사항이다. 이 확장 경로가 가로·세로·높이를 포함하는 현재 청구항의 권리범위에 들어간다고 단정하지 않는다. 보호 범위, 보정이나 후속 출원 가능성은 변리사에게 이 대응표와 함께 검토를 요청한다.

## 4. 소비자 보호 및 모델 진화와의 연결

명세서 [0050]–[0052](17–18쪽)의 이용권 확인·생성 전 안내·결제 확인·오류 및 재시도 처리와 연결해, 신규 서버 참조 원장은 예약 → 품질 확인 → 고객 승인 차감으로 설계했다. 실패·거절·만료·확인된 결함의 복원과 공급사 비용 기록을 분리한다. 이는 로컬 테스트가 있는 참조 구현이며 실결제 운영 증명은 아니다.

모델 버전은 요청 시 고정한다. 신규 버전은 규격 없는 광고를 포함한 회귀 평가와 비용 기준을 통과해야 제한된 배포 대상으로 올라간다. [모델 검증 문서](model-evaluation.md)를 참고한다.

## 5. 다음 실물 검증의 합격 기준

- 동일 상품의 원본 사진, 정확한 mm 값, 현재 실패 결과를 한 묶음으로 준비한다. 로고·색·윤곽·인쇄 중 필수 보존 항목을 명시한다.
- 포장재와 비포장재, 투명/반사 소재를 포함해 상품 보호 영역과 합성 영역을 비교한다. 단순 ‘비슷해 보임’을 동일 상품 판정으로 사용하지 않는다.
- 규격 표기·평면 비례·3D 형상 재현의 결과를 각각 기록한다. 미검증 항목을 성공값으로 채우지 않는다.
- 서비스 광고는 규격을 강요하거나 임의의 효능·가격·보험 보장 조건을 생성하지 않는지 확인한다.
- 본 대응표는 개발 분석이며 특허 등록·권리범위에 관한 법률 의견서가 아니다.
