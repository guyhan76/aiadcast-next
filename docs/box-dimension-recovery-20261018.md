# 박스 사진 치수선 복구 — 기본 비활성, 모의 검증 후보

기준은 PR28 d86a8c3. 기존 일반 광고 capability가 항상 false여서 관리자도 direct/inset 선택 후 생성 전에 차단됐다. 이 변경은 유료 차단을 제거하지 않는다. 신규 생성은 승인된 기존 이미지 분석과 별도이며 `allowNewGeneration:false`를 유지한다.

## 구현 범위

단일 직육면체 골판지 박스 완성 광고의 사진 좌표 취득·검증·합성. 사용자 소유 결과 jobId와 해시를 서버 저장 결과에 대조한다. 클라이언트 이미지·URL·모델·사용자 ID는 받지 않는다. 기존 키 경로를 재사용하되 운영 approval은 null이다. 환경변수나 API로 승인을 만들 수 없다. 실제 대상 결과 해시·사용자·기간·호출/예약 상한을 별도 검토해야 한다. 기존 참조 평가 승인을 재사용하지 않는다. 별도 분석 승인이 있어도 비용은 기존 회원별 월 예산 안에서 예약·정산한다. 월 배정액이나 전체 총예산을 늘리지 않는다.

분석 요청은 생성 결과 전체 한 장(최대1024px JPEG, 광고 속 문구·연락처 포함)만 사용한다. 기존 runAnalysis/단일박스 지시와 정확한 해시 바인딩을 재사용한다. 분석 지시는 본체 높이에서 덮개를 제외하고 표·광고 문구를 보호한다. 검증 전 결과를 실제 형상 판정으로 표시하지 않는다.

PostgreSQL 계정 스키마의 box_dimension_calls에 승인/사용자/요청 ID, 결과 ID/해시, 비용 상태/응답을 보존한다. 승인 없이는 테이블을 만들거나 공급사를 호출하지 않는다. 예약을 트랜잭션으로 직렬화하고 결과를 기록하기 전에는 다른 유료 요청을 막는다. 같은 요청은 저장 상태를 반환한다. 중단·사용량 불명·상한 초과는 uncertain으로 보류하며 새 요청 ID도 막는다. 승인당 최대2회, 회당$0.03 예약, 총$0.06 이하만 코드가 허용한다. 별도 실제 승인과 현행 공급사 가격 재검증이 필요하며 공급사 청구 하드 상한은 아니다.

응답의 좌표가 없거나 자동분석이 꺼져도 기존 생성 결과에서 수동 복구할 수 있다. 박스 영역, 세 축 끝점, 모든 문구/기존 치수 영역, inset 공간을 원본 기준 퍼센트로 입력하고 직접 확인한다. 빈 초기 좌표는 무효이며 자동 검출 결과처럼 그리지 않는다. 기존 점 이동 UI도 유지한다. 사진·치수가 바뀌면 이전 배치를 사용하지 않는다. 미리보기와 동일 픽셀로 확정·저장하고 기기 초안에 보존한다. inset은 생성 광고의 상품 영역을 복사하며 첨부 원본 사진을 별도 배경 제거해 넣는 기능이 아니다.

## 실패·비용·범위

위치 분석 실패는 이미지 재생성을 실행하지 않는다. 알려진 분석 실패만 명시적 새 요청 1회가 가능하고, 불확실 상태 확인은 같은 ID로 조회한다. 원본 보존·수동 보정은 계속 가능하다. 기존 생성 이용권은 검토 중 예약 후 확정 시 차감, 반려/만료 시 복원한다. 분석은 이용권을 추가 차감하지 않으며 이미 발생한 공급사 비용은 삭제하지 않는다. 관리자 이용권 면제도 API 무료 승인이 아니다.

이 기능은 사진 위 치수 표시다. 입력 치수대로 상품 형상을 재구성하거나 로고·인쇄·재질을 복원하지 않는다. 열린 박스 본체/덮개 구분·가림 없는 세 축·직접표시/inset·9:16을 첫 실검증 범위로 제안하며 실제 대상 이미지와 유료 검증은 아직 승인되지 않았다. 가방·의류·다중상품·불규칙 형상을 일반 지원으로 주장하지 않는다. 수동 지정은 복구 경로이며 자동 우선 제품 경험의 실검증을 대체하지 않는다.

운영 배포·키 설정·실제 생성/분석·회원지원·Toss 변경·APK 재빌드 없음. 이 PR을 배포하는 것만으로 자동분석이 활성화되지는 않는다. 기존 APK에는 새 수동 복구 UI가 없으므로 추후 별도 앱 업데이트가 필요하다.

## DB와 롤백

기본 비활성 배포에서는 신규 테이블을 초기화하지 않는다. 향후 승인된 요청에서 계정 스키마의 box_dimension_calls를 지연 생성하고 기존 DB 보호 규칙을 적용한다. 수동 복구는 기존 프로젝트 저장만 사용한다. 자동분석 예약과 기록은 동일 PostgreSQL 연결/잠금 안에서 사용자 budgets의 held_micros에 $0.03을 반영한다. 알려진 비용은 spent_micros로 이동하고 불확실 응답은 hold를 유지한다. 이용권 장부나 월 배정 한도는 변경하지 않는다.

분석 실행 전 코드 롤백은 기존 배포 기준을 따른다. 실행 후에는 신규 분석을 중지하고 저널·사용자 예산의 사용/보류액을 보존한다. 같은 승인/요청에 대한 중복 호출 방지를 유지하는 호환 코드로 복구한다. 저널 삭제·budget 초기화·과거 DB 복원으로 비용을 없애지 않는다. 불확실 요청은 운영자가 공급사 증거와 대조해 정산해야 하며 자동 해제/재호출 경로는 없다. PR27 회원 지원 저널 관련 롤백 제한도 그대로 적용된다.

## 기존 생성 결과가 없는 경우

이 변경은 승인 없는 새 이미지 생성이나 자동분석을 허용하지 않는다. 따라서 현재 사진 치수선을 선택한 채 생성 전에 막힌 사용자는 이 PR만 배포해도 새 광고+자동규격 완성을 얻지 못한다. 기존 소유 결과가 있으면 새 UI에서 수동 복구할 수 있다. 결과가 없으면 원래 첨부 사진을 몰래 완성 광고로 바꾸거나 재생성을 자동 실행하지 않는다. 별도 승인된 생성/분석 실검증 이후에만 자동 경로를 진행해야 한다. 표시 끄기는 일반 광고 점검용 임시 대안이며 핵심 요구 완료가 아니다.
