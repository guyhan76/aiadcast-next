# 신규 aiadcast 사용성 평가와 개선 결정

2026-10-09. 제공된 기존 앱 화면·실제 결과물·사용자의 문제 제기를 기준으로 한 설계 검토다. 외부 고객 인터뷰나 광고 성과 실험을 완료한 것은 아니다.

## 판단

**지금 상태로 유료 ‘최고의 AI 광고 앱’이라고 출시하기에는 부족하다.** 직접 편집과 프로젝트 재사용은 시연할 수 있지만 실제 AI 생성과 운영 결제가 연결되지 않았고, 상품 동일성·다국어 품질도 실물 자료로 검증해야 한다. 디자인 개선과 상용 완성을 같은 기준으로 보지 않는다.

## 이번에 바꾼 흐름

처음부터 긴 입력 폼을 보여주던 구조를 **홈 → 광고 대상 → 사진·정보 → 스타일·비율 → 편집 → 저장·재사용**으로 정리했다. 홈에는 바로 시작하는 버튼, 상품/서비스/교육/자동차 진입점, 원본·규격·매체 비율의 가치를 배치했다. 검정·흰색 중심의 화면과 제한적인 오렌지 강조, 고정된 모바일 탐색으로 페이지 간 일관성을 맞췄다.

| 사용자가 막히는 부분 | 적용한 수정 | 다음 확인 |
|---|---|---|
| 내가 만드는 광고가 어떤 대상인지 불명확 | 상품·서비스 경로와 업종 분류 | 비제조업 사용자도 첫 화면에서 시작할 수 있는지 |
| 규격이 필요 없는 광고에 치수 강요 | 신규 제작은 규격 선택 입력, 사진 없는 서비스 지원 | 자동차·교육·보험·매장 사례별 입력 부담 |
| 한 번 만든 광고를 다시 못 고침 | 프로젝트 목록·검색·다시 열기·백업, 전환 시 편집본 저장 | 저장 실패·브라우저 삭제·실기기 파일 복구 |
| 결과를 어디에 써야 할지 모름 | 타깃·추천 채널·키워드·제작 의도와 비율 변경 | 고객이 실제 광고를 게시하는 데 충분한 안내인지 |
| 생성 전후 원본 여부가 불명확 | 원본 보존과 창작 준비를 분리, 미연결 기능 상태 표시 | 실제 생성 서버에서도 같은 구분을 강제하는지 |
| 업데이트마다 품질/비용 변화 | 버전 고정·회귀 평가·제한 배포·이상 시 중단 | 실제 공급사·운영 작업에서의 안정성 |

## 우선순위

1. **신뢰 가능한 결과:** 원본 보호, 확정된 문구, 일관된 규격, 실패 시 비용 보호. 실제 원본·실측 자료로 먼저 검증한다.
2. **쉽고 빠른 첫 완성:** 제품군별 좋은 템플릿, 사진 분리/보정, 업종에 맞는 확인 가능한 광고 문안. 지금은 기본 템플릿 중심이므로 표현 다양성을 늘려야 한다.
3. **편집과 반복 사용:** 자동 번역 초안 검토, 부분 수정, 다중 자산, 자유 배치·크기·폰트, 클라우드 동기화. 현재 기기 저장만으로 팀 협업을 약속하지 않는다.
4. **사업 운영:** 인증·이용권·결제·영수증 검증·환불·운영 관제·지원. 서버 참조 코드의 로컬 통과만으로 실결제를 켜지 않는다.
5. **영상:** 먼저 원본 사진을 유지하는 이동/확대와 정확한 자막을 조합한 광고 영상을 검증한다. 생성형 영상은 상품과 로고가 프레임마다 바뀌는지 별도로 평가하고 모델 어댑터로 확장한다. 아직 영상 출력은 없다.

## 실사용 검증 계획

초기 제조/판매업 3명, 서비스업 2명 이상에게 설명을 최소화한 상태로 ‘첫 광고 만들기 → 문구 수정 → 다른 비율 저장 → 다음날 재편집’ 과제를 요청한다. 이 인원은 계획이며 이미 인터뷰한 고객 수가 아니다.

첫 광고 완성 여부와 시간, 되돌아가는 입력 단계, 오타 수정 횟수, 원본 보존 판단, 잘못 차감된 이용권 여부, 다음 작업에서 다시 쓰고 싶은 이유를 기록한다. 비율이나 시간을 목표로 확정하기 전에 최초 사용 결과를 측정한다. 클릭 수만으로 설치·재구매 의사를 대신하지 않는다.

보험·교육·서비스 광고 문구는 입력된 사실·조건을 근거로 작성하고 고객이 확정한다. 확인되지 않은 보장·효능·수익·할인을 자동으로 만들어 넣지 않는다.
