# aiadcast 신규 플랫폼 — 기술·사업 설명 초안

작성일 2026-10-09 · 셀업랩스 주식회사 · 기술보증기금/중소벤처기업진흥공단 상담 준비용

## 사업 설명

**aiadcast는 사업자가 실제 상품 사진과 상품·서비스 정보를 이용해 광고를 만들고, 문구·배경·언어·규격 표시를 수정하며 여러 매체용으로 재사용하는 광고 제작 플랫폼을 개발하는 사업이다.**

기존 외주 MVP는 포장재 중심의 이미지 생성 흐름을 검토하는 데 사용했다. 대표자 설명상 Google Play 등록을 마쳤고 카드결제는 테스트 단계다. 신규 플랫폼은 소스코드와 운영 계정의 독립적인 관리, 원본 상품 보존, 수정 가능한 광고, 실패 시 고객 보호를 목표로 별도로 개발 중이다. 기존 앱 등록 실적과 신규 앱의 개발 완료 여부를 혼동하지 않는다.

## 해결하려는 고객 문제

| 현재 사용자 문제 | 신규 플랫폼의 방향 | 검증할 효과 |
|---|---|---|
| 첨부한 제품이 다른 상품으로 바뀜 | 원본 상품 레이어 보존, 배경·문구 분리 | 승인된 상품 특징 유지율, 수정 요청률 |
| 한글 오타와 언어 변경의 어려움 | 확정 문구를 글꼴로 출력, 언어별 편집본 보관 | 문자 누락·오타·잘림, 번역 수정률 |
| 작은 수정도 전체 재생성 | 프로젝트 저장과 부분 편집 | 수정 완료 시간, 유료 생성 횟수 |
| 치수와 표시가 결과마다 달라짐 | 구조화한 규격, 표시 여부 선택, 원본 비례 검토 | 입력값/출력값 일치, 원본 대조 결과 |
| 실패에도 고객 이용권 소모 | 예약·품질 검증·고객 승인·복원 원장 | 중복 차감, 복원 누락, 고객 문의 |
| 포장재에 사용 범위가 한정됨 | 일반 실물 상품과 규격 없는 서비스 공통 제작 흐름 | 업종별 첫 광고 완성률·재사용률 |

위 지표는 앞으로 측정할 항목이다. 현재 매출 증가율·광고 전환율·고객 만족도·유료 이용자 수가 입증됐다는 의미가 아니다.

## 기술 구성과 출원

사용자가 제공한 출원서의 명칭은 「상품 규격 정보와 상품 이미지를 결합한 마케팅 콘텐츠 자동 생성 시스템 및 그 방법」이며 파일명상 출원번호는 10-2026-0158120이다. 출원 명세서 24쪽 및 청구항 1개를 분석해 [구현 대응표](patent-implementation-map.md)를 작성했다. 대출 상담에는 공식 출원 접수증·서지사항 등 실제 증빙을 함께 준비한다. **등록 특허로 기재하지 않는다.**

기술 흐름: 다단계 입력 → 실제 이미지·규격·속성 결합 → 모델용 요청 계약 → 원본 보호/창작 경로 분리 → 문구·규격의 별도 렌더링 → 품질 검토 → 이미지와 광고 활용 가이드 → 편집 가능한 프로젝트 보관.

규격 없는 서비스 광고는 제품 범위를 확장하는 별도 기능이다. 해당 경로의 특허 보호 여부는 별도 검토가 필요하다.

## 현재 실제로 시연 가능한 범위

- 모바일/PC 반응형 홈, 3단계 제작, 프로젝트 목록·검색, 사용 안내, 편집 화면.
- 상품 사진 원본 바이트·SHA-256·화면비 보존, 한/영 문구 직접 편집, 배경 변경.
- 일반 상품·자동차·교육·보험·서비스 분류, 선택적 규격과 일관된 표시 설정.
- 대화 요청 보관·수정 범위 선택·확인 후 빠른 편집·대화 백업. 실제 AI 대화는 연결 전.
- 정면 사진에서 사용자 지정 두 변과 규격 비례 비교. 실물 전체의 3D 재현은 아님.
- 7개 광고 비율의 PNG 출력, IndexedDB 기기 저장, 프로젝트 JSON 백업·복원.
- 분류·일부 규격을 이용한 초기 타깃·매체·키워드 제안, 생성 요청 계약 다운로드.
- 고객 이용권 예약/복원과 공급사 비용을 분리하는 서버 참조 원장 테스트.
- 서명된 평가 보고서 검증, 제한 배포·자동 승격/중단을 위한 모델 교체 제어기 테스트.

테스트 범위와 실행 결과는 [validation.md](validation.md), 소스 버전·파일 체크섬은 전달 ZIP의 `build-info.json`과 Git bundle로 확인한다. 홈페이지의 과거 생성 사례는 기존 앱 결과이며 신규 앱 성능 증거로 대체하지 않는다.

## 아직 완료되지 않은 범위

실제 OpenAI 이미지 생성·자동 번역·배경 제거/영역 수정, 실물 형상 재현, 서버 계정·저장소·작업 큐, 실결제·스토어 영수증 검증, Android AAB 빌드·실기기 검증·신규 Play 등록, 운영 장애 대응은 완료 전이다. 모델 목록 자동 조회와 평가·배포를 주기적으로 운영하는 서비스도 미연결이다.

독립 소스 저장소는 로컬에 구성했으며 소유 계정 계획은 `guyhan76`이다. 비공개 GitHub 원격 생성·접근, 신규 API 프로젝트와 서명키의 소유 검증은 남아 있다. 사용자 계정 관리 권한 확인은 해당 리소스의 기술적 연결 완료와 다르다.

## 사업화 단계와 자금 사용 근거

| 단계 | 실행 내용 | 다음 단계 진입 증거 |
|---|---|---|
| 기술 검증 | 원본·규격 대응 실물 자료, AI 연결, 한글/다국어·복잡한 소재 평가 | 원본-결과 대조표, 결함률, 실제 API 원가 |
| 운영 기반 | 독립 서버·계정·데이터 저장, 원장·영수증 검증, 모니터링·복구 | 중복 결제/장애/복원 시험, 접근권한 확인, 복구 시연 |
| 고객 검증 | 소상공인·제조업·서비스 사업자의 과제 기반 시범 사용 | 첫 광고 완성률, 수정 시간, 재사용·구매 의향의 실제 기록 |
| 출시 | Android 패키징·실기기·접근성·스토어 제출, 이용 정책과 고객 지원 | 실기기 결과, 결제 검증, 출시 검토 자료, 스토어 심사 결과 |
| 고도화 | 검증된 모델 자동 교체, 다국어 확장, 광고 영상 | 모델별 품질/원가 비교, 프레임별 상품·문자 일관성 검증 |

집행 항목은 개발 인력/외부 검증, AI 평가 비용, 서버·스토리지, 결제·보안·실기기, 고객 실증 등으로 산정할 수 있다. 신청 금액과 기간은 실제 견적·보유 자금·지원 요건을 확인해 작성한다. 현재 확인되지 않은 금액이나 매출 예측을 확정치로 제시하지 않는다.

## 수익 모델 검토

검토 중인 가격은 표준 생성 10회 9,900원 / 7.99달러, 30회 24,900원 / 19.99달러, 100회 79,900원 / 59.99달러다. 고품질 모드는 3크레딧 사용을 가정한다. 실제 구매 기능과 최종 가격은 확정 전이다.

한국어/영어에 따른 표시 통화와 실제 결제 통화는 구분한다. 스토어 결제는 구매자의 스토어 국가·상품 가격 정책을 따라야 한다. API 실패·무료 재생성·고객 복원·세금·스토어 수수료까지 포함해 원가를 측정한 뒤 확정한다. 기존 원가 계산은 가정 기반이며 [가격 검토](pricing-strategy.md)에 근거와 미확인 사항을 남겼다.

## 상담 전 준비할 증빙

사업자/회사 자료, 공식 특허 출원 증빙, 기존 MVP 계약·성과 범위, 신규 소스·동작 시연·검증 결과, 대표자 경력 증빙, 실제 개발 견적·자금 집행 계획, 고객 인터뷰/사용 기록을 모은다. 대표자의 26년 이상 산업 경험은 회사 소개에 사용하는 사용자 제공 정보이며 별도 경력 자료로 뒷받침한다.

현재 신규 앱은 개발 검증 단계다. 이 문서는 대출 승인이나 기관의 기술성 판단을 보장하지 않으며, 기관 제출 전에 최신 신청 요건과 증빙에 맞춰 검토한다.
