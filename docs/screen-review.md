### 이번 자료에서 확인 가능한 문제와 확인 한계

- 이 결과에는 치수선과 규격 요약이 모두 있다. 모든 생성 결과에서 일관되게 적용된다는 근거는 아니다. 새 엔진은 두 위치를 같은 치수 데이터에 연결한다.
- 입력 상세 설명과 결과에 '다양한 인쇄를 적용이 가능하여'라는 어색한 표현이 공통으로 보인다. 글자를 폰트로 출력하는 것 외에 입력 문구·AI 제안 문구를 검토하고 확정하는 단계도 필요하다. 사용자가 확정한 문구를 내보낼 때 임의로 다시 작성하지 않는다.
- 업로드 파일명 `18606.jpg`는 보이지만 파일 속 실제 상품 사진은 이번 자료에 없다. 결과와 원본의 형태·인쇄 일치도를 아직 판정할 수 없다.
- 결과 이미지는 시각적 결과를 보여준다. 기존 서버가 실제로 어떤 레이어나 편집 데이터를 저장하는지는 화면만으로 판단하지 않는다.
- 3 MB 제한과 PDF 지원 안내는 화면상 정책이다. 신규 앱의 제한은 원본 보존·업로드 안정성을 고려해 따로 정하고, PDF를 받는다면 사용할 페이지와 상품 영역 선택을 제공한다.

화면에 표시된 가격·문구는 기존 서비스의 참고 자료다. 새 앱의 결제 구현이나 환불 정책이 확정되었다는 뜻은 아니다. 결제 실패 표시만으로 실제 청구·이용권 증감 결과를 알 수 없고, 개발자 표시명만으로 계정 소유 관계를 판단할 수도 없다.

총 15개 자료로 기존 사용 흐름 확인을 마쳤다. 현재 구현된 검증판은 아래 전체 흐름 중 **원본 사진을 사용하는 편집·저장·내보내기**를 우선 검증한다. 기존 홈·이용권·로그인 화면을 만들어 실제 연동처럼 보여주지는 않는다.

## 신규 화면 흐름 초안

1. 상품 정보: 카테고리, 치수, 소재, 장점, 기업 정보.
2. 상품 사진: 대표 사진 선택 → 보존할 상품 영역 확인 → 나머지 참조 사진의 용도 구분.
3. 출력 설정: 9:16/2:3, 콘텐츠 언어, 규격 표시 켜기/끄기, 템플릿.
4. 문구 검토: 제목·장점·가격·연락처와 번역문 확인·수정.
5. 결과 편집: 아래 도구로 원하는 요소 선택.
   - 상품: 원본 보존, 위치·크기·마스크 보정.
   - 배경: 색·이미지 교체 또는 배경만 새로 생성.
   - 문구: 직접 수정·번역·폰트·배치.
   - 규격: 숫자·단위·치수선 위치·표시 설정.
6. 저장·내보내기: 편집 가능한 프로젝트와 최종 이미지 파일을 함께 보관.

비율 변경과 언어 전환은 같은 원본 상품과 확인된 치수에서 파생한다. 레이아웃 변환 뒤 텍스트 넘침·상품 가림·치수선 위치를 확인한다. AI가 연결되기 전 검증판은 자동 생성이나 자동 번역이 되는 것처럼 표시하지 않는다.

## 남은 확인 항목

- 생성 전 실제 상품 사진과 입력 치수, 대응하는 결과 한 세트.
- 특허 전체 명세서·청구항과 구현 요건 대조.
- 기존 앱 계정·이용권 데이터와 Play Console 배포 권한.
