# 업종별 광고 만들기

## 선택 화면

홈에는 상품 광고와 서비스 광고 두 가지만 표시한다. 새 광고 만들기도 먼저 **상품 / 서비스**를 고른다. 상품을 선택하면 상품 카테고리 9개만, 서비스를 선택하면 서비스 카테고리 10개만 표시한다. 카테고리를 고르면 그 안의 세부 업종만 펼쳐진다. 검색은 현재 선택한 상품 또는 서비스 범위에 한정한다. 편집기의 업종 선택은 현재 선택한 업종 행으로 접어 두고 필요할 때 변경한다.

실물 상품 19종과 서비스 29종으로 총 48개 세부 분류를 유지한다. 위 표는 개발·검토용 전체 목록이다. 앱에서는 먼저 상품과 서비스를 구분하고 선택한 범위의 카테고리, 선택한 카테고리의 세부 항목만 보여준다. 자동차 상품과 리스·렌탈 서비스도 각각 상품과 서비스에서 선택한다.

## 요청문 없이 고르는 제작 방향

새 제작의 첫 단계에서 상품 또는 서비스 → 카테고리 → 세부 업종을 고르고 이름을 입력한다. 이어서 사진·정보 → 광고 방향으로 진행한다. 업종별 목적 카드 3개와 공통 시각 스타일 4개를 제공한다. 목적의 이름·문구·행동 안내는 업종에 맞게 바뀐다. 예를 들어 음식점은 매장 소개/방문·예약 안내/메뉴 이야기, 필라테스는 스튜디오 소개/수업·체험 안내/프로그램 소개, 은행은 은행·서비스 소개/이용·상담 안내/상품·조건 안내를 고른다.

포장재의 일곱 분야는 브랜드·제품 소개, 규격·소재 안내 등 대상에 맞는 방향을 고를 수 있다. 사진을 다시 그리지 않고 원본 사진과 규격 사용·표시 선택을 유지한다.

패션·스타일의 다섯 분야는 컬렉션·제품 소개와 소재·디테일 등 대상에 맞는 방향을 고를 수 있다. 자유 요청을 작성하지 않아도 추천 방향과 스타일 선택으로 시작한다.

사주·운세의 네 분야는 각각 소개, 상담·예약, 이용 정보의 세 방향을 제공한다. 상담 분야·이용 방법 등 사업자가 제공한 정보를 바탕으로 구성한다.

스타일은 에디토리얼, 시그니처, 내추럴, 모던 테크다. 편집용 색상·글자 대비·절제된 벡터 장식을 적용하며 원본 상품 사진을 다시 그리지 않는다. 화면의 미니 스타일 카드는 디자인 참고 그림이고 AI 생성 사례가 아니다.

‘더 담고 싶은 내용’은 선택 입력이다. 비워두어도 기본 방향으로 진행하며, 창작 모드의 사진 없는 서비스도 추천 방향만으로 요청을 준비할 수 있다. 추가 입력은 연출 지시로 보관하고 광고에 인쇄될 문구로 자동 삽입하지 않는다. 새 제작에서는 사업명·선택한 방향·제공한 소개를 바탕으로 편집 가능한 기본 문구를 구성한다. 편집 중인 프로젝트의 추천 문구는 사용자가 ‘추천 문구 적용’을 눌러야 바뀐다.

사진 속 새로운 공간·조명·인물·장면을 그리는 실제 AI 생성은 아직 미연결이다. 현재 PNG 출력은 원본 사진, 직접 편집한 문구, 선택한 스타일로 구성하는 합성 결과다. 추천은 규칙 기반이며 AI의 해석·자동 번역·광고 성과를 주장하지 않는다.

## 상품·서비스·규격

서비스 29종은 사진과 규격 없이 시작할 수 있다. 실물 상품 18종과 자동차는 원본 사진으로 직접 구성할 때 사진이 필요하다. 실제 음식 제품은 ‘식품·음료’, 음식점·메뉴·매장 안내는 ‘음식점’처럼 광고 대상에 맞춰 선택한다.

모든 업종에서 필요한 경우 규격 정보 사용을 켜고 형식과 표시 여부를 선택할 수 있다. 현재 치수 입력은 실물의 mm 치수다. 부동산 면적·이용 기간·수량·요금 등 다른 단위의 사업 정보는 서비스 소개나 추가 속성으로 입력한다. 업종을 서비스로 바꾸면 규격 사용·표시를 끄되 기존 치수 값과 사진·문구를 지우지 않는다. 원본 보존/창작 선택과 규격 표시 선택은 별도로 유지한다.

## 저장과 생성 요청

상품·서비스 선택과 카테고리 구조를 바꾸면서 기존 세부 분류 ID와 프로젝트 형식은 유지한다. 저장된 분류에 맞는 상품 또는 서비스와 카테고리로 다시 열리고 원본 사진·문구·규격 설정을 보존한다. 기존 포장재 분류 ID `packaging`은 포장재 그룹의 기타로 유지하고 사진·문구·치수와 규격 사용·표시 설정을 보존한다. 저장된 사진에서 박스 등 세부 유형을 자동 판정하지 않으며 사용자가 필요하면 다시 선택한다. 새 세부 분류 ID는 `boxes`, `shoppingbags`, `labels`, `containers`, `plasticfilm`, `pouches`다. 패션의 기존 분류 ID `fashion`도 유지한다. 기존 패션 프로젝트는 패션·스타일 그룹의 의류·패션으로 열리고 사진·문구·규격 등 저장 정보는 그대로 보존한다. 이전 사주·궁합과 철학관 프로젝트는 명리학으로, 점·무속 프로젝트는 신점으로 복원한다. JSON 가져오기와 기기 저장본 복원에 적용하며 기존 사진·문구·규격은 유지한다. `campaign.creative`에 목적 ID·스타일 ID·선택 입력을 보관하고, 이전 프로젝트에는 이 필드가 없어도 열린다. 기기 저장·JSON 백업·복원과 생성 기획 내보내기에 포함한다.

생성 기획에는 선택한 카테고리·세부 업종·목적·시각 스타일 참고·현재 확정된 배경과 글자색·추가 지시를 함께 넣는다. 사용자가 나중에 직접 바꾼 화면 정보가 스타일의 참고 색상보다 우선한다. 상품 원본·치수·언어·고객이 제공한 사실 정보를 별도로 유지한다. 제품 효능·임상 결과·투자 수익·금리·가격·인증 등을 입력 사실 없이 만들지 않는 조건도 포함한다. 실제 모델의 이 조건 준수는 공급사 연결 후 추가 검증해야 한다.

## 검증 범위

도메인 검사는 전체 업종 포함, 서비스 무규격·무사진 경로, 실물 사진 요구, 원본·문구·치수 보존, 추가 지시와 출력 문구 분리, 저장 형식 검증을 포함한다. 브라우저 검사는 상품·서비스 선택, 선택 범위의 카드·검색·세부 업종 표시, 주요 서비스 제작, 스타일·추가 지시 보존, 구형 프로젝트, 실제 PNG 내보내기와 모바일 폭을 확인한다. 최종 실행 결과는 `validation.md`에 기록한다.
