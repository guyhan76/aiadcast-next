aiadcast Studio — 편집 검증판 0.1

1. ZIP을 내려받았다면 압축을 풀어주세요.
2. PC의 Chrome 또는 Edge로 aiadcast-studio.html을 여세요.
3. 홈 → 나의 광고 만들기 → 광고 대상 → 사진·정보 → 스타일·비율 → 편집 시작 순서로 사용하세요.
4. 규격은 선택 사항입니다. 서비스 광고는 사진 없이도 만들 수 있습니다. 내 프로젝트에서 저장한 작업을 다시 열 수 있습니다.
5. PNG 내보내기 → 완성 이미지 저장. 프로젝트 백업 → 원본 사진과 편집 정보를 JSON 파일로 저장.

이 파일은 설치형 Android 앱이 아닌 웹 편집 기능 검증판입니다.
휴대폰에서는 로컬 HTML 실행 지원이 브라우저마다 다릅니다. 모바일 이용은 향후 별도 HTTPS 체험 주소로 제공할 예정입니다.

구현된 기능
- 업로드한 원본 사진 보존, 비율 유지, 사진 크기 조정
- 한국어·영어 문구 별도 입력과 전환, 글꼴로 정확히 출력
- 배경색·배경 사진 변경
- 가로·세로·높이 mm 입력과 치수선 위치 직접 조정
- 개별 수정, 되돌리기, 기기 저장, 프로젝트 백업·불러오기
- 1:1 / 4:5 / 3:4 / 9:16 / 2:3 / 16:9 / 1.91:1 PNG 내보내기

현재 범위
- 자동 번역·AI 배경 생성·자동 배경 제거·결제는 연결하지 않았습니다.
- 사진 안에 포함된 배경과 상품 인쇄 문구는 유지됩니다. 상품만 사용하려면 투명 PNG를 추가해주세요.
- 정면에서 촬영하고 사용자가 상품 두 변에 치수선을 맞춘 사진은 비례 점검을 할 수 있습니다. 자동 측정·실물 3차원 복원은 아닙니다.
- 편집기를 바로 열었을 때 보이는 문구와 규격은 예시입니다. 새 광고 만들기는 규격 없이 시작하며 실제 정보에 맞춰 선택 입력합니다.
- 입력 원문 자체의 오타는 직접 확인해주세요. 글이 넘치면 내보내기를 막고 안내합니다.

저장
- 사진과 편집 내용은 외부 서버로 전송하지 않습니다.
- 브라우저 저장 데이터는 삭제될 수 있으니 JSON 프로젝트 파일을 백업해주세요.
- PNG만 저장하면 문구와 배경을 분리하여 다시 편집할 수 없습니다.
- 공유할 JSON에는 원본 사진과 연락처 등 입력값이 포함됩니다.

이 검증판에는 Noto Sans KR 글꼴이 포함되어 있습니다. 글꼴 라이선스는 FONT-LICENSE.txt를 확인해주세요.

추가된 범용 상품 기능
- 광고 정보 탭: 포장재·식품·뷰티·전자제품·패션·가구·산업용품·기타 분류 및 소재 입력
- 규격 탭: 가로/세로/높이, 가로/세로, 지름/높이, 규격 없음 선택
- source/server/: 이용권 오류 복원·중복 차감 방지·API 비용 제한의 로컬 서버 참조 코드
- source/docs/service-roadmap.md: 소비자 보호, 결제 연결, 모델 업데이트, 영상 및 Google Play 출시 계획

주의: 서버 참조 코드는 브라우저 편집기의 실제 결제 기능이 아닙니다. 결제·OpenAI·영상 생성은 아직 연결하지 않았습니다.

규격 표시 선택
규격 탭에서 ‘표시 안 함 / 규격 요약만 / 요약과 치수선’을 선택하세요.
표시를 꺼도 입력한 치수는 지워지지 않습니다. 저장 후 다시 열 때도 선택이 유지됩니다.
이 설정은 앱이 붙이는 규격 요약과 치수선을 제어합니다. 원본 사진과 홍보 문구에 직접 들어 있는 숫자는 그대로 남습니다.

이미지 제작 방식 선택
- 사진과 문구로 직접 만들기: 원본 사진을 사용하는 현재 편집·PNG 출력 기능입니다. 기본값입니다.
- 새로운 광고 이미지 만들기: 사진과 규격을 참고해 새로운 상품을 구상합니다. 형태·인쇄가 달라질 수 있습니다. 현재는 선택·요청 내용 저장만 지원하며, AI 연결 후 생성 기능을 제공합니다.
- 규격을 사용하는 프로젝트는 표시를 숨겨도 치수를 참고값으로 보관합니다. 규격 사용 자체를 끄면 생성 요청에는 치수가 포함되지 않습니다.
- 창작 모드의 첨부 사진은 참고 자료이며 생성 완료 결과가 아닙니다.

광고 용도별 이미지 비율
미리보기 위 ‘출력 비율’ 또는 ‘광고 용도별 비율 고르기’에서 선택하세요.
- 1:1 — 1080×1080 — SNS 피드·정사각형 상품 소개
- 4:5 — 1080×1350 — 인스타그램·페이스북 세로 피드
- 3:4 — 1080×1440 — 세로 상품 소개·카탈로그
- 9:16 — 1080×1920 — 스토리·릴스·쇼츠용 이미지 소재
- 2:3 — 1080×1620 — 세로 포스터·핀터레스트
- 16:9 — 1920×1080 — 웹 가로 홍보 이미지·영상 썸네일
- 약 1.91:1 — 1200×628 — 링크 광고·가로 배너

원본 사진은 비율을 유지하며 전체가 보이도록 배치됩니다. 문구·규격·제작 방식은 유지되고, 가로형은 문구와 상품을 좌우로 배치합니다.
현재 내보내기는 정지 이미지 PNG이며 영상은 생성하지 않습니다. 광고 매체와 노출 위치의 규격·안전 영역은 게시 전에 확인해주세요.

규격 없는 자동차·교육·보험·서비스 광고
1. 광고 정보 → 광고 업종·상품 분류에서 해당 업종을 선택하세요.
2. 네 업종은 ‘규격 정보 사용’이 기본적으로 꺼집니다. 다른 상품도 직접 끌 수 있습니다.
3. 상품·서비스명과 서비스 내용, 문구·언어 탭의 광고 제목·설명을 입력하세요.
4. 교육·보험·서비스는 사진 없이 문구와 배경만으로도 PNG를 만들 수 있습니다. 자동차 원본 보존 광고에는 실제 차량 사진을 추가하세요.
5. 7가지 비율 중 선택하고 기기 저장 또는 PNG 내보내기를 사용하세요.

‘규격 사용 안 함’은 생성 요청에 치수를 넣지 않습니다. ‘규격 사용 + 표시 안 함’은 생성에 참고하되 화면에서만 숨깁니다. 예전에 입력한 값은 지우지 않습니다.
새로운 광고 이미지 만들기는 현재 설정 저장까지 지원합니다. 사진 없이 요청할 때는 원하는 광고 내용을 입력하며 실제 AI 생성은 연결 전입니다.

독립 앱 관리 및 백업
- 이 신규 앱은 외주 MVP와 별도로 개발하는 aiadcast입니다. 기존 MVP/회사 홈페이지를 변경하지 않습니다.
- source/docs/independent-app.md: 저장소·계정·서명·서버·결제·출시 절차.
- source/docs/model-evaluation.md: 새 AI 모델을 비교하고 안전하게 교체하는 기준.
- aiadcast-next-source.bundle: 소스 Git 변경 이력을 복원할 수 있는 파일입니다.
- build-info.json: 소스 커밋과 파일별 SHA-256. Android 앱 빌드/등록 완료를 뜻하지 않습니다.
- 현재는 웹 편집 검증판입니다. 실제 AI·회원·결제 서버·Android 앱과 Google Play 등록은 별도로 구현/검증합니다.

이용 요금 미리보기
- 상단 ‘이용 요금’을 열면 출시 제안가를 볼 수 있습니다. 현재 구매·차감은 하지 않습니다.

- 광고 문구 언어와는 별도 설정입니다. 실제 결제는 연결 후 스토어 국가와 결제 화면의 금액·통화를 따릅니다.
- source/docs/pricing-strategy.md: 과거 경쟁 가격 참고, 실제 청구서가 아닌 원가 가정, 가격 추천 근거.
- source/docs/pricing-calculation.md: 재시도·실패·부가세·스토어 수수료 가정에 따른 계산.
