aiadcast 개발 검증판 · 2026-10-15

이 버전은 대표자 주도 개발과 기능 검증을 위한 버전입니다.
Google Play 공개 출시·심사 완료 또는 외주 앱 대비 이미지 품질 우위를 뜻하지 않습니다.

실행 환경
- aiadcast-studio.html: PC Chrome/Edge에서 확인하는 웹 화면 검증판입니다. 휴대폰의 로컬 HTML 실행은 브라우저에 따라 제한됩니다.
- 실제 AI 생성: 무료 Render 서버와 Supabase가 연결된 HTTPS 앱 또는 서버를 연결한 Android 앱에서 시험합니다.
- HTML 파일 자체에 OpenAI API 키를 입력하지 않습니다. 서버 상태 응답은 확인했으며, 최신 코드 배포와 로그인 후 실제 생성은 아직 검증 전입니다.
- 화면에 오프라인 체험이라고 표시되는 경우 준비된 소재를 사용하는 모의 흐름이며 실제 OpenAI 생성 증거가 아닙니다.

기본 사용 순서
1. 홈에서 광고 만들기를 엽니다.
2. 산업과 상품/서비스 이름을 선택하고 선택적 회사 정보를 입력합니다.
3. 사진 활용 방식(AI 새 광고/실사 그대로)을 선택합니다. 각 사진에 실제 상품·공간 또는 디자인 참고 용도를 지정합니다. 서비스는 사진 없이 시작할 수 있습니다.
4. 규격은 필요한 경우만 입력하고 광고에 표시할지 선택합니다. cm, mm, inch를 지원합니다.
5. 상세설명에 확인된 재질·제공 범위·가격 등을 입력합니다.
6. 광고 문구를 AI에게 맡기거나 직접 입력합니다. 직접 입력한 문구는 그대로 전달합니다.
7. 필요하면 광고 목적과 비율을 선택한 뒤 광고 생성을 요청합니다.
8. 결과의 상품 모습·재질·규격·문구·가격을 검토하고, 제작 의도·타깃·추천 채널·검색어를 확인합니다.
9. 사용 확정 후 이미지를 저장합니다. 실제 서버 생성에는 시험 이용권과 OpenAI 예산이 필요합니다.

업종과 디자인 지침
- 기존 48개 업종: 상품 19개, 서비스 29개.
- 업종별 구도·조명·재질·서비스 장면 지침을 자동으로 전달합니다. 고객이 긴 프롬프트를 외울 필요가 없습니다.
- /magazine-cover, /3Billboard, /packaging, /metaad, /showcase, /product-explosion, /adcreative는 추가 요청에 사용할 수 있는 선택적 제작 지침입니다. 외부 도구를 자동 실행하는 명령어가 아닙니다.
- 없는 가격·효능·시설·경력·성과를 만들지 않도록 지시합니다. 생성 결과에 오류가 없음을 보장하지는 않습니다.

확인된 범위와 남은 부분
- 사진 활용 업데이트 관련 코드 검사 53건과 웹 빌드가 통과했습니다. 48개 업종의 한국어·영어 요청 조합을 검사했습니다.
- 실제 광고 이미지 품질 비교, 원격 생성, 모바일 실기기 사용과 Google Play 배포는 별도 확인이 필요합니다.
- 완성 광고는 문구까지 포함한 이미지 한 장입니다. 기존 글자를 무료로 직접 바꾸는 기능으로 설명하지 않습니다.
- 사진 한 장과 치수 입력이 정확한 실물 3D 재현을 증명하지는 않습니다.
- 기기 저장과 서버 저장은 다릅니다. 로컬 브라우저 데이터를 삭제하면 기기에만 있던 작업은 사라질 수 있습니다.
- PNG만으로 원본 편집 레이어가 복원되지 않습니다. 프로젝트 백업에는 사진과 입력 정보가 포함되므로 공유 대상을 확인합니다.

무료 시험 설정
현재 저장소에는 계정 최대 20개, 동시 AI 호출 2건, 전체 저장 900MB·개인 100MB, 월 1달러의 OpenAI 시험 예산이 설정돼 있습니다. 실제 배포 값은 연결 후 확인합니다. 무료 호스팅이어도 OpenAI 사용료는 별도입니다.
