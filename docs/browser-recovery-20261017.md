## 복구 동작

- 폼 변경을 layout effect에서 상위 draft에 전달하고, 화면에 반영되는 commit에서 저장을 시작한다. 250ms 임의 대기를 없앴다.
- IndexedDB 연결을 재사용하고 readwrite 트랜잭션을 즉시 등록한다. 동일 object store의 트랜잭션 순서로 오래된 사진이 최신 사진을 덮어쓰지 않도록 한다.
- 큰 사진을 저장하는 동안 또는 저장 실패 후에는 브라우저 이탈 경고로 미저장 입력을 보호한다. 저장 상태와 실패 이유를 표시하며, 다음 저장이 성공하면 경고를 해제한다.
- 브라우저 검사는 즉시 새로고침을 시도한다. 저장 중 경고가 나타나면 실제 사용자가 ‘머무르기’를 선택하는 동작과 저장 완료 표시를 검증한 뒤 새로고침한다. 임의 sleep으로 회귀를 숨기지 않는다. 사진 수·용도·원본 바이트·생성 요청의 사진 해시를 확인한다.
- 4MB 원본의 역할을 세 번 바꾸고 새로고침하는 검사, 저장 공간 오류를 주입한 뒤 경고·내용 보존·정상 복구 검사, 관리자 0개 이용권의 결과 검수/저장 검사를 추가했다.
- 이탈 경고를 무시한 강제 종료, 브라우저 저장소 삭제, OS 프로세스 종료까지 영구 저장을 보장하는 것은 아니다. 기기 저장은 서버 백업과 구분한다.

## 기존 기능 회귀 기준

사진 첨부와 미리보기, 일부 파일 실패 시 유효 사진 유지, 합계 10MB 초과의 빨간 경고와 원본 무압축 전달, 실제 사진/디자인 참조 용도, 규격 단위와 표시, PNG 픽셀/크기, 수동 문구, 생성 검수·중복 차감 방지, 계정별 격리와 서버 충돌 보호를 유지한다. 관리자 면제·일반 회원 위조 차단·예산 및 비용 보존은 로컬 공급사 대역의 서버/도메인 검사로 확인한다. 실제 공급사 품질·실물 3D 비례의 자동 검증을 완료했다는 의미가 아니다.

## 검사 기록 기준

`npm run typecheck`, `npm run build`, `npm run test:domain`, `npm test`, `npm run check:cloud`, `npm run check:isolation`을 구분한다. 최종 커밋의 로컬 결과와 원격 CI 링크는 PR에 기록한다. CI에도 독립 typecheck/cloud 확인과 테스트별 브라우저 증거 업로드를 추가했다. 기존 skip을 늘리거나 테스트를 삭제하지 않는다.

웹 `lint` 스크립트와 lint 설정은 기존 저장소에 없다 (`npm run lint`: Missing script). 기존 문서의 lint는 Android Gradle lint다. 이번 환경에 Android SDK가 설정되지 않아 Android lint/APK를 새로 검증한 것으로 보고하지 않는다. TypeScript 검사와 `git diff --check`는 lint와 별도로 기록한다.
