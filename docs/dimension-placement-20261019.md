# 본제품/작은 사진/치수선 없음 선택 우선

운영 3d0fcb3 기준 최소 서버 수정이다. APK 0.2.43의 사진 규격 표시 라디오는 method=ai와 선택한 main/inset/none을 저장한다. generation.ts는 main/inset을 dimensionDisplay.layout으로 전송하며, ‘규격을 AI 참고로 전달’은 별도의 dimensionPlan만 제어한다. main을 inset으로 바꾸는 fallback은 확인되지 않았다. 사진에 설치 버전이나 실제 전송 요청 로그가 없으므로 사용자 결과의 단일 발생 원인을 확정하지 않는다.

기존 프롬프트는 main을 지시하지만 작은 규격 인셋 대체를 명시적으로 금지하지 않았다. 이번 수정은 최종 프롬프트 끝에 사용자 위치 선택의 우선순위를 명시한다. main은 본제품에만 치수선을 표시하고 별도 측정 인셋·도표로 대체하지 않는다. inset은 같은 제품·구조·재질·열림 상태의 작은 사진에 표시한다. none은 치수선을 금지하며 숫자 요약은 기존 ‘광고에 규격 표시’ 값에 따른다. 기존 광고 스타일·모델·가격·예산은 변경하지 않는다.

관련 도메인 검사 18건 통과: 각 위치 × 규격 참고 ON/OFF, 300/200/100mm, 우선 지시, 기존 해시/검수/예산/멱등 경로. 실제 유료 생성을 하지 않았다. 프롬프트 전달 검증은 생성 이미지의 위치·입력 치수·실물 비율을 완벽히 보장하지 않는다. 기존 생성 이미지는 자동으로 바뀌지 않는다.

서버 적용이 필요하다. APK 전체 변경이나 PR41 배포는 필요 없다. 별도 클라이언트 브랜치 fix/save-share-caption-20261019는 APK 0.2.43 기준으로 저장·공유 버튼 아래 지정된 회색 설명 문단만 제거하며, 버튼·기능·오류 알림을 유지한다. 그 문구 제거를 설치 앱에 반영하려면 새 APK가 필요하다. 이번 단계에서는 새 APK 제작이나 운영 배포를 실행하지 않는다.
