# 홈 행동 통합 · 2026-10-10

홈은 광고 만들기 하나를 중심으로 구성한다. 서비스 광고, 이전 광고, 최근 작업 카드, 하단 편집 복귀 링크와 추가 단계 안내를 제거했다. 제작 첫 화면에서 상품/서비스를 선택한다. 기존 업종·규격·참조사진·요청사항·선택 연락처를 유지한다.

내 프로젝트에 현재 편집본을 같은 ID의 저장본 대신 보여준다. 최신 편집을 다시 열 때 기존 저장 절차를 따르며 중복 타일을 만들지 않는다. 자동 클라우드 동기화는 아니다.

검증: 모바일/PC 30개 브라우저 테스트 통과. 단일 시작 경로, 사진 없는 서비스, 기존 업종, 10개 사진, 연락처, 미완성 작업 복귀와 중복 방지 확인. Android Java 2개 테스트 및 lint/빌드 통과. APK와 dist 144개 assets 바이트 비교. 0.2.10-dev/versionCode12, 기존 서명 유지. 공개 서버 미연결 상태는 그대로이며 이번 변경으로 AI 생성 완료를 주장하지 않는다.
