# 메인 활용 안내와 업종 분류 수정 · 2026-10-10

- 메인 중앙의 영문 ai 그래픽을 사진·설명 → 광고 이미지 → 매체별 저장의 한국어 구성 예시로 교체했다. 피드/스토리/블로그·홈페이지 활용, 게시글·키워드, 저장한 광고 재편집을 안내한다. 예시는 CSS로 그린 레이아웃이며 실제 생성 결과로 표시하지 않는다. 영어 UI에서는 영어 안내를 제공한다.
- 제작 화면의 48개 업종을 한 번에 표시하던 드롭다운을 공통 IndustryPicker로 교체했다. 실물·규격 상품(9개 카테고리) / 서비스(10개 카테고리) → 카테고리 → 세부 업종으로 선택한다. 검색도 해당 대분류 안에서만 작동한다. 단일 업종 카테고리는 바로 선택된다.
- 업종 ID와 기존 프로젝트 호환성은 유지했다. 상품: 포장재 → 박스/쇼핑백/라벨/용기/비닐/파우치/기타. 서비스: 스포츠·운동 → 헬스/요가/필라테스/수영/테니스/골프/기타 스포츠 등.
- 웹 빌드와 관련 PC/모바일 브라우저 26개 통과(최초 25개 통과, 비동기 프로젝트 불러오기 완료를 기다리도록 검사 수정 후 해당 파일 4개 재검사 통과). 모든 업종 경로, 기존 프로젝트 호환성, 영어 선택, 참조사진 10장, 저장/출력을 확인했다. AI 유료 호출 없음.
- APK 0.2.1-dev / versionCode 3, 빌드·Java 검사·lint·서명 검증 통과. APK 웹 자산 127개가 검사한 dist와 일치. 0.2.0-dev와 같은 개발 서명이며 삭제 없는 업데이트 대상이다. 실제 기기 업데이트 성공은 별도 확인이 필요하다.
- 회원가입/공개 AI 서버 연결은 이번 화면 변경에 포함되지 않는다. 생성 버튼을 동작하는 것처럼 바꾸지 않았다.

## 0.2.2 — 첫 단계 회사 정보

사진 첨부 앞에 선택적인 회사·연락처 입력 항목을 추가했다. 회사명·전화·이메일·홈페이지를 입력하고 각 표시 여부를 선택한다. 마지막 단계에서도 동일 값을 확인·수정한다. 미입력으로 진행 가능하다. 관련 PC/모바일 10개 검사, Android 빌드/검사/서명 확인을 통과했다. 0.2.0/0.2.1과 같은 개발 서명이다. 추가 유료 API 호출 없음.

## 0.2.3 — 새 AI 생성 광고 이미지

사용자가 제공한 고급 광고 이미지의 조명·재질·패키지 구성을 참고해 image_gen 도구로 새 메인 이미지를 생성했다. CSS 선물박스 그림을 제거하고 실제 생성 PNG(1122×1402)를 APK에 포함했다. 사진은 전폭으로 보이며 한국어/영어 광고 문구는 별도 HTML 요소로 표시한다. 원본 생성 파일은 보존하고 출처와 해시는 src/assets/provenance.json에 기록했다.

이 이미지는 메인 소개를 위한 AI 생성 예시이며 모바일 앱의 Sunburst API 실행 결과나 실물 상품 동일성 검증 결과가 아니다. 사용자 제공 브랜드/연락처를 새 이미지에 복제하지 않았다. 휴대폰 생성 서버 연결 상태를 변경하거나 완료로 표시하지 않았다. PC/모바일 관련 검사 14개, Android 빌드·검사·서명 확인 통과. 웹 자산 128개가 APK와 일치. 0.2.0 이후와 동일 서명.

## 0.2.4 — 럭셔리·뷰티·패션 광고 갤러리

럭셔리 가죽 가방과 성인 모델의 패션 광고 이미지를 image_gen으로 새로 제작해 기존 뷰티 이미지와 3종으로 구성했다. 출처/해시를 기록했으며 실제 브랜드 제휴나 모바일 API 실적처럼 표시하지 않는다. 첫 화면은 럭셔리 광고이며 분야 탭, 좌우 키보드, 가로 터치 넘기기를 지원한다. 세로 스크롤은 광고 전환으로 처리하지 않는다. 자동 재생 없음. 한국어/영어 제목·설명과 명암에 맞는 글자색을 제공한다.

관련 PC/모바일 16개 검증 통과(기존 14개와 Touch 초기화 인자를 수정한 갤러리 검사 2개 재검사). APK 빌드·Java 검사·lint·서명 검증 통과, 웹 자산 130개 일치. 이미지들은 앱에 포함되어 외부 이미지 서버 접속 없이 표시된다. 휴대폰에서의 실제 업데이트/스와이프 체감 검증은 별도다. 0.2.0~0.2.3과 같은 개발 서명이다.


## 0.2.5 — 잡지 표지 스타일 캠페인

사용자 요청에 따라 3개 광고 사진을 새로 생성했다. 레드 실크·버건디 가방·조각 같은 골드 장식, 딥 블루·황금빛 향수·물결, 코발트·블랙 쿠튀르·레드 실크의 성인 모델로 색·재질·빛의 대비를 강화했다. 원본 PNG는 보존하고 출처/해시를 갱신했다. 좌측 상단 아이보리 바탕에 기존 aiadcast 로고의 ai #b65a35, adcast #292d27, 삼각형 #f27a37을 사용했다. 한국어/영어 헤드라인은 이미지와 분리하여 표시하고 모델 얼굴을 피하도록 패션 배치를 조정했다.

390px에서 3개 실제 렌더를 시각 확인했다. PC/모바일 관련 16개 검사, Android Java 2개 검사, lint(기존 경고 1개, 오류 없음), APK 빌드·서명 확인 통과. APK 내부 웹 자산 130개가 dist와 일치한다. 0.2.5-dev / versionCode 7은 0.2.0~0.2.4와 동일 서명이다. 공개 AI 서버·실기기 설치 검증은 별도이며 메인 이미지가 앱 API 결과인 것처럼 표시하지 않는다.


## 0.2.6 — 현실적인 상품·의류로 재교체

사용자가 0.2.5의 향수병 형상, 추상적 가방 장식, 비현실적인 의상을 거부했다. 세 이미지 모두 image_gen으로 재제작했다. 반듯한 직사각형 유리 향수병, 작은 직사각형 골드 잠금장치의 검정 가죽 가방, 베이지 재킷·흰 셔츠·검정 바지의 성인 모델로 교체했다. 빛과 건축적 그림자 중심의 배경에 짙은 한글/영문 제목을 배치했다. 좌측 상단 로고의 원래 색상을 유지하며 밝은 배경에서는 바탕 상자를 제거했다.

390px 실제 렌더에서 세 이미지와 글자 배치를 확인했다. PC/모바일 관련 16개 검사, Android Java 2개 검사, 빌드·서명 검사 통과. lint는 기존 JavaScript 설정 경고 1개, 오류 없음. APK 0.2.6-dev / versionCode 8, 포함한 웹 자산 130개 일치, 0.2.0~0.2.5와 같은 개발 서명. 원본 이미지와 출처 기록을 보존한다. 휴대폰 AI 서버 연결·실기기 설치 검증은 여전히 별도다.
