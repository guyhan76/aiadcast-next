# 프리미엄 광고 제작과 홈 예시 — 2026-10-11

사용자 승인: 상표 없는 독자적 상품으로 홈 예시를 전면 교체하고 10개 분야를 소개한다. 상품 5종(화장품, 패션소품, 패션, 주얼리, 소형가전)과 서비스 5종(여행, 호텔, 보험, 병원, 자동차 리스·렌탈)이다. 기본 CTA는 없고 고객이 요청사항에 명시한 경우에만 넣는다.

## 구현

- imagegen 스킬과 내장 이미지 생성 도구로 10개 사진을 제작했다. 기존 AHC·샤넬 상품을 입력으로 사용하지 않았으며 로고·인쇄·대표 디자인을 복제하지 않는다. 사진 파일은 WebP로 최적화했고 생성 지침·해시를 `src/assets/showcase-provenance.json`에 기록했다.
- 홈은 사진 위 정확한 한글·영문 DOM 문구를 별도 배치한다. 상품/서비스 그룹, 전체 10개 선택, 이전/다음, 6초 자동 넘김, 모션 감소 설정, 터치 일시정지, 확대 검수를 지원한다.
- 스킬의 제작 원칙을 서버의 업종별 연출 브리프에 반영한다. 재질·촬영 기법과 3개 후보 콘셉트를 제공하고 모델이 단일 콘셉트를 선택하도록 지시한다. 브라우저/서버는 같은 문구 여백을 사용한다. 이는 규칙 기반 브리프와 생성 지침이며 별도 비전 평가 모델로 후보를 실제 비교 채점하는 시스템은 아니다.
- 새 창작에서는 사진의 상품 특징을 참고한다. 원본 보존에서는 상품을 새로 그리지 않고 빈 배경만 요청한다. 규격은 비례 참고이며 정확한 3D 복원 보장이 아니다.
- 제목·설명은 실제 글꼴 너비로 줄바꿈·축소한다. 글을 임의로 자르거나 수치를 다시 쓰지 않는다. 최소 크기로도 넘치면 내보내기 오류로 처리한다.
- CTA는 요청사항의 명시적인 의사에서만 활성화한다. 광고 목적이 문의여도 자동 활성화하지 않는다. 생성 사진에는 CTA를 그리지 않고 승인 문구를 별도 조판한다. 직접 입력한 문구는 사용자의 편집 의사로 보존한다.
- 생성 미리보기에서 원본과 대조해 확대 검수할 수 있다. 재질·비율·제품 인쇄·인물·손·잡티를 검토하고, 적용 후 광고 문구와 사실 정보를 확인한다. 사용자의 기존 결과 확인/적용 흐름과 비용·중복 차감 보호를 유지한다.

## 검증과 한계

10개 사진을 직접 확인했고 소형가전의 가장자리 잘림과 작은 흔적을 내장 이미지 생성 도구로 보정 후 재검토했다. 브라우저 검사는 두 언어의 10개 광고, 모바일 너비, 키보드, 자동 넘김, 확대·닫기 동작을 검증하고 실제 DOM 출력 스크린샷을 남긴다. 숫자·문구 보존, CTA 명시 요청, 업종 브리프, 원본 보존은 도메인 테스트로 확인한다.

생성 모델의 자체 잡티 점검은 품질 보장이 아니다. 의미적 오타, 상품 동일성, 인물 이상과 실제 서비스 사실은 사람의 검수 대상이다. 홈 예시 제작에 쓰인 내장 생성 도구와 앱의 고정 서버 이미지 어댑터는 서로 다른 실행 경로다. 서버 지침 변경만으로 내장 도구가 고객 앱에 설치됐다고 표현하지 않는다. 실제 서버의 10개 업종 유료 생성 평가, 외부 배포 및 Android 실기기 확인은 별도다.
