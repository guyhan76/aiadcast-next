# 내 계정의 앱·서버 버전 표시

후보 `feat/visible-version-info-20261018`은 PR32 최종 `db15d693130a4d3cb94b51ab7eb0a170614cd24d`에서 분기했다. 해당 후보의 운영 배포와 독립적으로 준비했으며 이 작업에서는 운영 배포를 실행하지 않는다.

로그인한 화면 상단 내 계정 영역에 실제 Android `versionName`과 `versionCode`를 표시한다. 숫자 링크 또는 내 계정을 누르면 설치 앱 버전/패키지, 패키징 시각/웹 자산 digest, 웹 화면 버전/빌드 commit, 서버 조회 상태/버전/commit을 따로 보여준다. APK 0.2.34-demo/code36은 기존 패키지와 서명을 유지한다.

Android BuildConfig 값을 기존 신뢰 origin의 WebView 초기화에 주입한다. 프런트 패키지 버전으로 네이티브 버전을 추정하지 않는다. 네이티브 정보가 없는 웹 또는 구형 앱에서는 웹 버전으로 표시하고 설치 앱 버전은 확인 불가로 표시한다. 구형 WebView의 늦은 초기화도 갱신 이벤트로 처리한다.

읽기 전용 `GET /api/version`은 `schemaVersion`, 고정 서비스 식별자, package.json 버전, 검증한 40자리 commit만 반환한다. 기존 Render commit 메타데이터 또는 실행 저장소 HEAD를 사용하며 둘 다 없으면 commit은 null이다. 서버 키·계정·환경값·예산·경로를 공개하지 않는다. 기존 origin 검사와 요청 제한을 유지하고 인증/이용권/지급/생성 서비스를 호출하지 않는다. 신규 DB 마이그레이션·환경변수·권한은 필요하지 않다.

앱은 이 endpoint의 실제 응답만 서버 정보로 사용하고 인증 토큰을 보내지 않는다. 404, 잘못된 데이터, 연결 실패, 10초 시간 초과는 확인 불가로 표시한다. 성공한 과거 값을 새 조회 실패 뒤에 현재 값처럼 남기지 않는다. 명시적 다시 확인을 제공하며 버전 숫자 차이만으로 호환성이나 배포 성공을 추정하지 않는다. 기존 서버를 먼저 변경하지 않아도 새 앱의 설치 버전은 표시되지만 서버 정보는 endpoint 배포 전까지 확인 불가다.

실제 운영 endpoint 확인이나 배포는 별도 작업이다. 로컬 대체 응답, SQLite/PostgreSQL 경로, Android 빌드/패키지와 데스크톱·모바일 흐름을 검사한다. 실제 유료 API, 결제, 키·예산 변경은 실행하지 않는다.
